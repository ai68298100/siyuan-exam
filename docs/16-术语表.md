# 术语表（中英对照）

> 文档/界面/代码注释统一用词。来源：docs/11·13 与竞品调研。

| 中文 | 英文 | 含义 |
|---|---|---|
| 题库 | bank / question bank | 一个思源笔记本=一个题库 |
| 题目块 | question block | 超级块 + exam-* 属性的题目单元 |
| 刷题 | practice | 判分式作答（对应 recite 背诵） |
| 背诵 | recite | 盖答案+四级自评形态 |
| 闪卡 | flashcard / card | 送入内核 riff 的记忆卡 |
| 错题本 | wrongbook | 答错自动收录的派生视图 |
| 消灭 | eliminate | 连对 2 次自动移出错题本 |
| 已掌握 | mastered | 手动处置覆盖层状态 |
| 永久移除 | removed | 手动处置覆盖层状态 |
| 举一反三 | more like this / same-kp drill | 同考点变式题 |
| 模考 | mock exam | 蓝图组卷+限时+成绩单 |
| 蓝图 | blueprint | 模块×题数×分值×来源 的组卷配置 |
| 答题卡 | answer sheet | 底部题号网格（未答/已答/标旗） |
| 标旗 | flag | 标记存疑题目 |
| 冲刺 | cram | 考前模式：错≥2 队列，不写回调度 |
| 每日一练 | daily set | 到期优先+高频错题补足的当日队列 |
| 期望保留率 | desired retention | FSRS 唯一建议调参（默认 0.9） |
| 共用材料 | material | 题组母块（不参与判分） |
| 材料组 | material group | exam-group 关联的子题集合 |
| 待审核 | pending | AI 生成题的入库前状态 |
| 二遍核验 | 2nd-pass review | 换角色置信度核验（≥0.85） |
| 挑战码 | challenge code | 异步 PK 的导出卷（v1.x） |
| 战报 | daily report | 写入日记的当日学习摘要 |
