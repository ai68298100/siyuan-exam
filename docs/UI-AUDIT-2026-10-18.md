# 小驴考试 UI / R54 对照审计（2026-10-18）

> 范围：当前 v0.10.4 工作区的生产源码、`design/prototype-r54/`、UI 组件清单、浏览器 harness，以及本轮隔离思源宿主操作记录。本文取代 `output/audit-2026-10-18-ui-notes.md` 的当前状态判断；旧记录保留为过程资料。

## 结论与入口

R54 的五项任务导航、题目 Peek、出题四分面、专注作答和报告分区已经进入生产组件。它仍由练习、模考、报告三个思源自定义 Tab 承载，属于任务结构迁移，不是原型整页直接投产。示例题库、保存、作答和成绩在生产中会真实写入；原型只有合成数据和页内演练状态。

桌面仅注册一个顶栏按钮，点击固定进入练习台主页；没有独立状态栏或错题 Dock，也没有顶栏右键多入口。移动前端不注册桌面顶栏，依赖命令、块菜单及已打开页面内部导航。错题由练习台 Rail、命令或相关上下文操作进入。设置由思源 SettingUtils 承载，并非原型中的独立设置页。

## 尚未交付或不可扩大解释的能力

1. **题目作者生命周期未接通生产链路。** `src/core/revision.ts` 有 `QuestionLifecycleStatus` 和 `canTransitionLifecycle` 及测试，但 `Question`、题块持久化、编辑表单、入库/组卷未形成草稿 → 审核 → 发布 → 废弃闭环，界面没有完整状态切换流程。
2. **完整来源证明未交付。** 现有 `source`、`origin`、批次、资料及笔记关联可提供来源线索；尚无从来源证据、采集版本到人工核实结论的完整可审查历史。AI 二遍核验或来源文字不代表事实已经查证。
3. **修订时间线不是全部历史作答的冻结题版。** 已实现题目内容/答案/规格快照、差异和恢复，每题保留最多 10 条；尚未将每次练习/历史记录统一绑定永久修订号与不可变完整题版。模考已存在开考冻结卷和漂移提示，不能由此推广为所有题目历史均已冻结。
4. **发布前守卫未接通。** 没有完整生产入口按“缺答案/缺题型/孤儿资料”等清单阻止发布，也没有发布后的题库/队列消费规则。`revision.ts` 文件头的目标描述不是接线完成证据。
5. **OCR 尚未接入。** 原型保留“等待思源 3.8.7 正式版”的历史设计文案；不能据当前隔离内核升级而判断 OCR 已可用。打印、实际文件下载/剪贴板、外部阅读器、打卡桥和真实 AI 仍分别待验。
