## A. 加载与框架（2 分钟）

1. ✅/❌ 思源重载后无报错，顶栏/状态栏出现小驴考试入口（📝 今日/错题/连胜 计数）。
2. ✅/❌ 命令面板可搜到「练习台/模考场/报告中心」三个命令，点击打开对应 Tab。
3. ✅/❌ 设置面板四项可保存（每日题数/保留率/AI 端点/AI Key），重开思源后值保留。
4. ✅/❌ 若之前装过旧版：是否弹出「已更新」提示。

## B. 建库与导入（3 分钟）

5. ✅/❌ 首次打开练习台出现「先建一个题库」守卫；输入名称创建成功。
6. ✅/❌ 导入题库 → 下载官方模板 → 填 2 行（含 1 行材料 + 1 行子题）→ 选择文件导入 → 6 行全部入库无错误行。
7. ✅/❌ 材料组验证：浏览模式中材料行与子题行均带组 ID；练习时子题上方出现「📎 共用材料」卡。
8. ✅/❌ 导入折叠区的「⬇️ 下载官方模板」可下载可打开。
9. ✅/❌ 故意导入 1 行坏答案 → 错误行进清单、「导出错误清单 CSV」可下载且 Excel 打开中文不乱码。

## C. 刷题核心（3 分钟）

10. ✅/❌ 快速刷题进入会话；单选点选/提交/反馈正确；多选可 toggle 多个字母。
11. ✅/❌ 答错后：错因三分类 chips 可点；「转为闪卡」提示成功；「讲解此题」（需 AI 通道）返回解释；追问输入可多轮。
12. ✅/❌ 键盘流：A-F 选、Enter 提、J 下一题、E 收藏（星标 chip 点亮）、Esc 结束（弹确认）。
13. ✅/❌ 结束后重进会话恢复进度；「放弃」后队列清空。
14. ✅/❌ 背诵模式：盖答案 → 提示①考点可点 → 翻开 → 1-4 自评（含键盘）→ 组结算显示自评分布；🔊 朗读题干。
15. ✅/❌ 纯听题 🙈：题面/选项文字隐藏、自动朗读；再点恢复。
16. ✅/❌ 收藏练习卡：只刷已星标题；「只看收藏」浏览过滤同步。

## D. 错题与状态（2 分钟）

17. ✅/❌ 错题 Dock 计数与列表实时刷新；每行 ✓（已掌握）/ ✕（移除）按钮生效且状态栏同步。
18. ✅/❌ 手动「已掌握」后再答错 → 自动重新收录（覆盖层清除）。
19. ✅/❌ 状态栏 📝/❌/🔥 数字随作答变化；点击打开练习台。
20. ✅/❌ 报告中心：KPI/热力图/掌握度条（<3 题灰显）/薄弱组卷按钮/时段分布/周对比 均渲染。
21. ✅/❌ lv-exam:stats：控制台执行 `window.addEventListener("lv-exam:stats", e => console.log(e.detail))` 后切换 Tab，可见脱敏聚合（无题干/路径）。

## E. 模考与收尾（2 分钟）

22. ✅/❌ 模考蓝图：默认按考点生成模块；开始 → 计时走动 → 答题卡网格点击跳题 → 🚩 标旗 → 交卷（未答完弹确认）。
23. ✅/❌ 成绩单：总分/及格判定/分模块条/雷达（≥3 模块）/历史 chips 点击回看分模块明细；「导出成绩单 MD」下载。
24. ✅/❌ 估分卡：题库模式勾选 → 答案序列自动生成 → 估分出结果 → 历史 chips 累积。
25. ✅/❌ 日常拖拽：xlsx 拖入思源窗口 → 进导入流程。
26. ✅/❌ 题库包：导出折叠区「📦 导出题库包」下载 .sy.zip；「📥 导入题库包」可选文件导入成新副本。

## F. v0.6-dev 增项（约 8 分钟；对应 CHANGELOG「未发布」段）

> **API 级脚本已覆盖的步骤**：30（读回）/31（先导语义）/33（批量改属性）/34（批次回滚含 3.8.6 deleteBlock 行为）已由 `node scripts/smoke-data.mjs` 自动验证（2026-10-03 真机 3.8.6 6/6 通过）；27/28（模考恢复/过期）与 36-38（信心/行动/AI 记录）属 UI 旅程，仍需人工执行。另：`pnpm smoke` 一条命令跑完全部可自动化验证（preflight 17 项 → smoke-data → perf-bank 性能基线；3.8.6 实测：写 500 题 ≈8s、检索 3500 行 <250ms）。

27. ✅/❌ **模考恢复**：开考答 2 题+标旗 1 题后直接关闭 Tab → 重开模考场出现「有一场进行中的模考」横幅 → 恢复后答案/标旗保留、剩余时间延续真实流逝（未重置）。
28. ✅/❌ **模考过期**：把电脑休眠超过剩余时长后回来 → 自动交卷一次；报告中心核对模考流水只有一份（无重复交卷）。
29. ✅/❌ **交卷防重**：交卷按钮快速双击 → 历史成绩只新增一条。
30. ✅/❌ **导入读回**：正常导入完成显示「✓ 读回确认 N 题」；断网状态下导入则显示「未能读回确认」而非成功。
31. ✅/❌ **先导 5 行**：解析 10+ 题后点「🧪 先导 5 行试导入」→ 提示读回结果；「入库」按钮计数减 5，完整入库后总题数不多不少。
32. ✅/❌ **映射复用**：Excel 导入成功后「💾 保存此列映射」命名 → 换文件同结构再导入 → 下拉选映射直接解析；换不同列数的表则提示回退自动映射。
33. ✅/❌ **批量编辑**：浏览「批量编辑」多选 3 题 → 改考点 → 「预览变更」逐题 from→to → 「应用」→ 思源文档中对应题块属性更新 → 「撤销本次」还原。
34. ✅/❌ **批次回滚**：🩺 题库健康面板出现「导入批次」→ 撤销整批（confirm）→ 思源中该批题块消失、练习统计不受影响。
35. ✅/❌ **保存徽章**：正常操作后练习/模考头部无 💾 徽章（=全部已确认）；如出现红/黄徽章，点击可定位目标。
36. ✅/❌ **信心校准**：练习答前点 信心/按 1-3 → 提交后反馈区显示已记录信心 → 报告中心「信心校准」卡对应档计数 +1。
37. ✅/❌ **行动闭环**：结算页「错题加入下一步行动」→ 报告中心行动卡出现（重复加入提示跳过）→ 点「🔁 重练」开单题会话且该行动标记完成。
38. ✅/❌ **AI 发送记录**：讲解一次后 AI 视图「🧾 AI 发送记录」可展开看到实际发送内容；断网点讲解显示降级提示而非异常栈。
39. ✅/❌ **诊断导出**：报告中心「🩰 导出诊断信息」→ 剪贴板为 JSON（含内核状态/统计口径，无题干/key/路径）。
40. ✅/❌ **CSV 往返**：浏览「⬇️ CSV」导出 → Excel 打开改一处再保存 → 重新导入：1 题判重复跳过、其余正常解析。
