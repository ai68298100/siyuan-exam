## 4. 逐项验收补充

每项给出可观察的结果、必要最小前置和将来需要保留的证据；以下均是待实现/待验收要求。

### U01 将15个场景接入真实宿主入口

主承接：**45-01 / W14 / S1起**。相关原项：47-01/03、86-02、37-05、69-03。

**触发与期待结果**：明确15个场景到现有练习/模考/报告Tab、Dock及命令入口的承接表，宿主路由不直接照搬原型hash。两个Tab实例分别保持project/session/source/locator及返回控件；关闭一个实例仅释放自己的计时、监听和请求，活动会话离开确认只触发一次。

**必要最小前置**：选定主前端、可观察Tab实例生命周期和最小returnContext；不要求先注册15个Tab。

**验收证据**：从Dock和报告分别进入同题，跨页返回与关闭其中一个Tab的录像/日志及实例释放记录。

### U02 项目配置草稿与已确认版本分离

主承接：**80-02 / W02 / S1起**。相关原项：80-03、47-05、85-06。

**触发与期待结果**：项目名称、考种、阶段、范围与容量输入只修改草稿，确认前展示受影响计划/试卷；取消或保存失败不得提前改全局项目、报告范围及历史版本。确认成功后相关入口使用新版本；已有冻结试卷保持原条件。

**必要最小前置**：项目身份/修订、对象级保存确认和本次变更影响清单。

**验收证据**：编辑后取消、写入失败、成功重载各一例；核对旧成绩和首页项目标签。

### U03 首页卡片来自可追溯项目快照

主承接：**86-03 / W14 / S3起**。相关原项：80-03、88-03、109-03、69-04。

**触发与期待结果**：今日任务、待审数量、待复测和笔记数量标明同一项目/范围/更新时间，点击能回到实际对象；加载部分、陈旧快照、失败与零分别显示。切项目后旧请求不覆盖新首页；完成某任务后只刷新其事实影响，不因生成AI文本增加完成数。

**必要最小前置**：项目快照和本次已支持任务类型的计数/失效规则；G8的事实一致性继续适用。

**验收证据**：两项目交替切换、迟到返回、仅一类数据失败和真实完成一个任务的快照/下钻核对。

### U04 分钟容量真正改变混合任务队列

主承接：**84-01 / W11 / S3起**。相关原项：84-02/03/04、117-02、82-04。

**触发与期待结果**：拖动分钟预算先预览阅读/练习/笔记/复测的增删、预计耗时及保留未完成任务，确认后形成计划版本；AI调整走同一提案路径。改预算、阅读定位或接受建议均不自动完成任务；实际用时与估计值分开，超预算和欠账有可解释处理。

**必要最小前置**：至少两类任务的成本与完成定义、可恢复计划版本；首条AI闭环不等待容量引擎全集。

**验收证据**：同项目10/25/60分钟计划差异、一个超时任务和次日未完成任务的记录。

### U05 空态按资源与范围判断

主承接：**81-04 / W14 / S2起**。相关原项：81-01/02/06、47-06。

**触发与期待结果**：分别判断无项目、无来源、无题、无当前范围命中、无作答证据与资源失效；无题不隐藏已有资料/笔记，无今日数据不显示整库为空。原创演示有独立身份和退出/清除入口，浏览或重置演示不写正式项目统计。

**必要最小前置**：已选资源类型、查询范围和演示/正式数据隔离规则。

**验收证据**：有笔记无题、有历史无今日、过滤零命中及退出演示四种状态的后续可达操作。

### U06 保存状态绑定具体对象和回执

主承接：**37-01 / W03 / S1起**。相关原项：37-02/03/05、45-06、83-02、109-04。

**触发与期待结果**：项目、作答、资料笔记、AI候选与行动各有目标ID/修订、待保存内容和确认回执，不能共用原型noteSaved。顶栏汇总可定位具体失败对象；保存另一笔记或恢复网络不把该对象标成功；确认丢失显示结果未知，重载后按目标核对并恢复。

**必要最小前置**：本次对象的存储响应与确认方式、在途写入协调；不把同步完成当本机写入确认。

**验收证据**：两个笔记目标交替编辑、一个失败一个成功、响应丢失和重载的内容/状态对照。

### U07 字段映射驱动真实校验和试导

主承接：**38-02 / W05 / S1起**。相关原项：38-01、38-07、45-05。

**触发与期待结果**：改变列映射或修正某行须重新产生预览与校验；原文/候选保留，原始行号能定位。映射、文件或修正值改变使旧试导确认失效；返回前步不丢修正；AZ等无效答案需按实际选项修复，不以固定替换演示充当解析。

**必要最小前置**：一种真实输入格式、稳定行/选项身份和可复现校验器。

**验收证据**：异名列、乱序列、合法但映射错误的数据，以及试导后改映射的阻断/重新确认。

### U08 导入完成页基于真实读回清单

主承接：**38-04 / W05 / S1起**。相关原项：37-01/03、38-03/07、69-05。

**触发与期待结果**：按同一batch列成功、失败、未处理及已写待索引对象；重试只补未确认部分，取消保留可恢复checkpoint。完成页的题数和“开始练习”仅使用确认读回的qid/版本；索引等待不提示全部失败，部分成功不能显示全量成功或重导已成功行。

**必要最小前置**：导入批次/行身份、写入回执、索引等待与失败的区分。

**验收证据**：第二批故障、取消重载、索引滞后后读回与入口实际题目集合的核对。

### U09 作者编辑与个人笔记分开保存

主承接：**43-01 / W06 / S3起**。相关原项：43-06、38-07、83-04、109-04。

**触发与期待结果**：“编辑题目”和“编辑AI候选”进入实际题干/选项/答案/解析/引用编辑目标，个人反思不得默认写成官方解析。展示原/候选修订差异；目标已变需重新核对，草稿取消/保存失败不发布，接受未确认候选不能直接进入练习；历史作答保留原题版。

**必要最小前置**：一种具体题目/候选产物的编辑与校验、作者修订身份和发布确认。

**验收证据**：题目、AI候选、个人笔记三个目标，以及并发修订、取消和发布后旧作答回看。

### U10 题库筛选与练习集合共用查询范围

主承接：**65-01 / W13 / S3起**。相关原项：43-05、61-01、65-02/03、69-05。

**触发与期待结果**：搜索、题型/来源/待审过滤和命中数作用于完整声明范围，分页后不退化为当前DOM筛选；“练本范围”冻结查询及实际选中qid/修订。返回保留过滤/排序/位置，范围更新后说明变化；不能把首批或首题库当全部命中。

**必要最小前置**：稳定查询身份、分页与会话范围快照；仅开放已支持字段。

**验收证据**：命中位于第二页/第二库、返回列表、结果更新后创建练习集合的比对。

### U11 实际题型控件保持键盘与焦点

主承接：**40-06 / W08 / S1起**。相关原项：40-01、45-03/07、61-03、36-02。

**触发与期待结果**：单选和多选使用稳定选项身份，点击/键盘得到同一完整答案；动态反馈、标旗或计时更新不重建当前输入焦点。中文输入、textarea/select/contenteditable及对话框中不触发答案快捷键；提交中禁重复，播报状态不提前朗读正确选项。

**必要最小前置**：当前支持题型的结构化输入及实际Svelte响应性，快捷键冲突表。

**验收证据**：多选增删、10选项键位、中文组合输入、持续计时和反馈更新时的焦点/提交记录。

### U12 答前信心绑定对应尝试

主承接：**44-02 / W10 / S1起**。相关原项：63-01/02/06、82-03、39-06。

**触发与期待结果**：信心选择随attempt及答前答案版本记录，可明确未填写；提交后不能修改最初置信度以改写校准。揭示/讲解后的信心作为新反思或改答记录，切题和恢复不沿用上一题；报告能区分未报信心与猜测。

**必要最小前置**：尝试身份、作答时间点、答案修订及证据缺失表示。

**验收证据**：答前选择、提交后变更、切题/恢复和未填写四例的初始记录及校准下钻。

### U13 帮助与反馈时机在全部入口生效
