## 2. 发布动作

1. `pnpm update-version` → 选版本（两份 manifest 同步）
2. CHANGELOG：`## Unreleased` → `## <version> (YYYY-MM-DD)`，补验证状态行
3. commit：`chore(release): <version>`（update-version 已改两文件）
4. `git tag v<version> && git push origin v<version>` → release.yml 自动：版本一致性校验 → guard → build → verify-package → release-check → SHA256 → GitHub Release
5. 发布后核验：下载 `package.zip` 与 `SHA256SUMS`，校验 SHA256、包内 manifest/tag 版本与文件清单；e2e 另记录实际宿主安装版本，不把旧安装态视作新版本验收
