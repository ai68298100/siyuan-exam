新增或修改数据控件时，逐项核对：

| 检查项   | 必须表现                                                                                                                                                                                                                                                         |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 可触发性 | 可见按钮/链接/卡片点击区都有真实 handler；禁用时有原因或邻近说明，不使用无响应占位。                                                                                                                                                                             |
| 加载     | 显示 busy/骨架或状态文本；锁定重复提交、切换和会造成竞态的控件；请求取消后清理 timer/listener。                                                                                                                                                                  |
| 成功     | 显示回执，精确刷新相关列表/详情，并给出下一步或回到来源的路径。                                                                                                                                                                                                  |
| 失败     | `role=alert` 或可读 toast 说明原因；输入保留；提供安全重试；未知写入结果先查回执，不能盲目重放。                                                                                                                                                                 |
| 空结果   | 说明是未创建、筛选无结果还是尚未读到；提供示例、录题、导入、重置筛选或回到上一级的动作。                                                                                                                                                                         |
| 表单     | 在字段附近显示校验；提交期间按钮锁定；成功有明确归宿；破坏性操作先确认，可撤销时提供撤销。                                                                                                                                                                       |
| 可访问性 | 原生 button/input/select 优先；图标按钮有 `aria-label`/`title`；Tab/焦点可达；当前页、选中项、弹窗和 busy 状态有 ARIA 关系；颜色不是唯一信息。                                                                                                                   |
| 响应式   | 生产 Rail 在插件容器 `760–1119px` 使用图标式窄侧栏，`<=759px` 显示五项底部任务栏；抽屉和底栏都限制在插件面板范围内。页面样式另有 `<=960px`、`<=820px`、`<=760px`、`<=720px`、`<=600px`、`<=480px`。R54 主画布使用 `1119px`、`960px`、`759px`、`359px` 容器断点；评审外框另有 `850px` 媒体断点。自动化覆盖 760/759px、今日周卡 960/900/759/390px 和宽窗口窄面板几何边界；逐档视觉/交互对比尚未验收。 |

## 6. R54 原型专有控件

`design/prototype-r54/index.html` 的状态选择器除正常/首次进入/通用加载/读取失败/部分成功/结果待核对外，还包含练习题库加载/空/失败、近七天无作答、资料空/无匹配/保存中/保存失败、模考加载/失败/空库/配额不足/题量不足/交卷失败、报告加载/失败/无库/范围加载失败/无作答/无证据。原型也有页面选择器、390px 切换、主题切换和重置演练；这些控件只服务设计评审，不是生产设置。R54 首页在零作答时展示三步引导，入口包括导入、手工录题、AI、开始练习和报告；可跳过，作答后自动消失。原型所有写入仍为本页内存演示，刷新后复位。R54 的练习/模考答案区含单位/容差数值输入和逐空输入演练；判分与生产结构化答案规则镜像。原型今日页周节奏在 `960px` 以下堆叠，近七天日期和星期随本机日历滚动；正常态仅为固定合成样例，空态明确演示零记录。原型容器断点为 `1119px`、`960px`、`759px`、`359px`，评审外框另有 `850px` 媒体断点；生产 Rail 在 `760–1119px` 使用图标式侧栏、`<=759px` 切换为抽屉和底部任务栏，页面内容另有 `960px`、`820px`、`760px`、`720px`、`600px`、`480px` 等断点。状态与导航 smoke 覆盖首用引导、周卡窄屏、760/759px 边界、390px 截图和窄面板几何；两套整体布局仍未逐档截图比对。

原型页面函数包括 `today`、`bank`、`studio`、`manual`、`aiPage`、`importPage`、`materialPage`、`practice`、`mockSetup`、`mockPage`、`results`、`report`、`settings`、`onboarding`。状态选择器有全局场景和页面专有场景；页面入口映射及未镜像的功能边界见 [DELIVERY](DELIVERY.md) 第 3 节。原型脚本 smoke 应验证状态选择能导航到正确任务面，不能只断言页面选择器存在。

R54 报告页头和“报告范围与证据”弹窗分别说明日期范围、当前题库与全局指标的口径；今日战报入口常驻显示当前库今日作答范围及“原型不写入”边界。日期选择只改变示例摘要，图表仍是固定样例。原型以 `smoke-report-scope.mjs` 验证这些说明，并在 320px 检查 KPI 数值不换行。生产周对比固定按当前自然周和上一自然周计算，且明确说明不受日期范围筛选影响。

## 7. 维护规则

添加页面、共享控件或新状态时，同一提交应同时更新：

1. 本清单的参数和状态表；
2. `design/prototype-r54/` 的对应状态或控件演练（若它是用户可见行为）；
3. `docs/DELIVERY.md` 的映射、限制和验证命令；
4. 中文/英文 i18n 字典、CHANGELOG 和必要的真机冒烟步骤。

只有源码 handler、自动化测试或真实思源走查能证明功能完成；原型点击、静态截图和“按钮看起来可用”不构成完成证据。
