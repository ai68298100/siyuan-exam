# 小驴考试 · 视觉设计规范

> 配套：高保真原型 [design/prototype/index.html](../design/prototype/index.html)（v3 全量 14 屏 + 组件库 UI Kit + 深浅双主题）；结构线框见 [docs/11](11-UI原型与交互规范.md)（信息架构真相源不变，本规范是其视觉层）。
> 硬约束：实装时所有 token 映射思源 b3 CSS 变量（亮暗主题自动适配），禁止硬编码色值——下文每个 token 都给出 b3 映射。

---

## 一、设计理念（参考系与取舍）

| 参考系统 | 借鉴什么 | 明确不借什么 |
|---|---|---|
| **Linear / Vercel（Geist）** | 中性面板 + 单一强调色的克制；数据密度下的秩序感（tabular-nums、1px 界线、微弱层阴影） | 极暗黑客风（思源是日间办公软件） |
| **shadcn / Radix** | 语义 token 分层（bg/surface/elev/border/text×3）；focus ring 规范；圆角体系 | 引入 React/无头组件栈（保持 Svelte + b3 原生类） |
| **Apple Fitness / Whoop** | 进度环（今日任务/分数主环）；大数字 + 小标签的层级 | 运动手表式重图表风 |
| **Duolingo** | streak/连胜的情绪化表达（🔥徽章、里程碑）；超大可点自评按钮 | 卡通拟物与强游戏化（工具调性优先） |
| **Things 3 / Arc** | 舒适留白与呼吸感；柔和大圆角；无噪声的沉浸态（背诵模式） | 全屏毛玻璃堆叠（性能与思源窗体内嵌限制） |
| **Notion / 反链面板** | 树-列表-详情三栏的密度与悬停反馈 | 弱层级灰字泛滥（保持三档文字对比） |

**一句话：安静的中性画布，让"题面"当主角；科技感来自数据可视化的发光强调，而非界面装饰。**

## 二、Token 系统

### 2.1 颜色（原型值 → b3 映射）

| Token | 亮色 | 暗色 | 实装映射 |
|---|---|---|---|
| `--bg` | #f5f6f8 | #0d0f13 | `var(--b3-theme-background)` |
| `--surface`（卡片） | #fff | #15181e | `var(--b3-theme-surface)` |
| `--elev`（浮层/沉浸） | #fff | #1c212a | `var(--b3-theme-surface)` + 边框提亮 |
| `--border` | #e6e9ef | #252a34 | `var(--b3-border-color)` |
| `--text` / `--text-2` / `--text-3` | #171b22 / #4d5665 / #8b93a2 | #e8ebf1 / #a6aebc / #697181 | `--b3-theme-on-background` × 透明度 100/70/45% |
| `--accent`（品牌靛蓝） | #5458e8 | #8a8df6 | `var(--b3-theme-primary)`——**跟随用户主题**，原型靛蓝仅为展示基调 |
| `--accent-soft` | 9% 透明 | 14% 透明 | `color-mix(in srgb, var(--b3-theme-primary) 10%, transparent)` |
| `--green/-red/-amber` | 语义色 | 提亮版 | `--b3-theme-success/-error/-warning`（存在即用，缺省回退上表值） |
| 渐变 `--accent-grad` | 135° 主色→偏紫 | 同 | 主色到 `--b3-theme-primary-light`（思源无则取 hover 提亮） |

规则：语义色只用于**状态**（对/错/警告/冲刺），强调色只用于**可交互与数据强调**；一屏内发光（glow）至多两处。

### 2.2 字体与字号

- 字族：系统栈（SF Pro / Segoe UI Variable / PingFang SC / 雅黑），不引外部字体；等宽仅用于计时器与题目 ID（`--mono`）。
- 阶梯：页面标题 17/700 · 卡片标题 14.5/650 · **题干 16.5/1.75（全应用最大正文字号，题面是主角）** · 正文 14 · 辅助 12.5-13 · 大数字 24-44/750+`tabular-nums`。
- 可访问性：题干字号独立滑杆 14-28px（覆盖题干档），其余 UI 不缩放。

### 2.3 空间 / 圆角 / 阴影

- 8pt 网格：间距 4/8/12/16/20/24/32；卡片内边距 20-24。
- 圆角：控件 8-10 · 卡片 12-16 · 沉浸容器 20；按钮胶囊只用于徽章 chip。
- 阴影两级：`--sh-1`（静态卡）与 `--sh-2`（悬停/浮层）；发光 `--glow` 仅主按钮/焦点/主进度环。

### 2.4 动效

- 时长：微交互 150-160ms · 视图切换 260ms · 均为 ease-out；位移 ≤6px（hover 抬升 2-3px）。
- 数据入场：进度环/条形用 stroke-dashoffset / width 过渡 400ms。
- `prefers-reduced-motion: reduce` 全量关闭（原型已实现，实装沿用）。

## 四、沉浸态规范（背诵模式 = 品牌时刻）

- 背景：深色基底 + 双径向 accent 光晕（右上主光 + 左下辅光）；浅色主题下同样使用深色沉浸（全屏专注的心智），文字反白。
- 层级：顶部元信息（压力/冲刺/组进度点）→ 大字号题面 → 提示链（虚线框，点击展开）→ 白色"翻开答案"主按钮 → 答案卡（①②③ 分点，关键词 accent 高亮）→ 四级自评。
- 该屏是"科技感+舒适感"的集中表达：光晕、留白、居中单列、无多余控件。

## 五、实装注意事项（Svelte/b3）

1. 组件类优先：按钮/输入/开关用 `.b3-button/.b3-text-field/.b3-switch` 打底，再叠本规范的间距与圆角覆盖类；自定义类一律 `lv-*` 前缀。
2. 颜色零硬编码：原型 token 表按 §2.1 映射进 `src/index.scss` 的 `:root`，全部取自 b3 变量或其 color-mix。
3. 图表自绘 SVG（环/条/雷达/热力），不引图表库；数据入场动画复用 §2.4 参数。
4. 背诵沉浸层用 `position:fixed` 覆盖层实现（思源 UI 完全遮蔽），主题变量在沉浸层内固定为反白组。
5. 移动端：≤960px 全部单列（原型媒体查询已给断点）；触达目标 ≥44px。

## 六、v2 质感与灵动增补（2026-10-01）

原型升级为 v2（`design/prototype/index.html`），在 v1 之上新增两组手法：

### 6.1 质感（Texture）

| 手法 | 实现 | 用在哪 |
|---|---|---|
| **渐变发丝边框** | 1px padding + mask-composite 渐变描边（`.hairline`） | hero 卡、沉浸层 |
| **噪点纹理** | 内联 SVG feTurbulence data-URI，opacity 3.5-5% | 沉浸层、大面板（消除大面积纯色的"塑料感"） |
| **三层阴影体系** | `--sh-1`（静）/`--sh-2`（悬停）/`--sh-pop`（沉浸/浮层），ambient+key 双层叠加 | 全局 |
| **统一图标体系** | 全部 emoji 换成内联 SVG symbol（stroke 1.7 圆头，currentColor），含小驴品牌标 | 全局 |
| **渐变大数字** | 分数主环中心 44px 数字用 accent-grad background-clip:text | S7 |
| **着色中性色** | 背景加两层 3-5% accent 径向 tint，替代纯灰 | body |

### 6.2 灵动感（Motion）

| 手法 | 实现 | 用在哪 |
|---|---|---|
| **交错入场** | `.stagger>*` rise 动画 + `--i` 自定义属性延迟（55ms 步进），每次切屏重触发 | 模式卡片/KPI/侧栏/树/列表 |
| **进度环绘制** | stroke-dashoffset 关键帧 `340→var(--off)`，切屏重放 | 今日任务双环、分数主环 |
| **数字滚动** | data-count + rAF 三次缓出计数（900ms） | KPI、分数、预测 |
| **条形生长** | scaleX(0→1) 带逐行延迟 | 三线对比/模块用时/掌握度/置信度 |
| **滑块分段控件** | `.seg .thumb` 弹性缓动跟随（spring 曲线） | 刷题/浏览、做题/背题、报告粒度、质量档位 |
| **走秒计时器** | 背诵计时真实倒计时，≤10s 变红 + 脉冲，归零显示"超时·已计模糊" | S4 |
| **呼吸光晕** | 品牌标 box-shadow 5.5s 缓慢脉动；hero 光斑 9s 漂移 | 顶栏/入口页 |
| **热力图悬停** | 单元格 scale 1.5 + title 提示（第 N 周 · N 题） | S8 |
| **微交互细节** | 按钮 active 缩放 0.975、选项 hover 右移 3px、对错图标浮现、树 hover 位移、sheen 扫光进度条 | 全局 |

动效总预算：单屏入场动画 ≤8 个元素交错、时长 0.5s 内完成；所有动效尊重 `prefers-reduced-motion`；实装时若在移动端掉帧，优先降级交错入场与呼吸光晕（保数据动画）。
