# ADR 0003 — 刷题/背诵/闪卡三形态共用一个调度器

日期：2026-10-02 ｜ 状态：已接受 ｜ 关联：docs/02 附录 A、research/03·04

## 背景
粉笔式刷题（外部判分）与 Anki 式闪卡（内部自评）在竞品中是两套并行系统，导致"题库一套进度、闪卡一套进度"的认知分裂。思源内核已有 FSRS（riff），但只服务块卡。

## 决策
1. 同一道题三种形态：**选择题（判分）→ 翻卡背诵（四级自评）→ FSRS 闪卡**，共用同一掌握度语义与 attempt 流水（kind 区分）。
2. 升降级规则：错 ≥2 降背诵并转卡；背诵 4 连"会"毕业出清背诵池；错题连对 2 次消灭（错题本出清 ≠ 停止记忆，FSRS 继续调度）。
3. 调度全走内核 riff（建卡/到期/评级），插件不自持久化 FSRS 状态；前端 ts-fsrs 仅做统计估算。
4. cram 队列永不写回调度（Anki reschedule-off 语义）。

## 后果
- 对用户只讲一个词"掌握度"；错题本=待消灭清单，闪卡=长期记忆。
- riff 端点未文档化 → 收口在 kernel/client.ts 单文件，rating 数值语义（0-3）待真机复核（27 组）。
