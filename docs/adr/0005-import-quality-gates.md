# ADR 0005 — 导入管线的质量门禁（绝不整批失败）

日期：2026-10-02 ｜ 状态：已接受 ｜ 关联：docs/02、research/02（考试宝范式）、research/07

## 背景
导入是产品成败的第一闸门。竞品用户口口相传的痛点是"一行错、整批死"和"系统猜格式"。

## 决策
1. **管线五段固定**：映射（列↔字段，可保存复用）→ 净化（合并单元格/全角/换行）→ 逐题校验 → 去重（题干 hash）→ 预览入库；每段可单独失败不阻断后续。
2. **错误行=数据**：每行错误记录 行号/原因/原值 三元组进错误清单，可单行修改后重试；跳过行也计数展示。
3. **答案规范化单一真相源**：`normalizeAnswer` 同时服务导入、判分、导出——任何一端改规则三端同步。
4. **先导 5 行**是一等按钮：用户可在全量前小步验证映射。

## 后果
- 坏数据永不进库（未通过的题根本不存在），错题本/统计的数据质量由导入端保证。
- 代价：复杂格式（材料组嵌套、图片公式）需逐个支持，QTI 等标准后置。
