# ADR 0002 — 题库块原生 + 作答流水设备分片

日期：2026-10-02 ｜ 状态：已接受 ｜ 关联：docs/02、docs/14 §五

> **v0.5.1 实施状态复核（2026-10-02）**：本 ADR 描述目标方案。当前 `app.ts` / `AttemptLog` 仍将完整事件数组写入单个 `attempts/log.json`，未实施设备/月 JSONL 分片、分片枚举与跨设备并集。已有 eid/device/seq 只提供事件身份；保存竞态、卸载清标记与存储响应确认仍待 TODO 37-01–04 验收。设备分片也不能自动解决同设备多窗口并发。

## 背景
题库存储两个候选：插件私有 JSON（Quizlet 式，锁数据）vs 思源块（用户可见可检索可同步）。作答流水若放 petal 单文件，多端同步整文件覆盖会互相吞数据（评审 P0 发现）。

## 决策
1. **题源 = 块 + `exam-*` IAL**（存储实测为 `custom-exam-*` 前缀），稳定 `exam-id` 做 diff/重连键。
2. **作答流水 = append-only 事件**，按 `月份.设备ID` 分片落 petal；多端只追加各自分片，同步合并即并集。
3. **派生视图（错题本/统计）= 本地缓存**，从全部分片幂等重算（event_id 去重、坏行跳过、时钟回拨计数），可随时重建——同步的真相只有不可变流水。

## 后果
- 题库获得搜索/双链/版本历史/`.sy.zip` 分享（竞品要自建知识库才有的能力）。
- 目标分片可隔离不同设备写入；同设备多窗口仍需协调。重算器输入随设备数增长，真实规模基准见 TODO 42-01。
- `loadData` 带 `/` 的 key 的子目录语义仍待真机确认（27 组）。
