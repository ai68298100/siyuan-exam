# ADR 0006 — 题库包 = 思源原生 .sy.zip + exam-id diff

日期：2026-10-02 ｜ 状态：已接受 ｜ 关联：docs/02 §2.3、TODO 7.0、research/03（Anki guid）

> **v0.5.1 实施状态复核（2026-10-02）**：原生导出已有既往预检记录。插件导入当前发送 JSON `{path}`，与官方 v3.8.5 Multipart 上传契约不一致，成功分支也未重建/持久化题库注册；`diffBank` 仅为领域函数及测试。导入、升级/克隆身份与冲突界面均须按 TODO 38-05/06 验收，本 ADR 的目标流程尚未完整实施。

## 背景
题库包分享有两种路线：自定义打包格式（manifest+JSON，需自研导入器与媒体管理）vs 思源原生 `.sy.zip`（原生导出已有预检，导入协议与完整旅程需补测）。

## 决策
1. **包格式 = 思源原生 `.sy.zip`**（内核 `exportNotebookSY` 导出；导入需按包种类核对 `importSY` / `importSYNotebook` 的上传/目标参数）——复用原生块结构/属性/媒体；卡片归属与浏览器上传能力需实测。
2. **版本化按 `exam-id` diff**：`diffBank` 四分类（新增/更新/移除/未变）供导入前后对比；完整修订指纹判内容变更。当前题干/选项去重 hash 不覆盖答案/解析/分值，不能直接验收版本修订。
3. **冲突策略**：同 exam-id 且内容有修订 → 保留用户版本（含其作答流水关联），导入版可选覆盖。
4. manifest/changelog 以笔记本文档形式随包携带（首页文档），不引入自定义二进制段。

## 后果
- 学生侧"导入即得"，作答流水按 exam-id 与原题重连。
- 代价：diff 预览需导入后才能精确执行（zip 内块解析需 jszip 决策，TODO 已列）；跨版本幂等依赖导入者不改动 exam-id。
