# ADR 0009 — 模考运行快照与幂等交卷

日期：2026-10-03 ｜ 状态：已接受 ｜ 关联：docs/19 Q4、docs/21 U18–U20、TODO 40-04

## 背景
v0.5.x 的模考会话只存在于内存：关页/休眠即丢卷；成绩记录以蓝图 id 为身份，同蓝图多次考试互相混淆；自动交卷计时器与手动交卷按钮可能竞态双写流水。

## 决策
1. **runId 与蓝图 id 分离**（`r-…`）：作答事件 `examId`、成绩记录 `runId` 均指向运行实例；蓝图可复用而历史互不覆盖。
2. **运行快照可序列化**：开考冻结蓝图与卷面顺序；答案/标旗/游标/分段起始/逐题驻留（dwell）3 秒节流落盘。恢复按 wall clock 计算剩余时间（休眠不清零），卷面缺失题如实剔除并提示，不用其他题顶替。
3. **交卷幂等**：`submitting` 状态 + `session.submitted` 双守卫，双击/计时器竞态只写一次流水；过期恢复仅自动交卷一次；交卷回执落定后才清除快照；未答题落 `not_attempted` 审计事件（重算器跳过，不进统计分母）。

## 后果
- 模考中断恢复达到 U19/U20 的本机单端语义；跨端恢复（37-04）与后台暂停政策定案仍开放。
- 逐题驻留替代固定 +500ms，成绩单"模块用时"成为真实测量值。
- `deleteBlock` 类内核写行为虽未用于本 ADR，快照恢复依赖题库可读：题库不可读时不给恢复入口（离线守卫）。
