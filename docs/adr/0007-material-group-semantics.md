# ADR 0007 — 材料组自动分组语义（导入器）

日期：2026-10-02 ｜ 状态：已接受 ｜ 关联：docs/15、core/importer/pipeline.ts

## 背景
医考材料组（共用题干）在 Excel 中的分组方式需要确定且可预测。候选：显式组 ID 列 vs 材料行后自动跟随。

## 决策
**自动跟随 + 考点闭合**：
1. `材料` 题型行开启新组（生成组 ID）；
2. 其后**考点为空**或**与材料考点相同**的行自动入组；
3. 出现**不同考点**的行即出组（组闭合）；
4. 出组后需新材料行才再开组。

## 后果
- 用户无需填组 ID 列，材料+子题按自然顺序排列即可。
- 代价：同材料组后紧跟另一个同考点独立题会被误入组——规避方式是给独立题写不同考点（与医考真实数据形态一致）。
- 显式组 ID 列留作未来升级（若出现大量误分组反馈再评估）。
