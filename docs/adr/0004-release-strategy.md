# ADR 0004 — 发布策略：GitHub 先行，集市设门槛后置

日期：2026-10-02 ｜ 状态：已接受 ｜ 关联：TODO 7A/7B

## 背景
集市上架会带来用户期待与维护承诺；而纵切未真机验收前扩大曝光有口碑风险。仓库公开（GitHub Release 手动安装）则成本低、可回撤。

## 决策
1. **GitHub 公开先行**（用户 2026-10-02 授权，实际 v0.1 纵切后即执行）：Release 提供 package.zip 手动安装；小范围 beta 邀请反馈。
2. **集市上架后置**，四道门槛全过才开 PR：内测 ≥3 人用满 2 周无 P0、PRD 验收 1-5 通过、文档含隐私/AI 数据流声明、TODO第7.0组约定功能补齐；按已收敛的公开旅程验收，不扩义为620条候选全部完成。
3. 每个公开版本先过本地四道门禁（类型/架构/i18n/构建白名单）。

## 后果
- 反馈驱动迭代，避免集市差评首因效应；代价是早期用户需手动安装（文档化缓解）。
- 门槛制把"何时上架"从时间决策转为证据决策。

## 2026-10-02 范围澄清

集市暂缓及7B既有四项门槛保留。当前工作包、阶段与本次开放入口的验收关系见[docs/19](../19-待办融合与分阶段执行规划.md)；GitHub已有Release不等于人工内测或集市门槛已通过。此澄清只调整规划。
