# ADR 0008 — 挑战码友谊赛模式（含答案编码）

日期：2026-10-02 ｜ 状态：已接受 ｜ 关联：core/challenge.ts、TODO v1.x

## 背景
挑战码 PK 有两种路线：异步答案回传（出题人保留答案，受卷方提交答案串由出题人判分）vs 友谊赛完整编码（答案随包，双方本地判分）。

## 决策
**友谊赛完整编码**（`encodeChallengeCopy`）：答案随包编码，双方本地均可正常判分练习。理由：异步回传需要出题人在线判分+回传成绩，流程重且依赖出题人及时响应；友谊赛场景双方自律即可。

## 后果
- 双方体验一致（同一套练习/判分 UI），无需"等出题人判分"的异步等待。
- 代价：理论上可作弊（看答案），友谊赛场景可接受。
- 异步回传模式（`compareAnswers`）保留为纯函数，未来如需竞技排行可启用。
