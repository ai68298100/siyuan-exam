# ADR 0001 — AI 双通道：思源内置优先，BYO 端点为高级选项

日期：2026-10-02 ｜ 状态：已接受 ｜ 关联：docs/03 决策 #3、research/06

## 背景
AI 出题/讲解需要模型访问。云 AI 工具（Monic.ai 等）两年即停服且数据被锁；思源 3.8 已内置 AI 配置与 `/api/ai/chatGPT` 端点（实测存在）。

## 决策
默认通道 = 思源内置 AI（内核代理，零配置、无 CORS、无 key 管理）；高级通道 = OpenAI 兼容端点（BYO key，仅存本地插件数据，供独立模型/温度/批处理控制）。两通道实现同一 `AiChannel` 接口，管线不感知。

## 后果
- 用户开箱即用（前提：思源里配过模型）；多 provider 支持只需扩展 OpenAiChannel 预设。
- chatGPT 端点为单轮 msg 语义 → 多消息拼接为 `[指令]+正文`，牺牲对话历史换取简单（若需多轮改用 agent 端点族）。
- key 迁移到 `getSecret` 密钥链仍为 TODO（26.2 P1）。
