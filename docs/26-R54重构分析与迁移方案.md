# 小驴考试 · R54 重构分析与迁移方案

> 日期：2026-10-11；核查基线：本机小驴考试 v0.9.6 及当前工作区。
>
> 本轮设计预览预期位于 [`design/prototype-r54/index.html`](../design/prototype-r54/index.html)。它使用合成数据演练页面与交互，不连接思源、不调用模型、不写入题库、作答或成绩。生产页面尚未按本方案迁移；原型可点击不代表真实业务已接通。
>
> 本文是设计与迁移提案，不调整版本、发布状态或既有待办的完成标记。旧生产设计依据仍是 [`design/DESIGN-SPEC.md`](../design/DESIGN-SPEC.md)、[`docs/11-UI原型与交互规范.md`](./11-UI原型与交互规范.md) 与 [`docs/22-v5视觉落地与增量验收.md`](./22-v5视觉落地与增量验收.md)，正式迁移后再更新其引用。

## 1. 重构目标与依据

用户指定的目标效果是本机小驴闪卡 R54 原型；实现组织参考小驴打卡。考试已经有建库、示例、导入、手工录题、AI 出题、资料笔记、练习、背诵、错题、模考和证据报告，重构重点是让这些能力按使用任务呈现。

新用户首先需要知道如何获得第一道可练的题；熟练用户首先需要继续现场或开始今天的学习。题库维护、参数设置和深入统计仍然可达，但不应与开始学习争夺同一层级。R54 的效果来自稳定导航、清楚的任务面、连续的返回路径与统一反馈，也来自淡紫画布、白色工作面、细描边和克制的暖色摘要。

闪卡与考试的业务重点不同。考试要保留客观题判分、填空规格、主观题边界、严格模考、卷面条件和独立作答证据；不复制闪卡的 FSRS 正式评分流程，也不把考试的背诵自评写成客观正确率。

## 3. 五项导航与完整能力映射

建议产品导航为 **今日 / 题库 / 出题 / 模考 / 复盘**。设置、帮助、命令面板属于辅助入口。五项导航是产品信息架构目标，不要求首阶段立即合并或替换三个宿主 Tab；既有 `openPractice`、`openMock`、`openReport`、命令和事件入口需通过适配继续工作。

| 主入口 | 首屏问题                 | 一个主动作                       | 二级承载                                                             |
| ------ | ------------------------ | -------------------------------- | -------------------------------------------------------------------- |
| 今日   | 现在先做什么？           | 继续本场 / 开始今日练习          | 当前题库、预计时间、今日进度、待重练摘要、最近学习；其他模式按需展开 |
| 题库   | 找到并整理哪些题？       | 打开题目 / 练习当前范围          | 全部题、错题、收藏；搜索筛选、详情检视、批量与维护                   |
| 出题   | 如何把材料变成可练的题？ | 保存题目 / 确认导入 / 审核后入库 | 手工、导入、AI、资料，按任务使用分面；无需 AI 即可完成手工闭环       |
| 模考   | 如何验证这次准备？       | 检查卷面并开始考试               | 蓝图与范围、时长、历史卷与成绩、考后估分                             |
| 复盘   | 哪些证据支持下一步？     | 重练薄弱范围 / 查看本场结果      | 概览、考点与错题、记录与证据、待行动；深层工具按需进入               |

## 4. 与 R54 的具体差距

| 当前考试实现                                                      | 用户感受与问题                           | R54 目标                                                         |
| ----------------------------------------------------------------- | ---------------------------------------- | ---------------------------------------------------------------- |
| Rail 同列三全局项和六工具项，首页再给模式卡与长工具区             | 同一入口多次出现，用户先看到工具集合     | 五个稳定任务入口；工具进入对应页面的分面，当前库与主动作稳定     |
| tokens 位于全局 `:root`，颜色直接引用 `--b3-*`                    | 不同宿主主题下无法稳定获得用户指定的效果 | 插件根限定的浅深色板；跟随思源只决定明暗，单独挂载面共享主题     |
| v6 主按钮渐变和彩色多层投影，可点卡片浮起                         | 强调较重，与 R54 平静工作面不一致        | 以平面操作色、细描边、明度与空间分层；普通卡悬停不位移           |
| 既有设计原型画布偏暖灰，生产随宿主主题；胶囊/分面和面板层级不统一 | 组件之间看起来来自不同阶段               | 淡紫画布、白面、淡紫次级面、暖色时间摘要；控件圆角与间距统一     |
| `@media` 与 Rail 的窗口宽度判断                                   | 思源分屏中的窄 Tab 仍可能保留桌面宽布局  | 插件容器断点；宽屏分栏，中屏收敛，窄屏单栏/Sheet/导航            |
| 手工录题只有长表单                                                | 用户保存前不能直观看到各题型实际作答效果 | 内容编辑与题面预览并置，窄屏为同一草稿的分面                     |
| AI 材料、参数、候选纵向顺排                                       | 材料、当前候选与审核动作间来回滚动       | 来源/候选/题面有明确工作面；批次归属常显，参数逐级展开           |
| 资料登记、元信息、搜索、笔记编辑混在同一纵向页面                  | 阅读、整理与出题的主次不清楚             | 连续资料列表＋详情阅读/笔记面，按对象进入上下文动作              |
| 题库行内展开编辑、修订与规格等                                    | 展开一个题打断列表，返回定位成本高       | 题目 Peek；窄屏 Sheet；关闭恢复搜索、选中、滚动和焦点            |
| 作答与背诵仍保留完整壳和顶部多项统计                              | 题面与无关状态竞争注意力                 | 专注上下文，仅保留范围、进度、来源、模式与退出；安全返回恢复现场 |
| 报告所有统计纵向堆叠                                              | 缺少先看事实、再看证据、最后行动的顺序   | 概览/考点与错题/记录与证据分层，深指标按需进入                   |

### 4.1 视觉基座目标

以下为闪卡 R54 的目标语义值，供考试原型保持系列一致；迁入生产前需按具体文字与控件验证对比度。

| 语义          | 浅色                  | 深色                  | 使用边界                     |
| ------------- | --------------------- | --------------------- | ---------------------------- |
| 画布          | `#F7F7FC`             | `#141419`             | 插件工作区背景               |
| 工作面        | `#FFFFFF`             | `#1D1E24`             | 题面、列表、表单             |
| 次级面        | `#EFF0FA`             | `#26272F`             | 分组、预览、解释             |
| 描边          | `#E4E6F4`             | `#2C2D38`             | 边界；状态另有文字与图形     |
| 正文/辅助     | `#2A2B35` / `#63657A` | `#EFEFF6` / `#9FA0AC` | 中文可读性优先               |
| 主操作/浅底   | `#5B65E8` / `#EAE6FF` | `#8B93F8` / `#2B2C44` | 主动作、选中与焦点           |
| 节奏暖色/浅底 | `#F6A94B` / `#FFF1D9` | `#F6B04E` / `#38301F` | 时间与温和摘要，不代替错误态 |

建议字体使用系统中文无衬线栈；标题 24–28px、正文 14px/22px、题面 20–22px/1.7、辅助 12px/18px，数字等宽。间距使用 4/8/12/16/24/32px；小控件圆角 8–10px、列表行 12px、卡片 16–18px、浮层约 22px。装饰仅用于今日、首用与结果，题面、题库和出题工作面优先内容。

样式按 `tokens → primitives → layouts → pages` 分层。迁移需要同步调整现有样式检查和正式规范，不能在仍要求全局 `--b3-*` 的旧规则下不断追加高优先级覆写。

## 6. 跨页面与状态契约

1. **返回保留现场**：题库 → 题目详情 → 练习 → 结果 → 返回，应恢复题库、查询、筛选、选中、滚动和焦点。资料 → AI 返回后保留同一材料及草稿。
2. **请求冻结归属**：导入、AI 批次、手工保存、笔记、练习与成绩的目标库/对象/材料在操作开始时固定；换页、换库和迟到结果不能改写归属。
3. **实际回执再成功**：处理时锁定关联动作，实际保存后才显示成功；失败保留输入和可恢复入口。部分成功逐项区分，成功项不重复写入。
4. **同一对象多处呈现**：新增题目更新今日和题库；作答更新结果、错题和报告；不在页面维护第二套题目、统计或审核状态。
5. **范围和口径就近可见**：当前库、本场、历史累计、日期窗口、独立/受助、自评/客观分值不能依靠颜色或页头一个标签含混表达。
6. **首用与能力回退**：无题库、空题库、筛选无结果、无错题、无记录、未配置 AI、离线和只读分别解释原因与可做的下一步；只有依赖能力的动作禁用。
7. **键盘等价**：命令面板、选项、提交、翻题、背诵评分、Esc/返回与焦点归还继续可用；输入法、编辑字段、宿主编辑器和后台 Tab 不响应作答快捷键。
8. **原型诚实反馈**：所有模拟写入使用“仅预览，未写入”等回执；没有演练动作的入口明确标为设计预览。正式按钮必须有入口、前置条件、范围、处理中、成功、失败和返回点。

## 7. 响应式与宿主形态

使用插件容器宽度决定布局。验收起点可采用：≥1120px 完整侧栏和工作分栏；760–1119px 收敛侧栏与详情；480–759px 单栏和窄屏导航；<480px 紧凑任务切换。最终以实际中文、题型和宿主分屏验证调整，不以窗口宽度替代。

Tab 承载完整工作台。窄 Dock 以今日最小任务和继续学习为主，复杂出题与维护进入 Tab。作答/模考进入专注上下文，返回恢复原导航。Sheet、底栏、安全区与输入法不得遮挡提交、评分、交卷或保存动作。

每页优先一个主滚动区；必要的候选列表、详情和答题卡有清楚的局部滚动边界。桌面密集控件至少 36–40px，触控目标至少 44px；窄屏背诵评分采用 2×2。字体放大、长题干、多空题、共享材料和低高度下，题面与主动作均可到达。
