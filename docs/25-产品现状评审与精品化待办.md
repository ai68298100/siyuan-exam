## 2. 已交付能力评审

### 2.1 核心学习闭环：接近可用

已具备：建库、手工录题、XLSX/XLS/CSV/TSV/GIFT/Aiken/原生包输入；试导、映射、去重、更新、回读；练习会话恢复、先回忆、逐层提示、多选、键盘和受助记录；错题处置、错因与复盘；模考快照、真实驻留计时、交卷审计、蓝图短缺和成绩导出；报告、延迟独立回忆、信心校准；资料登记、定位、笔记、题目关联；考纲覆盖、缺口和勘误；打印题册/答案册/答题卡与纸笔回录；FSRS 连接和 AI 闪卡候选。

核心风险是“写入结果未知”“重载后仍在”“跨窗口不串库”“受助与独立口径不混算”仍需要在真实宿主中持续验收。所有入口都要保留失败回执和手工恢复路径。

### 2.2 AI：管道已成形，产品效果未证明

运行时任务信封中目前有 7 个讲解类模板：hint、Socratic、explain、misdiagnosis、report explanation、next action、flashcard candidate；另有生成/复核/修复管线。任务上下文指纹、预算、strict mock、审计和待审核队列已存在。

仍需验证：实际端点的取消与迟到结果、发送前内容预览、来源/版权提醒、费用与 token 反馈、模型质量、低配置降级、候选修改后的应用/撤销，以及普通 UI 与思源智能体入口的一致性。文档和宣传不得把 docs/18 的 13 个计划模板目录当成 13 个已接入模板。

### 2.3 UI 与交互：实现面大，验证面薄

PracticeTab 已承担入口、会话、浏览、导入、背诵、资料和 AI 等多种状态，功能丰富但文件过大、状态耦合较重；当前没有 Svelte 组件级自动回归测试。侧栏布局已有基础键盘切换，但需要完整的 tab/tabpanel 关系、方向键/Home/End、焦点回收和懒挂载。

移动端还要特别验证 `window.open`、打印弹窗、文件下载、剪贴板、全屏和拖放在 Android SiYuan WebView 的降级路径；浏览器响应式截图不能作为移动端验收证据。

### 2.4 工程与发布：基础扎实，发布链仍有断点

> 2026-10-05 更新（v0.7.1/0.7.2 发版后）：本节所述 release 断点已收口——tag 发布现执行 guard + build + verify:package + release:check 并附 SHA256SUMS（P0-04 ✓）；冒烟脚本硬编码 token/workspace 已移除，改 SIYUAN_TOKEN/SIYUAN_WORKSPACE（P0-06 ✓）；v0.7.1 首次 tag 发布即被链接审计拦下 docs/13 引用 gitignore 目录的问题，修复后 CI 全绿发版，门禁有效。新增遗留：`pnpm smoke` 编排曾引用缺失的 perf:bank script（已修）；CI 与本地唯一的假绿源=gitignore 内文件被文档引用，已以截图入库（design/playwright）消除。

当前 `check.yml` 会执行 lint、check、test、build、verify；tag 发布的 `release.yml` 仍需要补齐 guard、release-check、verify-package、产物哈希和安装后检查。`pnpm format:check` 当前会报告约 140 个文件，需先明确格式化范围，不宜无差别改写全部历史文档。

构建还有 8 条 `INEFFECTIVE_DYNAMIC_IMPORT` 警告；它们不阻断构建，但应清理或在门禁中明确接受原因。冒烟脚本中的默认 token 和固定工作区路径也必须移除，避免把错误请求发往错误工作区或在其他机器上产生假绿结果。

### 2.5 品牌与公开信息：可发布，转化力不足

`icon.png` 清楚但识别度偏通用；`preview.png` 更像线框占位图。GitHub 需要真实的桌面、窄屏、导入、练习、模考报告截图和一段短演示，所有示例标注“原创/示例数据”。README 英文版、CHANGELOG、plugin.json 和开发说明存在测试数、pnpm 版本、原型屏数、AI 模板数和 Anki/apkg 宣传漂移，应先统一事实。

## 4. 每个待办的完成规则

1. 写明用户动作、最小范围、依赖、负责人、目标版本和证据位置。
2. 同时记录源码、离线测试、真实内核、宿主 UI 和公开宣传五种状态；任何一层未验都不能写成“全面支持”。
3. 真实内容使用原创或明确获准的 fixture；不把购买、免费访问或 AI 改写当成公开分发许可。
4. 失败路径必须有用户可执行的恢复动作：重试、导出、手工继续、回滚或清理；“静默忽略”只能用于明确的可选生态桥。
5. 每次发版后更新本文、docs/23 和 docs/24；历史批次只保留为证据，不覆盖当前状态。
