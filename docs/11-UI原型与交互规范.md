## S2 · 刷题会话 · 单题作答与反馈（练习态）

```
┌──────────────────────────────────────────────────────────────┐
│ ← 结束练习   专项·资料分析  [做题⇄背题]  ◔ 7/20  正确率 71% 🔥12│
├──────────────────────────────────────────────────────────────┤
│ 【单选 · 2023 国考 · ★★★】  题干块渲染（Lute DOM，公式/图）   │
│                                                              │
│ ┌ 选项 ────────────────────────────────────────────────────┐ │
│ │ ( ) A  ……                                                │ │
│ │ ( ) B  ……                                                │ │
│ │ ( ) C  ……                                                │ │
│ │ ( ) D  ……                                                │ │
│ └──────────────────────────────────────────────────────────┘ │
│ [F 🚩标记] [E ⭐收藏] [📝 笔记] [🤖 问 AI]      [ 提交 ⏎ ]   │
├────────── 提交后（反馈态，同一屏展开）────────────────────────┤
│ ✅ 回答正确            或   ❌ 回答错误 · 正确答案 B          │
│ 解析区（默认遮罩 → 点击展开；模考态整段隐藏）                 │
│ 考点: 资料分析/增长率 → [跳转笔记] [查看同类题]               │
│ 错因标注（仅答错）: [粗心] [知识不会] [陷阱] [跳过]           │
│ 错题操作: [转为闪卡] [举一反三 ×3]                            │
│                                    [ 下一题 J / ⏎ ]          │
└──────────────────────────────────────────────────────────────┘
```

- 术语约定（R1）：单题级动作=「提交」；练习会话级结束=「结束练习」；模考会话级结束=「交卷」。左上角按钮点击弹确认（未答进度保留为可续做会话）。
- 做题/背题双模式：会话头部常驻切换（默认跟随设置），切换即时生效于后续题目，不改已答题。
- 作答态/反馈态同屏切换（不换页），反馈区从底部推入。
- 选项点击即选中（多选累积，判断题两钮）；键盘 A-F 直选、⏎ 提交、J 下一题。
- 判分后立即写 attempt 事件（会话内缓冲，批量落盘）。
- 背题模式：跳过作答态，直接进入反馈态（答案+解析全展开），顶部显示「背题模式」徽章与退出开关。
- 错因标注防疲劳（R2）：默认沿用该考点上一次的错因选择（显示为预选中，可改可跳过），避免每题重复三连问。

- **多题库并行**（R1）：题库=笔记本，顶部切换器在多个考试题库间切换；今日任务聚合所有启用题库（docs/10 §bank）。
- 左树三层折叠：章节（文档结构，兜底考点）；年份/标签视图切换同一列表。
- 过滤器 Chips：只看错题 / 只看未做 / 难度 / 题型 / 来源（真题|模拟）。
- 单题详情右侧栏由模块贡献（wrongbook/memory/ai 各塞一块）——扩展点。
- 「本视图开刷」把当前树节点+过滤器圈定的题集作为会话（查询圈题的同源逻辑）。

         ┌ 题干←C  选项A←D  选项B←E … 答案←G  解析←H  章节←B  难度←I ┐
         [先导 5 行试试]
④ 预览   成功 497 · 待修 3（错误清单: 行号/原因/原值，可单行改）
         ┌ #42 多选: 答案"ABD"但 E 列缺该选项 → [改] [跳过] ┐
         随机抽查 10 题完整题面渲染

- 全程失败不整批：单题失败只进清单；「先导 5 行」在 ③ 任一时刻可用。
- 「+新建题库」内嵌守卫（R2）：目标下拉在任何入口（导入/表单/AI）无可用笔记本时出现，一键建笔记本+章节骨架后回到原流程。
- 映射可保存命名复用（按用户命名）；AI 识别通道复用第 ④⑤ 步（识别结果进同一预览流）。

- 重新生成单题只影响该题；经济档位隐藏二遍核验徽章。
- 生成中可随时取消（已完成的分片题目保留进待审核队列，R2）；「整个笔记本」来源超 200 块时提示按章节拆分生成（成本与质量双保险，对应 PRD 两段式生成）。
- 入库后题目进入浏览模式可再编辑（origin=ai 标记保留）。

### 响应式断点

- ≥1280px：S3 三栏全展开；S12 侧栏常驻。
- 960-1280px：S3 单题详情改抽屉；S12 改浮层。
- <960px / mobile：单列纵向；dock/蓝图/AI 出题入口隐藏；字号默认 18px。

### 无障碍

- 对比度遵循 b3 主题（≥4.5:1）；题干字号独立滑杆 14-28px；
- TTS 三形态（看题/看+读/纯听）纯听态隐藏题面仅留评分钮；
- 所有图标按钮带 aria-label / tooltip。
