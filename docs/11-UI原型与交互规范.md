## 1. 全局界面结构

主导航为 **首页 / 资料与题库 / 学习与复测 / 模考 / 证据与知识 / AI任务**。项目切换和设置常驻全局区域；窄屏以导航抽屉和就地返回入口呈现。

页面从上到下先回答“当前目标与状态”，再呈现内容，最后给一个明确主操作。内容区按任务使用题目、资料或证据；AI作为就地任务入口和共享任务中心存在。资料来源、版本、保存反馈与 AI 实际发送范围都可以展开核查，无需用户读取技术 schema。

```text
项目切换 · 六主域导航 · 设置
当前场景 / 来源路径                     当前条件 · 保存/任务状态
主内容：资料、题目或证据                  可收起的来源/笔记/AI区
主操作                                  返回来源 · 保留草稿
```

各场景保留来源、筛选、页/时间点、会话和草稿的返回上下文。切页不会自动提交、揭示、批准或应用。原型演示的成功状态统一标注“模拟”；实际产品只有收到对应回执才能显示已保存或已应用。

## 2. 场景规格

### home · 项目首页

原型：[home](../design/prototype/index.html#home)。

| 项目 | 规范 |
|---|---|
| 目的与主操作 | 显示当前项目、考试目标、继续上次、待复测及待审任务。主操作优先“继续上次”；首次使用选择“建立项目”或原创演示。今日任务可查看理由、调整或暂缓。 |
| 状态 | 无项目显示简短引导；无新记录显示可选下一步；有未保存会话显示恢复入口；离线区分本地可继续与外部原件暂不可访问。 |

| AI输入与边界 | 用户申请“帮我选下一步”时发送所选项目、可用分钟和必要的本地证据摘要，展示缺失项。建议可改写；不预测正式通过率，不代替用户开始会话。 |

## 3. 共享状态与动作词

| 状态/动作 | 面向用户的表达与行为 |
|---|---|
| 未保存 / 保存中 / 已保存 | 已保存必须对应确认回执；失败保留输入及恢复动作。演示显示“模拟已保存”。 |
| 提交本题 / 结束练习 / 交卷 | 区分题级与会话级作用域；结束和交卷说明未答、续做及计时影响。 |
| 请求提示 / 正式揭示 | 前者记录受助条件；后者明确会显示答案，strictMock禁止。 |
| 待补证据 / 待审阅 | 分别给补材料/简化任务与查看问题/人工判断入口，不能互相替代。 |
| 生成候选 / 批准 / 应用 | 模型输出、人工选择、实际写入分开；实际应用前重查版本、权限和模式。 |
| 取消 / 执行结果未知 | 取消停止本地后续步骤；未知先核对任务/回执，不自动重试收费或写入。 |
| 原件失效 / 需重定位 | 保留原版本和个人笔记，提供重选来源或手工位置，不伪造定位成功。 |
| 暂缓 / 归档 / 删除 | 分别说明队列、入口和内容影响；不能用隐藏入口代替删除确认。 |

加载、空、错误、部分成功、保存失败、权限/模式受限和离线是按真实能力选择的状态，不要求每个页面机械复制相同占位图。错误说明发生在哪一步、已保留什么和下一动作；全文件损坏可以终止导入，整批部分成功需展示真实入库数。

## 4. 键盘、焦点与返回

- 选项区使用radio/checkbox及清晰标签，多选保留完整勾选再提交；输入框、公式编辑、IME组合和AI对话获得焦点时暂停题目快捷键。
- 字母选项键仅在题目作答区有效，不与标记或收藏动作复用。提交、揭示与下一题各有独立状态条件；Enter不因弹窗或输入焦点误交卷。
- 对话框打开时聚焦标题或首个必要字段，Tab保持可达；确认或关闭后回到触发元素。提交成功后将反馈播报给读屏，再提供下一题；保存失败保留答案焦点。
- 返回操作恢复列表/题目/资料定位和未完成任务。真实数据冲突需重新确认目标；原型仅展示相应条件和状态。

## 5. 响应式与可访问性

宽屏可并排显示来源、作答和笔记；中屏先收起辅助区；窄屏使用单列、详情页面和抽屉。断点按容器宽度调整，参考1280/960/390px评审；屏幕宽度与移动平台能力分别判断。文件选择、系统打开、媒体控制或某插件接口不足时解释当前能力及替代路径，不将导入、模考或AI永久限定到桌面。

触控目标至少44px，主操作避开安全区和软键盘；200%缩放与长公式/中英混排保留内容可读性。交互状态同时使用文本/图标/形状，正文对比度满足4.5:1、必要大字及控件满足对应3:1要求；主题变量本身不等于已通过对比度检查。

题型有明确输入标签，必填和错误关系可被读屏理解；图表提供文本等价。声音、TTS、播放速度和动画由用户选择，`prefers-reduced-motion`下减少动效。媒体播放、字幕、提示及纯听方式造成的暴露条件需要记录；听过题不自动算完成。

## 6. 原型评审范围

评审使用原创讲义、3道单选/多选原创样例、一个模拟PDF页和一个模拟媒体片段。先走“查看/个人笔记”和“获准片段→候选审核→独立作答→复盘”两条路径，再演示严格模考禁用、保存失败、材料缺失、取消/迟到、版本冲突和移动返回。

原型中的页码、视频时间、模型任务、评分及保存回执都是演示状态；实际AI输入、宿主接口、文件打开、内核评级和跨端恢复仍须按 [docs/19](19-待办融合与分阶段执行规划.md) 对本次开放范围真实验收。15个场景和各工作包不会因原型完整而勾选完成。
