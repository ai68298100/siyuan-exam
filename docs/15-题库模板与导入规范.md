# 题库模板与导入规范（官方模板契约 v1）

> 本文是导入管线的**格式契约真相源**：Excel/CSV 列定义、材料组行规则、答案方言、估分答案串规范。
> 校验实现：`src/importer/pipeline.ts`（单测 `tests/importer.test.ts`）。

---

## 一、Excel/CSV 列契约（每行一题）

| 列名 | 必填 | 说明 |
|---|---|---|
| 题号 | - | 仅作参考，导入时忽略 |
| 题型 | ✅ | 单选/多选/判断/填空/简答/材料（别名见下） |
| 题干 | ✅ | 支持换行与 Markdown |
| 选项A~F | 按题型 | 单选/多选至少 2 项（A/B 必填，C-F 可空）；判断/填空/简答留空 |
| 答案 | ✅ | 单选=`B`；多选=连写 `ABD`（顺序无关）；判断=对/T/√/是；填空/简答=文本 |
| 解析 | - | 建议 ≥30 字含因果 |
| 难度 | - | 1-5（超范围自动钳制） |
| 知识点 | - | `/` 分层：`资料分析/增长率`；材料行写考点 → 组内子题沿用 |
| 分值 | - | 默认 1 |
| 来源 | - | `2023 国考 · 115 题`；配合"真题/模拟"标记 |

- **选项数不固定**：C-F 可整列留空；选项内不要含换行（用分号）。
- **判断题答案方言**：对/T/√/是/正确 均识别为"对"；错/F/×/否/错误 →"错"。
- **材料组**：一行 `材料` 题型开启新组，**其后不带知识点的行自动入组并沿用材料考点；考点与材料相同的行同样留在组内；带不同考点的行=独立题，结束该组**。

## 二、题型别名（题型列可写）

单选/单选题/single · 多选/多选题/multiple · 判断/判断题/judge/TrueFalse · 填空/填空题/fill · 简答/简答题/问答/论述/short · 材料/材料题/共用题干/material

## 三、Aiken 文本格式（粘贴导入）

```
// 注释行
题干（可多行）
KP: 考点/子考点
A. 选项甲
B. 选项乙
ANSWER: B

（空行分隔下一题）
```

规则：选项 `A-J` 连续；`ANSWER:` 必须存在且字母在选项范围内；`KP:` 可选。

## 四、估分答案串规范

- 两串等长、每字符一题；我的串中 `.` 或 `？` = 未作答。
- 全角自动折半角、大小写不敏感（判分方言同上）。
- 长度不齐按较短者计分。
- 题库模式：勾选后标准答案取自题库题目的 `exam-answer`（材料母块排除），顺序=浏览模式顺序。

## 五、导入行为承诺

1. 逐题校验：答案∈选项集、题型↔答案格式一致、题干非空——**失败行进清单，绝不整批失败**。
2. 去重：题干+选项指纹（空白/全角折叠后），批内+与库内既有题比对；重复计数不丢弃已有题。
3. 先导 5 行：一等按钮，成功再全量。
4. 错误清单：行号/原因/原值，可单行修改重试。
