# 小驴考试审计快照（2026-10-18）

## 结论

源码当前为 v0.10.4。入口已收敛为桌面端一个可见顶栏入口，点击固定进入小驴考试练习台主页面；模考、报告、错题和设置从主页面内部导航或命令进入。状态栏、错题 Dock、顶栏右键多入口和上次页面自动恢复已移除，避免宿主出现多个小驴考试按钮或启动在次级页面。

本轮修复了题目笔记 IAL/属性读回、收藏状态反转、AI 生成/拒绝项修复取消后的迟到结果与队列保留、应用未就绪时练习台空引用、宿主恢复页签 UUID 去重，以及修订恢复中的明确清空值与完整判分规格。新增 `TabAppRegistry` 按页签实例维护归属，避免销毁同类型的其他页签组件；4 项回归覆盖该问题。资料详情的“关联题数”改为响应式快照，新增关联、改链、解绑后资料列表和详情徽标即时刷新，并补齐 workflow 回归；外部命令、恢复页签和 app 尚未 ready 时直接进入资料页也会刷新资料快照；返回资料页时同步当前笔记缓存，资料被移除后关闭旧笔记抽屉并清空缓存。插件补齐 `border-box` 规则，使真实宿主主内容区域原有 44px 横向溢出降为 0，并去掉 harness 全局盒模型 reset，避免测试台掩盖生产漏项。补齐 `external-link` / `edit` 图标，不支持 Web Speech 时禁用朗读按钮；导入/资料文件选择改用可键盘触发的原生按钮，Studio 使用普通导航按钮和 `aria-current`，焦点样式限定在插件内。进一步修复初始化期间模考/报告命令被默认练习台覆盖、760–1119px 紧凑 Rail 快捷行动菜单被 `overflow:auto` 裁切，以及 ≤600px 背诵评分四列样式覆盖导致的横向溢出。

R54 的实现对照、无障碍与响应式检查，以及尚未接通的题目生命周期、完整来源证明、全部历史作答冻结修订与发布守卫见 [UI-AUDIT-2026-10-18](UI-AUDIT-2026-10-18.md)。
