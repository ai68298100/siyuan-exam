## 三、实装工作流（每屏五步）

1. **看线框**（docs/11 对应 S 节）确认信息架构与三态（加载/空/错误）要求；
2. **抄原型**（design/prototype 对应锚）取布局尺寸、色值 token、动效参数——CSS 类名从 `lv-base.scss` 取，缺的组件先进 UI Kit 页再消费；
3. **建组件**（src/ui/…）——props 契约按本册 §2.2，i18n 键按 `public/i18n` 扁平点号规范；
4. **过三态**——按 docs/11 每屏"状态设计"表逐格自测（含空态守卫文案）；
5. **对验收**——桌面+移动双端对照原型截图比对；动效对照 docs/12 §六参数表。
