## 一、存储分层总原则

| 层 | 存什么 | 放哪 | 为什么 |
|---|---|---|---|
| 题源层 | 题目本体（题干/选项/答案/解析/属性） | **思源块 + 块属性** | 免费获得搜索/双链/版本历史/同步/.sy.zip 分享；用户可见可改 |
| 事件层 | 作答流水（append-only 不可变） | 插件私有存储 `data/storage/petal/siyuan-exam/`（loadData/saveData，JSON 按月分片） | 不污染题源；统计与错题全部派生，永远可重算 |
| 派生层 | 错题本/掌握度/统计/ streak | 事件层的物化视图，随事件重算 | 避免"题库一套进度、闪卡一套进度"的状态分裂 |
| 调度层 | FSRS 记忆状态 | **思源内核 riff 库**（`/api/riff/*`） | 不重造调度；与思源内置闪卡互通 |
| 配置层 | 设置/模块开关/Prompt 模板/AI key | 插件 loadData + `localStorage`（轻量 UI 状态） | 随同步走 |

## 二、题目块契约（题源层）

### 2.1 块结构

一题 = 一个超级块（不换行风格可选）：

```markdown
{{{row
<!-- 块属性（思源 IAL，挂在超级块上）-->
{{{child
题干：思源笔记内核使用的闪卡调度算法是？
}}}
{{{child
- A. SM-2
- B. FSRS
- C. SuperMemo-5
}}}
{{{child
解析：思源 3.8 内核集成 go-fsrs v3……（可含图/公式/块引用）
}}}
}}}
{: exam-id="q-8f3a2c" exam-type="single" exam-answer="B"
   exam-difficulty="2" exam-score="2" exam-source="国考 2023 行测 115 题"
   exam-year="2023" exam-origin="imported" exam-batch="b20261001-01"
   exam-kp="闪卡/FSRS" exam-review="verified"}
```

### 2.2 块属性字段表（`exam-*` 命名空间，避免污染其他插件）

| 属性 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `exam-id` | ✅ | string | 稳定题目 ID（导入时生成，`q-` + 随机 6 位；更新按此 diff） |
| `exam-type` | ✅ | enum | `single`/`multiple`/`judge`/`fill`/`short`/`essay`/`material`(组)/`match` |
| `exam-answer` | ✅ | string | `B` / `ABD` / `对` / 文本（fill/short） |
| `exam-difficulty` | - | int 1-5 | 存星值，显示映射 易(1-2)/中(3)/难(4-5) |
| `exam-score` | - | number | 分值（模考评卷用，默认 1） |
| `exam-source` | - | string | 出处（"国考 2023 行测 115 题"） |
| `exam-year` | - | string | 年份（真题/模拟双视图依据，配合 `exam-source-kind`） |
| `exam-source-kind` | - | enum | `real`(真题)/`mock`(模拟)——组卷与统计区分，杜绝"组卷分虚高"混淆 |
| `exam-origin` | ✅ | enum | `imported`/`ai`/`manual` |
| `exam-batch` | - | string | 导入批次 ID（批量治理用） |
| `exam-kp` | - | string | 考点标签（分层级用 `/` 分隔："判断推理/逻辑判断/加强论证"） |
| `exam-review` | - | enum | `pending`/`verified`/`edited`/`rejected`（AI 题审核流状态机） |
| `exam-group` | - | string | 材料组 ID（共用题干题组的母块 id） |
| `exam-meta` | - | json | 扩展（AI 的 model/prompt_template/quality_score、置信度等） |

**红线**：题干/选项/解析正文**永远写在块内容里**（富文本、可含图片公式、可被思源检索），块属性只存元数据——对齐 Damophus"数据契约"与 Obsidian SR 的历史教训（不把数据塞进正文注释）。

### 2.3 题库包（.sy.zip）与版本化

- 导出：题库笔记本 → `.sy.zip`（思源原生格式），附 `manifest.json`（题库名/版本/作者/题目数/changelog）。
- 更新：按 `exam-id` diff → 输出"新增/修订/删除"三清单供确认；**用户作答流水按 exam-id 保留**（Anki guid 机制的思源版）。
- 接受侧流程（R2 优化补全）：导入题库包 → diff 预览三清单（新增/修订/删除）→ 用户勾选确认 → 应用；冲突题（本地已作答且内容有修订）保留用户版本并提示。

### 2.4 收藏与用户注释层（R1 优化补全）

**收藏**：题目块属性 `exam-fav="1"`——不进插件私有存储，而是落在块上：随思源同步天然多端一致、可被 SQL 检索（用户可自建查询嵌入块圈出全部收藏题）、取消收藏=删属性。

**用户注释（口诀 / 个人笔记 / AI 讲解存档）**：统一作为**题目块的子块**写入，子块挂属性 `exam-note-kind`：

```markdown
{{{child
★ 口诀：实践才落地
}}}
{: exam-note-kind="mnemonic"}   <!-- mnemonic=口诀 | note=个人笔记 | ai-explain=AI 讲解存档 -->
```

设计理由：注释跟随题目块获得同步/双链/搜索/版本历史，删除题目块时注释随之消失（符合直觉）；错题本视图与浏览模式侧栏通过子块遍历聚合展示。导出题库包时 `exam-note-kind="mnemonic"` 可选附带（调研 04 号"UGC 精益简化版"）。

**红线**：注释永远不写进插件私有存储——它是"可见可改"的学习内容，不是派生数据。



## 三、事件层（作答流水）

### 3.1 attempt 事件（append-only，按"月份.设备"分片）

```jsonc
// data/storage/petal/siyuan-exam/attempts/2026-10.d4f8a1.jsonl
// 分片名 = 月份 + 本机设备 ID（首次启动随机生成并持久化）
{"v":1,"ts":1791920400000,"qid":"q-8f3a2c","kind":"practice",   // practice|recite|mock|card
 "mode":"single",          // single|special|paper|wrong|fav|cram|daily
 "verdict":"wrong",        // correct|wrong
 "my_answer":"A",          // 作答快照（背题/闪卡为 null）
 "self_rating":null,       // 背诵/闪卡四级自评 1-4（1不会 2模糊 3会 4熟知）
 "time_ms":12400,
 "session_id":"s-20261001-01",
 "exam_id":"mock-20261001-01",  // 模考卷 id，练习为 null
 "queue":"normal"          // normal|wrong|cram
}
```

**同步与落盘规则**（设计评审修订，docs/05 速览 #1 / #6.3）：

1. **按设备分片**：petal 目录随思源同步走且整文件覆盖——各端只追加自己的 `月份.设备ID` 分片，同步合并后天然是全量并集，多端刷题互不覆盖。
2. **批量落盘**：saveData 是整文件读写，会话结束/面板切走/每 10 题/30 秒节流时一次性落盘，崩溃最多丢一组。
3. **只追加不修改**：错题本/掌握度/热力图/streak 全部由此重算；`session_id` 支撑续做；`kind` 区分三种形态，支撑"一个调度器三种形态"的状态互通。

**缓存规则**：`wrongbook.json`、`sessions/`、`snapshots/` 等派生物**只作本地缓存**（可随时从流水重建），语义上不是存储——同步的真相只有不可变流水与配置文件。重算器以全部设备分片为输入。

## 四、调度层（内核 riff）

- **建卡**：题目块 → `POST /api/riff/addRiffCards`（参数 `blockIDs`+`deckID`；R3 实测端点名，错题转卡、导入即建卡）；卡包创建走 `createRiffDeck`，卡包按题库组织（`deck` 命名：`小驴考试/<题库名>/<章节>`）。
- **到期与评级**：`getRiffDueCards`（deckID，到期队列）→ 自有 UI 作答 → `reviewRiffCard`（`cardID,deckID,rating`；rating 映射：二元 记住=Good / 忘了=Again；四级自评 4→Easy, 3→Good, 2→Hard, 1→Again）；另有 `skipReviewRiffCard`、`resetRiffCards`、`removeRiffCards` 供错题消灭与题库更新时调用（17 个 riff 端点已实测确认，docs/03 附录）。
- **暴露给用户的 FSRS 参数**：仅 `RequestRetention`（期望保留率，默认 0.9）与每日新题限额（插件侧限额，**不动内核全局 newCard 配置**），经内核 conf 写入并加全局影响警示；19 维 Weights 不暴露 UI，仅提供"优化器闭环"入口（P2：导出 revlog → 外部优化 → 写回）。
- **统计估算**：内核 `RiffCard` 不暴露 Stability/Difficulty，统计侧用 **ts-fsrs** 在前端独立估算留存率/未来负荷（复用小驴卡盒调研结论）。
- **收藏与属性查询**（R1/R3）：`exam-fav` 等块属性可经思源 SQL `attributes` 表检索（`SELECT block_id FROM attributes WHERE name='exam-fav'`——表结构待内核在线复核，兜底方案为遍历题库块 IAL）。

## 五、AI 题目 Schema（生成与入库的契约）

```jsonc
{
  "id": "ai-20261001-a1b2c3",
  "type": "single",                      // single|multiple|judge|fill|short
  "stem": "下列关于思源块引用的说法，错误的是？",   // 禁止"以下说法正确的是"式空泛句式
  "options": [
    { "key": "A", "text": "块引用支持跨文档跳转", "distractor_reason": null },
    { "key": "B", "text": "块引用会随源块删除自动变成纯文本", "distractor_reason": "常见误解：以为引用是软链接" }
  ],
  "answer": ["B"],
  "analysis": {
    "summary": "块引用是硬引用，源块删除时进入断链提示而非自动降级。",
    "per_option": { "A": "正确……", "B": "错误即本题答案……" }
  },
  "difficulty": "medium",                // easy|medium|hard|very_hard
  "bloom": "understand",                 // remember|understand|apply（v1 只用前三层）
  "knowledge_points": ["块引用", "数据安全"],
  "source": { "doc_id": "...", "block_id": "...", "quote": "删除源块时……" },  // 思源块引用=免费 citation
  "meta": { "origin":"ai", "model":"glm-4.7", "generated_at":"...",
            "prompt_template":"default-exam-zh", "review_status":"pending",
            "verify":{ "passed":true, "confidence":0.92, "checked_by":"self-round2" },
            "quality_score": 82 }
}
```

入库映射：`stem/options/analysis` → 块内容（富文本），其余 → `exam-*` 块属性；`source.block_id` 直接生成思源块引用。**质量门槛**：`quality_score ≥75` 且 `verify.passed` 才可入库；入库即 `review_status=pending`，用户校对后转 `verified`。

## 六、掌握度模型（派生层核心公式）

```
题目难度权重 w_q = 1 + 0.2 × (exam-difficulty - 3)
时间衰减 decay(t) = 0.5^(Δdays / 14)          // 半衰期 14 天
题量置信度 conf(n) = min(1, n / 5)             // <5 题标"数据不足"

知识点掌握度 KP = ( Σ w_q × verdict × decay × conf ) / ( Σ w_q × conf )
知识点留存率 R  = (1 + FACTOR·t/S)^DECAY       // FSRS 公式，S=该知识点复习间隔均值
薄弱度          = 1 - KP × R

预估得分率 = Σ( KP×R × 题量权重 ) / Σ 题量权重   // 附置信度说明
```

周快照：每周日把汇总指标（做题量/正确率/消灭数/掌握度分布）落 `snapshots/week-42.json`，支撑周对比报告。

## 附录 A：掌握状态机（设计评审修订，docs/05 速览 #8）

三套规则收敛为一条事件驱动的规则链，唯一输入是 attempt 事件流：

| 触发事件 | 错题本 | 题目形态 | FSRS 闪卡 |
|---|---|---|---|
| 刷题答错 | 收录，wrong_count+1，记错因 | 保持选择题 | — |
| 累计答错 ≥2 次 | 标记"顽固" | **降级为背诵题**（自动进背诵队列） | **建卡**（进 FSRS 调度） |
| 背诵/闪卡自评 | — | 连续 4 次"会"→升级回选择题 | "会/熟知"由 FSRS 自然拉长间隔 |
| 错题重练连对 2 次 | **移出（eliminated）**，计入消灭进度条 | 恢复选择题 | **不停卡**：继续 FSRS 调度直到间隔自然拉长 |
| 收藏 / 手动操作 | 手动移出/移入 | 强制切换形态 | 手动建卡/暂停 |

三条不变式：

1. **错题消灭 ≠ 停止记忆**：错题本是"待消灭清单"，闪卡是"长期记忆"——刷熟只清前者，后者由 FSRS 接管。
2. **对用户只讲一个词**：所有界面统一显示"掌握度"（题面粒度=加权正确率×留存率），不暴露"错题状态/卡片状态"两套进度。
3. **cram 队列永不写回**：冲刺队列的作答照常记流水，但不改变形态与调度（Anki reschedule-off 语义）。
