## 一、产品定位

**小驴考试（Lv Exam，`siyuan-exam`）**：思源笔记上的**本地题库学习管理大杂烩**。各类考试（公考/考研/医考/法考/教资/驾考/职业资格/校内课程……）的题库由用户自己导入或 AI 生成，本地化存储在思源笔记里，插件提供刷题、背诵、模考、错题本、FSRS 闪卡记忆、AI 讲解与出题的完整闭环。

一句话对标：**粉笔的刷题体验 × Anki 的记忆科学 × 思源的知识库**——但题库长在用户自己的知识库里，数据归用户，AI 自带 key。

**小驴系列定位**：打卡（习惯量化）→ 人脉（关系管理）→ 快切（效率切换）→ 拾遗（输入整理）→ **考试（学习输出与检验）**。与既有系列的数据联动点：拾遗/书架输入的笔记成为 AI 出题素材；打卡的连续性机制复用 streak。

### 差异化护城河（竞品要自建才能有、思源天然就有）

1. **双链还原**：题目块 ↔ 教材笔记块双向引用；反链面板聚合"同一考点的题和笔记"（医考帮"大纲还原法"/圣才"知识点串联"的零成本版）。
2. **内核 FSRS**：思源 3.8 内置 go-fsrs v3 与 `/api/riff/*` 全套端点，不重造调度算法，只做"驾驶舱"。
3. **块级数据契约**：题目是块 ⇒ 免费获得版本历史、同步、全文搜索、`.sy.zip` 分享；派生数据（作答流水）走插件私有存储，永不污染题源。

## 二、目标用户与核心场景

| 画像 | 场景 | 关键诉求 |
|---|---|---|
| 备考冲刺者（考公/考研/医考） | 考前 1-6 个月，导入真题题库刷题+模考 | 真题/模拟双来源标记、错题闭环、cram 冲刺、模考报告 |
| 笔记型学习者（课程/证书） | 日常把笔记变成题库与闪卡 | 笔记→AI 出题、错题回链笔记、FSRS 抗遗忘 |
| 题库分享者（老师/UP主） | 制作题库包分发给学生/粉丝 | Excel/Word/GIFT 导入、`.sy.zip` 题库包、导出 |
| 驾考/碎片型用户 | 通勤听题、每天 10 题 | 语音听题、每日一练、移动端刷题 |

## 三、设计原则（功能变多的克制手段）

1. **题库进思源**：题目本体永远是块（可见可改可搜索可同步），插件不锁数据；派生数据（作答流水/错题/统计）进插件私有存储，append-only 不可变事件。
2. **一个调度器三种形态**：同一道题在"选择题→翻卡背诵→分点闪卡"三种形态间流转，共用内核 FSRS 调度与统一"掌握度"语义；不出现"题库一套进度、闪卡一套进度"。
3. **模块开关**：设置面板按模块启用/禁用（人机对话题型、游戏化、语音听学、AI 均可关闭），功能面广但默认轻。
4. **导入优先于生成**：题源第一性是用户导入（确定性数据），AI 是增强不是依赖——题库不因 AI 服务不可用而瘫痪。

## 五、核心用户旅程（贯穿设计）

```
导入题库（Excel 向导 → 预览校对 → 入库为块）
   ↓
刷题诊断（单题/专项/整卷，即时判分）
   ↓ 答错
错题本（错因标注 → 连对 2 次消灭 → 举一反三变式）
   ↓ 一键转卡
FSRS 巩固（到期队列 → 四级自评 → 掌握度更新）
   ↓ 长期
报告中心（掌握度树 → 薄弱 Top10 → 定向组卷/定向 AI 再生成）
   ↓ 考前
冲刺 cram（倒计时姿态 + 高频考点队列 + 模考校准）
   ↓ 考后
估分 → 周报沉淀 → 题库包分享/复盘文档
```

任何时刻，题目可跳回来源笔记（双链），笔记可 SQL 圈题成临时练习集。

## 六、分模块功能规格

### 1. 题库引擎（P0）

- **题目存储**：一题一超级块（题干段 + 选项列表块 + 解析块），题目 ID 存块属性（`exam-id`，导入时生成的稳定 ID，重命名/移动不变）；题型/答案/难度/分值/来源年份等存块属性（`exam-*` 命名空间）。〔数据契约详见数据模型文档〕
- **题库组织**：一个笔记本=一个题库；文档=章节/卷；考点标签走思源标签或块引用。
- **多维视图**（同一题库多入口，苍盾"真题双视图"原则）：章节树视图 / 年份卷视图 / 题型视图 / 错题视图 / 收藏视图 / 标签（考点）视图——全部是同一题目集合的过滤投影。
- **检索**：题干/选项/解析全文检索（走思源内核 SQL），支持"搜索结果→临时练习集"。
- **题库健康**：重复检测（题干哈希+相似度）、字段缺失清单、批量编辑（章节/难度/标签批量改）。

### 2. 导入流水线（P0：Excel/CSV/Aiken/GIFT；P1：Word/apkg；P2：AI 识别/QTI）

**四通道漏斗**（考试宝范式）：AI 识别兜底 → 模板批量（Excel/CSV 管结构，Word 管富文本与公式→LaTeX）→ 文本格式（Aiken/GIFT/TSV）→ 单题手工编辑器。所有通道汇入同一条流水线：

```
选文件 → 选 sheet/区块 → 字段映射（用户确认列↔字段）
→ 输入净化（合并单元格/Alt+Enter/全角符号）
→ 逐题校验（答案∈选项集、题型↔答案格式、空题干）
→ 去重（题干哈希+相似度）
→ 预览列表（先导 5 行试错模式，人工抽查）
→ 入库（单题报错跳过并汇总错误清单，绝不整批失败）
→ 完成页引导首次练习
```

- **Excel/CSV 模板列契约**：`题号｜题型｜题干｜选项A-F｜答案｜解析｜难度｜知识点｜分值｜来源`；判断题答案约定"对/错"，多选连写 `ABD`；提供官方模板下载与说明文档。
- **Aiken**：单选纯文本；**GIFT**：全题型（含多选权重 `%50%`、判断、数值区间、匹配）；**TSV**：Anki 文件头声明式（`#separator`/`#columns`）。语法示例存于调研 07 号报告。
- **apkg 只读导入**（P1）：sql.js 解析 ZIP 内 SQLite（`notes.flds` 按 `\x1f` 拆分、media JSON 映射还原文件名），媒体存入思源 assets；revlog 可选转为复习流水。
- **导入后治理**：批量编辑/删除/去重、"公共题库请自行核对答案"提示。

### 3. 练习台（P0）

- **三种练习结构**（粉笔/华图/中公三家同构的最小完备集）：
  - 单题快刷：随机/顺序刷，碎片时间，无计时；
  - 专项练习：考点分类树下钻（章节→考点→知识点），按 tag 圈题；
  - 整卷练习：按卷（年份卷/组卷蓝图）限时或无限时。
- **入口五件套**：顺序 / 随机 / 章节专项 / 错题重练 / 收藏练习。
- **做题/背题双模式**（华图杀招）：做题=判分；背题=直接展示答案+解析，适合考前突击，切换开关常驻。
- **即时反馈**：判分后展示正确答案与解析；解析区三联动——收藏、个人笔记（存思源块）、错因标记。
- **选项乱序**（考试宝）：含"以上都对/都不是"类豁免规则。
- **会话续做**：刷题会话可暂停/续做、逐题草稿（Damophus 已验证的工程形态）。
- **自适应难度**（可选）：按正确率滑动抽题难度。

### 4. 错题本（P0）

- **收录**：练习+模考答错自动收录（可配置只收练习）；快照存**用户当时的作答**、正确答案、用时、考点、时间。
- **错因三分类**：`粗心` / `知识不会` / `陷阱`（+免标注跳过）；"只重练知识不会"一键筛选。
- **消灭机制**：默认连对 2 次自动移出（N 可配）；错题本首页"消灭进度条"（已消灭/总数）。
- **举一反三**（中公杀招）：按考点标签自动推荐同考点变式题，本地规则实现。
- **错题导出**：导出 Markdown 到用户笔记本（题干/你的答案/正确答案/解析用 callout 区分），供打印；错题写回文档（RecallGen 机制）可选。
- **分层**：按"错 N 遍"分层展示；错 2 遍以上自动推入闪卡队列。

### 5. 记忆引擎（P0：FSRS 对接+错题转卡；P1：cram）

- **调度走内核**：`/api/riff/*` 端点建卡/到期队列/评级，不重造算法；插件暴露的唯一 FSRS 参数=**期望保留率**（默认 0.9，建议 0.85–0.97）+ 每日新卡上限 + 优化按钮，其余隐藏。
- **评分制**：默认二元（记住/忘了，Mochi 已验证干净映射 FSRS Good/Again）；进阶设置切四级（墨墨：会/模糊/不会/熟知）或 Anki 式四按钮（带间隔预览）。
- **错题转卡**：答错一键转闪卡；导入即有卡（每题自动生成配对卡：正面题干、反面答案+解析）；论述/简答题走"分点排版"模板（①②③分行逐点展开）。
- **题目形态升降级**：答错 2 次自动降级为翻卡背诵题；背诵连续过关 4 次升级回选择题（04 号设计）。
- **cram 自定义复习**（Anki filtered deck）：按 tag/错误次数/到期/新卡筛选 + 排序（最常错/最久没见/最可能忘）+ **"不写回调度（纯预览）"开关**——考前突击不打乱长期进度。
- **双链三件套**：答题界面显示来源路径可跳回笔记；题目↔考点笔记块引用；SQL 圈题动态练习集。

### 6. 模考场（P1）

- **三种模式分层**：自由刷题（无计时）→ 单卷限时（总倒计时）→ 全真模考（分段计时+答题卡+超时自动交卷+考中不可回看解析）。
- **组卷蓝图**：按"模块×题型×数量×分值"配置（如行测：言语 40×0.8 / 数量 15×0.8 / 判断 40×0.8 / 资料 20×1 / 常识 20×0.5）；每个题型可配来源（真题/模拟/错题重考）；支持从错题/收藏一键生成变式卷。
- **答题卡**：底部网格三态（未答/已答/标旗），点击跳题、跳题不丢已选；提前交卷二次确认；切屏计数进报告。
- **成绩单**（粉笔报告维度）：总分与得分率、模块用时条形图（含超时题量）、"最后 20 分钟动态"、正确率雷达图；本地版用**得分率三线对比（本次 vs 历史均值 vs 目标分）**替代全服百分位。
- **行业评分**（P2）：法考式多选少选得分、案例分析倒扣分、及格线自定义。
- **人机对话题型引擎**（P2，高级题型模块）：共用题干、共用备选答案、案例分析不定项倒扣分、题型间与部分内不可回退——医考硬需求，导入端配模板行格式。

### 7. 背诵模式（P1）

融合墨墨四级自评 + 扇贝渐进提示 + Anki 考试周 cram（交互规范与界面线框见调研 04 号报告）：

- 正面：题干（论述题附"分点提纲遮挡"，①②③逐点展开）；可选倒计时（按分值 30s/60s/90s，超时计"模糊"）。
- 渐进提示链：提示① 关键词 → 提示② 思路框架 → 翻开完整答案。
- 翻开 → 四键自评（1 不会 / 2 模糊 / 3 会 / 4 熟知，快捷键 1-4）；"不会"立即重排队尾；组结算（组内正确率/回流题数/标红清单）。
- 顶部常驻"今日复习压力"（到期数）与"未来 14 天预测"迷你图（墨墨可视化）。
- "我的口诀"：题目页一级入口，本地保存，导出可选附带（UGC 精益简化版）。

### 8. 报告中心（P1）

- **四件套**：知识点树（按掌握度染色，FSRS R 公式衰减：`R = (1 + FACTOR·t/S)^DECAY`）、模块雷达图、薄弱 Top10（一键组卷"薄弱专项 20 题"）、分数预测卡。
- **掌握度模型**：`掌握度 = 加权正确率 × FSRS 留存率`，权重=难度×时间衰减×题量置信度；<5 题的知识点显示灰色"数据不足"，不显示 0 分。
- **可解释分数预测**：`预估得分率 = Σ(同考点加权正确率 × 题量权重)`，标注置信度（基于已刷题量），给"预测分 vs 最近模考分"分差归因（"差距主要在资料分析用时"）——不做黑盒控分。
- **热力图**：53 周学习热力图 + 做题量/正确率趋势曲线。
- **周报**：本地按周快照，周对比报告（做题量/新消灭错题/掌握度变化）。

### 9. AI 模块（P1，BYO key）

- **AI 出题**：输入源（当前文档/所选块/指定笔记本/粘贴文本）→ 题型（单选/多选/判断/填空起步）→ 数量/难度（易中难混合）/语言 → 产出**结构化 JSON 题目**（schema 见数据模型文档：题干/选项+干扰项理由/答案/解析含逐选项解释/难度/布鲁姆层级/知识点/**来源块引用**）→ 入"待审核队列"（`pending`）→ 人工校对/单题重生成/编辑后入库。**长输入自动切片**（R2）：按思源标题层级分段生成、逐段入审核队列；超过 200 块的来源提示按章节拆分，单次生成成本可预估可取消。
- **质量管线**：超量生成 1.5× → 客户端校验（答案命中选项、禁"以上都对"、解析≥N 字含因果词）→ 哈希+相似度查重（已有题摘要回灌 prompt）→ 二遍换角色核验（置信度 ≥0.85）→ `quality_score ≥75` 入库。
- **AI 讲解侧栏**：做题界面常驻"问 AI"；答错默认给"正确答案为什么对+你错在哪"逐选项解释；"给点提示"（Hint 递进）与"苏格拉底模式"（只提问不报答案）开关；讲解结果可存为思源块。
- **定向再生成**：错题本知识点分布 → "针对错 3 次的知识点生成 10 道新题"。
- **Prompt Settings**：出题 system prompt 可编辑，内置预设（公考行测/考研政治/医学执业/驾考）。
- **主观题 AI 批改**（P2）：按采分点比对给分（申论/简答）。

### 10. 备考计划（P1/P2）

- **考试倒计时**：设考试日与科目权重 → 反推每日新题量/复习量（RemNote Exam Scheduler 的 front-load 思路，用 Anki 社区"20 新卡≈200 复习"经验值估算）。
- **每日一练**：固定 10 题轻钩子（优先 FSRS 到期 + 高频考点），233/万题库双验证。
- **冲刺姿态**：距考试 N 天（可配，默认 14）自动切换——暂停远期推送、拉"高频考点+错题≥2"临时队列、总量上调、打卡海报切倒计时样式；考后一键恢复。**今日任务在冲刺姿态下的聚合规则（R2）**：cram 队列优先占满当日配额，不足部分再补每日一练；多题库时只聚合考日最近的题库。
- **估分工具**（P2）：考后导入真题+答案 → 对答案估分（考后天然使用峰值）。

### 11. 听学与无障碍（P2）

- **TTS 听题**（Web Speech API 零依赖）：三种刷题形态——看题 / 看题+朗读 / 纯听题；连读顺序"题干→选项（带'选项A'前缀）→[作答]→判读'正确答案是 B'"；0.8–2.0x 倍速；`onboundary` 逐句高亮；解析默认不自动读，逐段点击播放。
- **无障碍**：题干字号独立滑杆（14-28px）、护眼豆沙绿叠加层开关、暗黑跟随思源主题变量。
- **全屏专注模式**（P1）：模考与背诵的沉浸界面（233 机考界面的思源化替代）。

### 12. 激励系统（P2）

- **streak**：完整移植 Duolingo 规则——自然日判定，任一学习行为保号；默认 2 个连胜冻结、漏学自动消耗、满 100 天奖励 3 个一次性冻结；里程碑 7/30/100/365 天徽章。
- **积分**：获取（答题量/正确率加成/模考完成/消灭错题）→ 消耗（AI 讲解/出题次数、主题皮肤）；永不兑换"学习额度"。
- **单机赛道榜**：与自己的历史比（周环比曲线）+ 虚拟基准线（"50 题 Club"梯度），不做虚假全服榜。
- **挑战码 PK**：导出一周挑战卷（题集+时间）→ 朋友导入作答 → 互比成绩单（无服务器的异步 PK）。
- **打卡海报**：累计天数/刷题量海报图片导出（轻社交，扇贝式自传播）。

### 13. 互通与分享（P0：双链；P2：分享）

- **题目↔笔记双向引用**：出题时记录来源块引用；反链面板聚合"同一考点的题与笔记"。
- **错题写回文档**：低分题/顽固错题一键写回对应笔记（callout 区块）。
- **题库包分享**（P2）：题库导出 `.sy.zip`（含题目块与属性），版本化更新按题目 ID diff 出"新增/修订/删除"清单（Anki guid 机制），保留作者署名；导入时提示自行核对答案。
- **apkg/CSV 导出**（P2）：接入 Anki 用户群，满足打印与迁移。
- **跨插件联动**：拾遗/书架的阅读笔记 → AI 出题素材；打卡插件的连续性 → streak 数据源。

## 七、竞品关系与红线

- **不碰红海**：不做闪卡增强（14+ 插件卷制卡/遮挡/渐进阅读）、不做复习面板重造（闪卡小助手 ZY 已占）、不做课程内容（粉笔们的主场）。
- **唯一题库竞品**：Damophus（自用定位，明确不做 AI/错题文档/在线功能）——跟踪其 release，差异化空间天然存在。
- **红线**：不引入云端依赖、不做内容运营、不做订阅、不制造人为稀缺、AI 生成永远标"待审核"。

## 八、验收口径（v1.0 上架标准）

1. 用官方 Excel 模板导入 500 题题库，全流程无整批失败，错误行有清单。
2. 断网状态下刷题/背诵/模考/错题/FSRS 复习全部可用（AI 除外）。
3. 移动端可完成"每日一练 10 题"完整流程。
4. 任一题目可双链跳回来源笔记；任一笔记可圈题成临时练习集。
5. 模考成绩单四维度齐全；掌握度树与 FSRS 到期联动一致。

## 九、设计评审增补（2026-10-01，依据 docs/05）

### 9.1 画像收敛

主画像：**用思源记笔记的备考者**（考研/考证/医学生/公考）——他们既刷题又记笔记，"题库长在知识库里"对他们才是刚需。次画像：题库分享者（老师/UP 主，题库包生产与分发）。**纯刷题用户不是目标画像**（有粉笔，不装笔记软件）——不为他们牺牲知识库融合的深度。

### 9.2 v1.0 考试类型支持矩阵

| 能力 | v1.0 | v1.x+ |
|---|---|---|
| 单选/多选/判断/填空 | ✅ 开箱即用（所有客观题考试） | — |
| 简答/论述题面与分点背诵 | ✅（展示+背诵，不做批改） | AI 按采分点批改 |
| 材料组/共用题干 | 展示与作答 | 人机对话作答流（不可回退/倒扣分） |
| 行业评分（法考/及格线/倒扣） | 百分制+及格线 | 法考式/倒扣分规则 |

### 9.3 交互原则（新增四条）

1. **零决策开始**：顶栏"今日任务"点击=直接进入会话（到期复习+每日一练合并队列），没有中间选择页；命令面板/快捷键同理。
2. **键盘优先**：A-F 选选项、空格翻面与提交、1-4 四级自评、J/K 上下题、F 标旗、E 收藏。
3. **浏览与刷题同源**：练习台顶部"刷题 / 浏览"双模式切换——浏览=章节树→题目列表→单题详情（题面/答案/解析/个人统计/双链/编辑入口）；错题本、收藏在浏览模式中都是过滤器。移动端无 dock，错题入口走浏览模式。
4. **编辑器内不剧透**：题库文档的日常阅读、思源全局搜索命中题目块，都可能暴露解析——统一答案：块菜单"在练习台中打开此题"（单题详情，正常遮罩）；浏览模式的单题详情默认遮罩解析。

### 9.4 功能增补

- **手工录题表单编辑器**（v0.1 必备）：斜杆命令与块菜单打开表单对话框（题型/题干/选项/答案/解析/考点/难度），插件负责生成超级块+块属性；已有题目可从块菜单进入同一表单编辑。
- **章节即兜底考点**：`exam-kp` 缺失时，文档树（笔记本→文档→标题层级）自动充当考点层级——统计/掌握度/举一反三全部可退化到章节粒度运行，导入无考点列不再是阻断问题。
- **AI 默认走思源内置配置**：AI 通道优先复用思源设置-人工智能的模型配置（内核 `/api/ai/*`），零配置可用；BYO key 为高级选项。质量档位（经济/标准）控制生成成本。
- **查询圈题升格为正式功能**（v0.2）：思源查询嵌入块的菜单提供"用此查询开始练习"——用户用 SQL/查询语法圈题即成练习集。
