## 一、产品定位

**小驴考试（Lv Exam，`siyuan-exam`）**：思源笔记上的**AI 贯穿的本地可验证备考工作台**。用户把原创或有权本地保存/转换的资料整理为带来源、版本和许可边界的学习对象，AI 协助输入整理、范围规划、待审命题、练习陪学、错因解释、复测、计划与知识沉淀。插件记录明确作答条件与证据，帮助用户从“我还缺什么”走到“下一步做什么”，再验证是否能够独立完成。

一句话定位：**把你有权使用的题，变成思源里可复盘的学习证据**——连接练习、记忆复测与个人知识库。

**AI 产品主线**：统一任务/上下文/模板服务贯穿所有模块，提供就地 AI 入口、任务工作台与思源智能体能力接入；模型使用复用思源配置，自配兼容端点作为可选路径。当前已有生成/复核/修复和讲解，智能体注册、跨模块任务及新版模板仍属重点规划。AI 提出有依据的候选和行动，评分、FSRS、权限与实际写入由确定性服务及用户确认负责，离线/停用 AI 仍可学习与保存。详见 [research/16](../research/16-AI全流程与思源智能体融合调研.md) 和 [docs/18 模板正文](18-AI智能体与提示词模板规范.md)。

**内容供给边界**：插件提供功能与处理方法，内容由用户主动上传、手工录入或自行取得官方允许导出的文件，不内置第三方题库。仅在线访问授权的来源在思源保留外链、个人答案、笔记和学习记录，不复制受限题文/解析。官方 API 仅在有公开文档或书面授权且明确允许所需用途/留存时研究，不能宣传已直连粉笔、中公或众合；购买、公开可见和用户声明均不自动创造保存/改编/分享权。详见 [research/15](../research/15-考试软件竞品与用户题源接入调研.md)。

**资料学习边界**：用户购买的 PDF/讲义/视频可从本地、同步/挂载目录或网盘稳定入口登记，先查看/播放和编辑个人笔记，再选择获准页/时间段进入 AI/题库。预留 PDF 原页、媒体时间点、个人批注/字幕/章节和笔记编辑；原文件编辑按实际工具/权限另行衔接，不宣称可编辑任何 PDF 或剪辑任何课程。思阅/思播/思盘与本地软件按公开能力接入，无这些工具仍有思源原生/系统应用及手工定位路径。思源保留个人知识与学习证据，原件复制状态、位置/体积/同步/许可明确，大视频不默认全量搬入。详见 [research/17](../research/17-付费资料与本地网盘媒体联动调研.md)。

**执行组织**：第36–125组620条候选已按27个工作包与S0–S4阶段组织，详见[融合规划](19-待办融合与分阶段执行规划.md)。跨模块AI、资料、题源与考试配置共用契约；原编号全部验收通过才关闭，不按候选数量排版本。

**小驴系列定位**：打卡（习惯量化）→ 人脉（关系管理）→ 快切（效率切换）→ 拾遗（输入整理）→ **考试（学习输出与检验）**。与既有系列的数据联动点：拾遗/书架输入的笔记成为 AI 出题素材；打卡的连续性机制复用 streak。

### 差异化护城河（竞品要自建才能有、思源天然就有）

1. **双链还原**：题目块 ↔ 教材笔记块双向引用；反链面板聚合"同一考点的题和笔记"（医考帮"大纲还原法"/圣才"知识点串联"的零成本版）。
2. **内核 FSRS**：思源 3.8 内置 go-fsrs v3 与 `/api/riff/*` 全套端点，不重造调度算法，只做"驾驶舱"。
3. **块级数据契约**：获准导入的题目是块，可获得版本历史、同步与全文搜索；`.sy.zip` 公开分享仅限自有或允许再分发的资源，规划逐资源许可/隐私预览。派生数据（作答流水）走插件私有存储，永不污染题源；同步同样需要考虑副本传播范围。

## 二、目标用户与核心场景

| 次画像：课程/证书知识管理者 | 讲义、教材、自有笔记生成或整理题目 | 来源回链、修订影响、AI 待审、反思写回和可迁移导出 |

## 三、设计原则（功能变多的克制手段）

1. **获准内容与个人证据进思源**：获准导入的题目本体是块（可见可改可搜索），仅在线授权的来源保留指针和个人笔记，插件不锁用户原件；派生数据（作答流水/错题/统计）进插件私有存储，append-only 不可变事件，并保留可迁移出口。
2. **一个调度器三种形态**：同一道题在"选择题→翻卡背诵→分点闪卡"三种形态间流转，共用内核 FSRS 调度与统一"掌握度"语义；不出现"题库一套进度、闪卡一套进度"。
3. **模块开关**：设置面板按模块启用/禁用（人机对话题型、游戏化、语音听学、AI 均可关闭），功能面广但默认轻。
4. **用户题源与 AI 整理/生成协同**：用户提供获准材料，AI 协助结构整理、命题和审校，候选经核对后入库；缺依据时保留未知，题源不因 AI 不可用而丢失。
5. **AI 贯穿而权限可核查**：每个模块定义任务目的、必要输入、内置模板、结果、成功依据及人工路径；思源模型调用与智能体工具注册分开。未揭示答案的提示上下文不含答案/解析，严格模考本插件不调用题目级 AI；AI 不能直接改成绩/作答/许可或 FSRS 评级。

## 五、核心用户旅程（贯穿设计）

```
导入题库（Excel 向导 → 预览校对 → 入库为块）
   ↓
刷题诊断（单题/专项/整卷，即时判分）
   ↓ 答错
错题本（错因标注 → 连对 2 次消灭 → 举一反三变式）
   ↓ 一键转卡
FSRS 巩固（到期队列 → 四级自评 → 掌握度更新）
   ↓ 长期
报告中心（掌握度树 → 薄弱 Top10 → 定向组卷/定向 AI 再生成）
   ↓ 考前
冲刺 cram（倒计时姿态 + 高频考点队列 + 模考校准）
   ↓ 考后
估分 → 周报沉淀 → 题库包分享/复盘文档
```

任何时刻，题目可跳回来源笔记（双链），笔记可 SQL 圈题成临时练习集。AI 按节点处理输入修复、范围/命题、提示/追问、提交后讲解、错因/卡片候选、报告解释、容量内行动和知识写回；每一步保存来源与帮助条件。思源智能体和就地入口复用这些任务，产物先预览/审核，应用后给回执。

## 六、分模块功能规格

### 1. 题库引擎（P0）

- **题目存储**：一题一超级块（题干段 + 选项列表块 + 解析块），题目 ID 存块属性（`exam-id`，导入时生成的稳定 ID，重命名/移动不变）；题型/答案/难度/分值/来源年份等存块属性（`exam-*` 命名空间）。〔数据契约详见数据模型文档〕
- **题库组织**：一个笔记本=一个题库；文档=章节/卷；考点标签走思源标签或块引用。
- **多维视图**（同一题库多入口，苍盾"真题双视图"原则）：章节树视图 / 年份卷视图 / 题型视图 / 错题视图 / 收藏视图 / 标签（考点）视图——全部是同一题目集合的过滤投影。
- **检索**：题干/选项/解析全文检索（走思源内核 SQL），支持"搜索结果→临时练习集"。
- **题库健康**：重复检测（题干哈希+相似度）、字段缺失清单、批量编辑（章节/难度/标签批量改）。

### 2. 导入流水线（P0：Excel/CSV/Aiken/GIFT；P1：Word/apkg；P2：AI 识别/QTI）

**四通道漏斗**（考试宝范式）：AI 识别兜底 → 模板批量（Excel/CSV 管结构，Word 管富文本与公式→LaTeX）→ 文本格式（Aiken/GIFT/TSV）→ 单题手工编辑器。所有通道汇入同一条流水线：

```
选文件 → 选 sheet/区块 → 字段映射（用户确认列↔字段）
→ 输入净化（合并单元格/Alt+Enter/全角符号）
→ 逐题校验（答案∈选项集、题型↔答案格式、空题干）
→ 去重（题干哈希+相似度）
→ 预览列表（先导 5 行试错模式，人工抽查）
→ 入库（单题报错跳过并汇总错误清单，绝不整批失败）
→ 完成页引导首次练习
```

- **Excel/CSV 模板列契约**：`题号｜题型｜题干｜选项A-F｜答案｜解析｜难度｜知识点｜分值｜来源`；判断题答案约定"对/错"，多选连写 `ABD`；提供官方模板下载与说明文档。
- **Aiken**：单选纯文本；**GIFT**：全题型（含多选权重 `%50%`、判断、数值区间、匹配）；**TSV**：Anki 文件头声明式（`#separator`/`#columns`）。语法示例存于调研 07 号报告。
- **apkg 只读导入**（P1）：sql.js 解析 ZIP 内 SQLite（`notes.flds` 按 `\x1f` 拆分、media JSON 映射还原文件名），媒体存入思源 assets；revlog 可选转为复习流水。
- **导入后治理**：批量编辑/删除/去重、"公共题库请自行核对答案"提示。

### 3. 练习台（P0）

- **三种练习结构**（粉笔/华图/中公三家同构的最小完备集）：
  - 单题快刷：随机/顺序刷，碎片时间，无计时；
  - 专项练习：考点分类树下钻（章节→考点→知识点），按 tag 圈题；
  - 整卷练习：按卷（年份卷/组卷蓝图）限时或无限时。
- **入口五件套**：顺序 / 随机 / 章节专项 / 错题重练 / 收藏练习。
- **做题/背题双模式**（华图杀招）：做题=判分；背题=直接展示答案+解析，适合考前突击，切换开关常驻。
- **即时反馈**：判分后展示正确答案与解析；解析区三联动——收藏、个人笔记（存思源块）、错因标记。
- **选项乱序**（考试宝）：含"以上都对/都不是"类豁免规则。
- **会话续做**：刷题会话可暂停/续做、逐题草稿（Damophus 已验证的工程形态）。
- **自适应难度**（可选）：按正确率滑动抽题难度。

### 4. 错题本（P0）

- **收录**：练习+模考答错自动收录（可配置只收练习）；快照存**用户当时的作答**、正确答案、用时、考点、时间。
- **错因三分类**：`粗心` / `知识不会` / `陷阱`（+免标注跳过）；"只重练知识不会"一键筛选。
- **错题队列处置**：按声明的连续正确规则移出活动队列（N可配），保留历史；队列移出不等于能力掌握，提示后正确与延迟独立复测分开。状态机与证据见39-05/08。
- **举一反三**（中公杀招）：按考点标签自动推荐同考点变式题，本地规则实现。
- **错题导出**：导出 Markdown 到用户笔记本（题干/你的答案/正确答案/解析用 callout 区分），供打印；错题写回文档（RecallGen 机制）可选。
- **分层**：按"错 N 遍"分层展示；多次错误后建议补知识/复测/转卡，转卡由用户明确选择，不静默建卡。

### 5. 记忆引擎（P0：FSRS 对接+错题转卡；P1：cram）

- **调度走内核**：`/api/riff/*` 端点建卡/到期队列/评级，不重造算法；插件暴露的唯一 FSRS 参数=**期望保留率**（默认 0.9，建议 0.85–0.97）+ 每日新卡上限 + 优化按钮，其余隐藏。
- **评分制**：默认二元（记住/忘了，Mochi 已验证干净映射 FSRS Good/Again）；进阶设置切四级（墨墨：会/模糊/不会/熟知）或 Anki 式四按钮（带间隔预览）。
- **错题转卡**：答错一键转闪卡；导入后可预览并选择建卡（不默认为每题静默建卡：正面题干、反面答案+解析）；论述/简答题走"分点排版"模板（①②③分行逐点展开）。
- **题目形态建议**：可按失败/帮助条件建议回忆、补知识或变式，用户选择；原题型、历史版本与FSRS自评分不由连续次数静默改写（39-02/04、52-06、116-03）。
- **cram 自定义复习**（Anki filtered deck）：按 tag/错误次数/到期/新卡筛选 + 排序（最常错/最久没见/最可能忘）+ **"不写回调度（纯预览）"开关**——考前突击不打乱长期进度。
- **双链三件套**：答题界面显示来源路径可跳回笔记；题目↔考点笔记块引用；SQL 圈题动态练习集。

### 6. 模考场（P1）

- **三种模式分层**：自由刷题（无计时）→ 单卷限时（总倒计时）→ 全真模考（分段计时+答题卡+超时自动交卷+考中不可回看解析）。
- **组卷蓝图**：按"模块×题型×数量×分值"配置（如行测：言语 40×0.8 / 数量 15×0.8 / 判断 40×0.8 / 资料 20×1 / 常识 20×0.5）；每个题型可配来源（真题/模拟/错题重考）；支持从错题/收藏一键生成变式卷。
- **答题卡**：底部网格三态（未答/已答/标旗），点击跳题、跳题不丢已选；提前交卷二次确认；切屏计数进报告。
- **成绩单**（粉笔报告维度）：总分与得分率、模块用时条形图（含超时题量）、"最后 20 分钟动态"、正确率雷达图；本地版用**得分率三线对比（本次 vs 历史均值 vs 目标分）**替代全服百分位。
- **行业评分**（P2）：法考式多选少选得分、案例分析倒扣分、及格线自定义。
- **人机对话题型引擎**（P2，高级题型模块）：共用题干、共用备选答案、案例分析不定项倒扣分、题型间与部分内不可回退——医考硬需求，导入端配模板行格式。

### 7. 背诵模式（P1）

融合墨墨四级自评 + 扇贝渐进提示 + Anki 考试周 cram（交互规范与界面线框见调研 04 号报告）：

- 正面：题干（论述题附"分点提纲遮挡"，①②③逐点展开）；可选倒计时（按分值 30s/60s/90s，超时计"模糊"）。
- 渐进提示链：提示① 关键词 → 提示② 思路框架 → 翻开完整答案。
- 翻开 → 四键自评（1 不会 / 2 模糊 / 3 会 / 4 熟知，快捷键 1-4）；"不会"立即重排队尾；组结算（组内正确率/回流题数/标红清单）。
- 顶部常驻"今日复习压力"（到期数）与"未来 14 天预测"迷你图（墨墨可视化）。
- "我的口诀"：题目页一级入口，本地保存，导出可选附带（UGC 精益简化版）。

### 8. 报告中心（P1）

- **证据报告**：考点覆盖、模块表现、薄弱列表和可行动下一步；可用的内核卡片状态单独显示，不能把卡片R值称作整科能力。各指标附题库/时间范围、样本与帮助条件。
- **掌握度估计**：现有启发式标明算法/时间窗/独立题数/覆盖，不将加权正确率与FSRS调度状态的乘积视为能力真值；低样本显示数据不足，阈值按场景验证（39-07、88-01）。
- **分数表达**：条件相同的模考实得分/历史/目标可比较；考后按已核验答案估分单列。正式考试成绩/通过率预测保留研究，不因公式可解释就对外宣称有效（39-06/07、88-03、99-04）。
- **热力图**：53 周学习热力图 + 做题量/正确率趋势曲线。
- **周报**：本地按周快照，周对比报告（做题量/新消灭错题/掌握度变化）。

### 9. AI 任务、模板与思源智能体（核心服务：P0 契约 / P1 闭环）

**当前边界**：源码已有双通道、生成/二遍换角色核验/修复、5 个命题预设与三模式讲解；原材料块级出处、未揭示答案隔离、模板版本化和智能体注册尚待补齐。现有0.85阈值为模型自报，旧1.5×/quality_score≥75设计不视为已实现或质量证明；以下为目标规格。

- **总层任务服务**：每项绑定 project/qid/revision、模式、模板、实际上下文、端点、预算和结果，统一 pending/partial/needsEvidence/needsReview/applied；就地入口与智能体共享服务。
- **思源双向接入**：已配置可用模型时复用思源 AI；通过官方 `addAgentCapability` 向思源智能体暴露有范围、schema 和 effects 的业务能力。注册与模型推理分开，先读摘要/生成提案，写入需具体目标 diff、版本核对、幂等与恢复。
- **题源→范围→命题**：用户上传获准资料，AI 提出结构修复、主题覆盖和认知目标命题候选，原件/片段/页或块位置可回链；缺依据可少生成或待补。
- **独立审题与人工队列**：第一阶段不提供候选答案，再对照来源/答案/解析，检查多解、条件、量纲与媒体；每题保留完整证据包，人工确认后入库，模型一致不代替金标准。
- **练习陪学**：未提交时按模式给一次一层提示或一个追问，不传隐藏答案/解析；提交后引用依据讲解并给检查点，提示/脚本/解析暴露记为受助条件，严格模考本插件关闭题目级 AI 请求。
- **错因/记忆/写回**：根据用户步骤提出可验证错因假设、待审变式、最小卡与延迟复测行动；个人笔记草稿区分用户反思、来源事实和 AI 补充，先预览，不改成绩/作答/FSRS 评级。
- **主观题与领域模板**：按用户/教师提供的 rubric revision 引用原答并给建议分/未评状态；学校/CET/KET/法考/CPA/CFA 各补学段、技能、任务、年度、规则/准则与材料条件。无 rubric 不编官方分，人工确认最终分。
- **报告与计划**：AI 解释确定性统计和条件，在分钟容量内提下一行动、缩减/延期方案；计划应用与原成绩/到期记录分别处理，不预测保证通过。
- **Prompt Settings 与思源技能**：提供固定契约＋任务正文＋考试叠层＋偏好＋输出 schema；[docs/18](18-AI智能体与提示词模板规范.md) 有13个完整任务正文，含所选 PDF/媒体片段学习。用户可编辑、分叉、回滚，可选择后续思源专用技能安装，不自动覆盖用户技能/全局指令/模型设置。
- **质量与运行护栏**：任务级原创/授权 fixture 检查引用支持、泄题、字段、rubric、容量、权限、成本与恢复；支持取消和手工路径，已经发送或执行未知的请求不能承诺撤回，也不自动重试写入/费用动作。

### 10. 备考计划（P1/P2）

- **考试倒计时**：设考试日与科目权重 → 反推每日新题量/复习量（RemNote Exam Scheduler 的 front-load 思路，用 Anki 社区"20 新卡≈200 复习"经验值估算）。
- **每日一练**：固定 10 题轻钩子（优先 FSRS 到期 + 高频考点），233/万题库双验证。
- **冲刺姿态**：距考试 N 天（可配，默认 14）自动切换——暂停远期推送、拉"高频考点+错题≥2"临时队列、总量上调、打卡海报切倒计时样式；考后一键恢复。**今日任务在冲刺姿态下的聚合规则（R2）**：cram 队列优先占满当日配额，不足部分再补每日一练；多题库时只聚合考日最近的题库。
- **估分工具**（P2）：考后导入真题+答案 → 对答案估分（考后天然使用峰值）。

### 11. 听学与无障碍（P2）

- **TTS 听题**（Web Speech API 零依赖）：三种刷题形态——看题 / 看题+朗读 / 纯听题；连读顺序"题干→选项（带'选项A'前缀）→[作答]→判读'正确答案是 B'"；0.8–2.0x 倍速；`onboundary` 逐句高亮；解析默认不自动读，逐段点击播放。

- **全屏专注模式**（P1）：模考与背诵的沉浸界面（233 机考界面的思源化替代）。

### 12. 激励系统（P2）

### 14. 学习资料查看、编辑与工具联动（研究候选）

- **资料先用再结构化**：PDF/视频/字幕/课程包可先登记、查看/播放、编辑个人注释；不要求所有资料先转换题库。material/revision/location/locator 区分身份、版本、设备位置与页/时间段，来源/许可分别保存。
- **最低查看/编辑**：思源原生 PDF/资产与系统阅读/播放器作为基线，自己的页码/时间点/章节/批注/笔记能编辑；文本搜索/原文修改/媒体剪辑/批注写回原件按实际工具支持，不混成一种“编辑”。
- **网盘与本地**：用户下载或同步文件后选择，或登记思盘/网盘稳定入口；占位、临时签名地址、完整离线副本分别显示，凭据不进 AI/日志/题包，不接管平台登录。
- **工具协作**：核实思阅阅读接口/页码链接、思播时间链接/媒体笔记、思盘文件选择/持久打开入口；优先公开链接，再按版本探测 API。无插件、无会员、格式/前端不支持或无回调时提供原生/系统打开与用户回录。
- **AI 片段闭环**：用户获准页/时间段与实际 OCR/脚本→T13 理解检查→待审题→独立答→回原页/时间点→复测/知识写回。缺内容不声称已看视频，答案页/字幕暴露进入作答条件。
- **版本与退出**：外部修改、移动、换机或授权到期先预览影响，用户重选并核对身份；个人证据仍可迁移，原件/缓存/assets/副本按许可与用户选择处理。目标及待办见 [research/17](../research/17-付费资料与本地网盘媒体联动调研.md)，尚未实现联动。

题源流程统一为：用户提供 → 来源登记 → 隔离 → 原件与转换预览 → 许可/隐私/版本补全 → 答案与解析核验 → 内部发布 → 按资源权利导出。公开可见不等于可再分发；官方规则、样题、真题、答案、出版社解析、音频和图片必须分别记录来源、许可、版本、核验状态和媒体权利。真实性未核验不进入“官方/真题”筛选；许可未知不进公共包，默认隔离或外链，两轴独立。到期/撤回按具体许可处理全文，个人证据不静默丢失；个人信息需按用途脱敏或核对授权。

### 9.3 交互原则（新增四条）

1. **零决策开始**：顶栏"今日任务"点击=直接进入会话（到期复习+每日一练合并队列），没有中间选择页；命令面板/快捷键同理。
2. **键盘优先**：A-F 选选项、空格翻面与提交、1-4 四级自评、J/K 上下题、F 标旗、E 收藏。
3. **浏览与刷题同源**：练习台顶部"刷题 / 浏览"双模式切换——浏览=章节树→题目列表→单题详情（题面/答案/解析/个人统计/双链/编辑入口）；错题本、收藏在浏览模式中都是过滤器。移动端无 dock，错题入口走浏览模式。
4. **编辑器内不剧透**：题库文档的日常阅读、思源全局搜索命中题目块，都可能暴露解析——统一答案：块菜单"在练习台中打开此题"（单题详情，正常遮罩）；浏览模式的单题详情默认遮罩解析。

### 9.4 功能增补

- **手工录题表单编辑器**（v0.1 必备）：斜杆命令与块菜单打开表单对话框（题型/题干/选项/答案/解析/考点/难度），插件负责生成超级块+块属性；已有题目可从块菜单进入同一表单编辑。
- **章节即兜底考点**：`exam-kp` 缺失时，文档树（笔记本→文档→标题层级）自动充当考点层级——统计/掌握度/举一反三全部可退化到章节粒度运行，导入无考点列不再是阻断问题。
- **AI 优先复用思源配置**：思源 AI 已启用且配置可用模型时复用其通道，自配端点为可选项；智能体注册另探测宿主版本/前端/权限。内置不表示本地推理或免费，任务展示端点、实际上下文与预算，质量档位需经任务评测。
- **查询圈题升格为正式功能**（v0.2）：思源查询嵌入块的菜单提供"用此查询开始练习"——用户用 SQL/查询语法圈题即成练习集。
