# 使用体验走查与优化记录（2026-10-11）

本轮以新用户从建库到复盘的路径检查真实组件，对照 `design/DESIGN-SPEC.md` 与 `docs/11-UI原型与交互规范.md`。调整重点是入口可达、操作条件、保存回执、范围一致和失败后可继续。

| 使用路径 | 前置条件与反馈 | 本轮处理 |
| --- | --- | --- |
| 首次进入 | 无题库可以建库或创建示例，已有空库可以导入/录题 | 12 道原创示例覆盖主要题型；创建过程中防连点，失败重试通过文档原文核对 |
| 导入校对 | 先解析预览，显示目标题库，再试导或确认入库 | 仅更新重复题时也可提交；试导排除已确认题；处理期间禁止切库/重解析；失败保留恢复入口 |
| 手工录题/编辑 | 正确答案必须与现存选项一致 | 删除选项同步重映射答案，空选项提示修正，保存期间的新草稿不被清空 |
| 按题型作答 | 单/多选点击选项，判断选择对错，填空与简答输入文字 | 显示题型说明、参考答案/自评边界，清空输入禁用提交，切题恢复各自草稿 |
| 续做与题目变动 | 同题库恢复，缺题可解释 | 修正缺题后的游标、已答位置和草稿，保留重排题的独立位置 |
| 错题本 | 当前题库的错题才进入重练队列 | 侧栏数量、列表与消灭比例使用同一题库范围 |
| 模考 | 有可自动判分题、有效蓝图与时长 | 时长可编辑，说明题型限制及交卷后果；防重复交卷，成绩写入失败可重试；冻结卷面归属 |
| 报告与行动 | 先明确日期及题库口径 | 使用本地自然日，统计与下钻同步；今日战报只取当前库今日记录；打开重练不提前完成行动 |
| AI 候选 | 配置可用 AI，并主动申请生成 | 保存本批材料、题库和额外要求；修复/重生成使用原材料；错库禁用入库；候选与已入库反馈区分 |
| 资料笔记 | 登记资料后添加带位置的个人笔记 | 切换资料保留独立草稿，替换未保存草稿先确认；保存期间禁止切换编辑，失败保留输入 |
| 设置与保存状态 | 收到实际保存回执后提示成功 | 设置失败保留输入；保存详情显示中文对象与处理说明；初始化期间的入口点击待就绪后执行 |
| 导航、键盘与拖拽 | 操作属于当前可见页签 | 输入法不误执行，命令面板执行焦点项；窄屏收起导航并归还焦点；宿主编辑器/弹窗/后台页签不响应作答快捷键；文件拖拽接收正确 |
