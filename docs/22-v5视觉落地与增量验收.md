## 3. 逐项验收

每项以真实宿主中的操作与结果为完成依据；相关服务复用现有工作包。

### V01 表面层次与必要控件边界分开取色

主承接：**45-10 / W14 / S3起**。

**验收要求**：将画布/侧栏/内容/阅读纸页/浮层及普通分隔线/必要控件边界分别映射宿主token，不能把v5固定色值直接当所有主题值。正文与辅助说明按实际背景核对4.5:1，必要控件/选中/焦点边界核对3:1；同时验证渐变端点、hover、disabled和语义色组合，fallback逐项留证。

**需保留的证据**：宿主亮暗/第三方主题的实际色对、缺变量回退、必要边界与装饰线区分清单。

### V02 按阅读与作答目的选择内容密度

主承接：**61-02 / W14 / S3起**。

**验收要求**：实现普通/低密度布局时保留同一题面、来源、条件和主动作；首页重点、任务列表、阅读原件/个人笔记、作答区/辅助条件及AI输入/候选形成明确层次。用间距/字体/边界降低辅助信息竞争，不能以变淡或折叠隐藏必要规则；布局切换不改变已选答案/草稿/统计。

**需保留的证据**：同一长题/讲义在两种密度与窄容器的内容/目标/主操作比对，保留状态可读回。

### V03 导航与指标图标保持同一语义

主承接：**45-11 / W14 / S3起**。

**验收要求**：v5导航/AI入口/指标的线性SVG使用统一尺寸/描边与宿主sprite，装饰图标不重复朗读，图标按钮保留可访问名称；主题切换不改变意义。字体缺失、系统字体差异和长中文/英文标签下仍有稳定44px操作目标，品牌字标不作为唯一导航说明。

**需保留的证据**：图标/名称/i18n对照、屏幕阅读名称检查和字体差异样例；不重做品牌图标。

### V04 窄屏导航抽屉具备完整关闭与焦点契约

主承接：**45-04 / W14 / S1起**。

**验收要求**：导航抽屉打开后有标题/名称、关闭按钮与遮罩，背景不可交互，Tab/Shift+Tab在抽屉内循环；Esc/关闭/遮罩返回触发控件，选择场景则聚焦目标内容。切宽屏时关闭抽屉、恢复背景/滚动且不聚焦已隐藏菜单按钮；打开抽屉不取消会话或外发确认。抽屉触发模考离开等确认时先交接焦点与遮罩，不遗留两层模态陷阱。

**需保留的证据**：390/320px键盘循环、Esc/遮罩/导航选择、开着抽屉切宽屏和模考条件保留的操作记录。

### V05 视觉反馈刷新不重启页面或夺焦点

主承接：**45-07 / W14 / S1起**。

**验收要求**：区分换场景、局部输入/状态刷新和反馈展开：仅真正换场景使用页面入场，笔记输入、计时、保存/候选状态更新不重启动效、不把用户拉回顶部。题目提交后按既定反馈顺序聚焦；深浅主题、抽屉和弹窗关闭后仍能回到原控件/滚动锚点。

**需保留的证据**：编辑笔记、长解析提交、保存状态/计时更新、主题切换各自的焦点/滚动/动画记录。

### V06 表单说明、数值与错误在精细布局下可读

主承接：**45-05 / W14 / S1起**。

**验收要求**：项目/容量/页码/时间/把握度/导入映射保持可见label、单位、帮助和错误关系，不因新卡片布局把说明压成省略标签。错误在字段旁说明且可汇总聚焦首错；长译文、空值与IME组合输入不覆盖单位/按钮，连续数值更新保持可读而不每个字符播报。

**需保留的证据**：中文/英文长标签、无效页码/映射、空输入及中文组合输入的错误与读屏关联。

### V07 保存与审核徽章有可读的状态变化

主承接：**45-09 / W14 / S1起**。

**验收要求**：就绪、草稿待保存、保存中/已确认、失败/结果未知和离线用文字及适当标记区分，原型就绪点不代表真实写入成功；待审、已接受、已应用与受助也不靠绿色混同。灰度/forced-colors仍可识别，状态live播报只在有意义变化时发生，不能每次输入重新播报。

**需保留的证据**：状态转换表、灰度/强制颜色和读屏播报记录；与U06/U25的真实回执共同验收。

### V08 版式按宿主容器重排并处理长身份

主承接：**45-12 / W14 / S1起**。

**验收要求**：按实际Tab/Dock内容宽度实现主/辅列、指标、任务和AI卡片的重排，不能只读窗口innerWidth照搬原型断点。面包屑可省略但完整项目/目标可查；超长项目名、无空格英文、公式、表格与长选项各有换行/局部滚动策略，不能造成整页横溢或隐藏主操作。

**需保留的证据**：宽窗口窄Dock、320/390/960/1440容器、长项目名/题面与200%实际缩放的重排检查。

### V09 轻动效有范围并尊重用户偏好

主承接：**61-04 / W14 / S3起**。

**验收要求**：把页面入场与hover反馈限定为短时非必要提示；减少动效或用户关闭后取消位移/过渡，保持同样内容和状态顺序。AI流式/保存/计时不能触发整页动画，后台恢复不补播；成功提示不闪烁、不自动声音或庆祝，不以动画遮掩待确认状态。

**需保留的证据**：系统reduce/用户偏好/后台恢复下的computed style与操作记录及流式/计时更新抽样。

### V10 抽屉、浮层与消息适配动态可视高度

主承接：**45-13 / W14 / S3起**。

**验收要求**：在真实软键盘/安全区/横竖屏下核对导航关闭、笔记编辑、确认动作和toast；动态视口变化不能把dialog底部和下一步按钮藏到键盘后。滚动锁不得丢原页面位置或让遮罩穿透，消息不遮住当前主动作/字段错误；dvh/env样式回退按客户端验证。

**需保留的证据**：iOS/Android键盘开合、横竖屏、带安全区设备及抽屉/dialog关闭后的原滚动位置。

### V11 AI卡片分层保留长结果的审核上下文

主承接：**118-05 / W14 / S2起**。

**验收要求**：AI任务入口、实际输入、来源/目标差异、候选/缺项和应用回执分区呈现；长结果展开/复制/暂停阅读时保留来源、状态与目标，并让审核动作可达。流式未完成内容不显示已完成徽章或可应用主按钮；只对阶段变化播报，图形层次不能把建议分伪装成正式成绩。

**需保留的证据**：长/部分/缺证据/非法成果的键盘和读屏操作、来源/目标可查与应用按钮状态。

## 5. 原型验证与产品验收的区分

本轮Chromium布局检查覆盖15场景×1440/960/390/320px×深浅主题，共120组；未发现整页横向溢出、可见button/input/select操作目标不足44px（radio/checkbox核查其标签路径另取证）、脚本错误或外部请求。证据：[布局检查](../design/playwright/v5-layout-check.txt)。

另以首页/阅读/作答/AI/报告×1440/320px检查forced-colors与reduce，共10组，未发现布局溢出，页面animation为none、按钮transition为0s。证据：[强制颜色与减少动效](../design/playwright/v5-accessibility-check.txt)。这是浏览器CSS行为检查，不是完整读屏或真机验证。
