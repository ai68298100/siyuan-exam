产品定位为 **AI贯穿的本地可验证备考工作台**，围绕“题源→证据→行动→独立/延迟复测→个人知识资产/退出”。内容由用户提供；获准材料与个人内容可留思源，受限在线来源只留稳定指针、个人笔记和自报证据。AI给有依据的提案，确定性规则/人工确认负责评分、权限、FSRS和真实写入。

[融合执行规划](19-待办融合与分阶段执行规划.md) 将第36–125组 **620条**稳定编号归为 **27个工作包**；[全量索引](20-全量待办归并索引.md)逐项给主归属、最早纳入点和性质。它们是当前执行视图，原0–35组及下方版本目标保留历史，不能按旧版本顺序重复开发或把全部候选装进v1.0。

## 当前分阶段路线

| 阶段 | 用户得到什么 | 主要选入与边界 |
|---|---|---|
| S0 校准/选场景 | 当前能力和一个实际备考任务有可审阅依据 | 定位、真实阻断、原创fixture、目标前端/考种；文档整理已做，真机证据仍待补 |
| S1 可靠地基/契约 | 输入、作答、评分、保存和恢复准确 | 当前开放路径的保存、导入读回、模考/riff阻断；最小project/source/task/context/schema并行设计 |
| S2 基础资料/AI纵切 | 读看并记自己的笔记，获准片段变成待审题和可验证行动 | 无额外插件PDF/视频查看与笔记先可用；一条纯文本AI流与目标宿主只读/提案入口；不等全部考种/计划/桥 |
| S3 备考深化/公开质量 | 一项目的今日容量、模考、复测报告、考后退出闭合 | 分钟预算、多科取舍、考试配置、可访问性/性能、迁移及宣传证据；只对本次开放范围设门槛 |
| S4 条件扩展 | 有证据的场景增加深度和广度 | 更多考试域、复杂题型、教学、QTI/apkg、本地模型/多模态/转写、授权API和其他工具桥，先验证再选入 |

S1/S2中的“最小子集”不等于整项完成；原条目剩余验收保持未关闭。AI契约从S1开始，与可靠保存/题源/模式隔离并行；S2交付首条闭环。普通UI与思源智能体复用任务，但注册不等推理API，完整智能体/计划不能成为所有AI入口的前置。

最低资料能力是打开/播放、稳定页或时间点、个人批注/笔记编辑、保存与返回。OCR、字幕转写、片段AI、原件编辑、网盘API、思阅/思播/思盘及系统软件分别按真实能力增强。大型媒体默认外部保留，assets复制需体积/同步/许可预览；无第三方插件仍可手工继续。

下一批候选仅选 [docs/19的8个切片](19-待办融合与分阶段执行规划.md)：基线→可靠保存→小题库真实输入/读回→开放练习/模考/riff契约→最小AI共享服务→一条AI证据闭环→最低PDF/媒体笔记→当前范围的完整旅程/退出验收。契约与资料查看可并行；未来P0是启用该能力的条件，当前已开放的不可靠路径仍必须处理。

考试类型共用项目、题组、结构化答案、评分、版本与AI模板服务。学校/CET/KET/法考/CPA/CFA作为配置/域叠层，先选一个合法最小样例验证；不为各考试复制引擎。更多内容、真实模型调用和插件联动均待实现/实测，模板正文见 [docs/18](18-AI智能体与提示词模板规范.md)，来源研究见 [研究索引](../research/00-总览与功能矩阵.md)。

## 发布与范围约束

集市继续暂缓，TODO7B既有要求保留：≥3名内测用户连续≥2周无P0反馈、PRD验收1–5、文档/隐私声明、7.0约定功能补齐。按该范围附真实输入/前端/产物与人工证据，不扩义为620条全部完成；GitHub已发布也不代表这些门槛已通过。

激励不限制用户自配AI的学习帮助；真实模型费用/预算单独管理。转卡由用户明确选择，客观正确不自动变成FSRS Easy；rubric仅给建议分。启发式掌握度不能作为正式考分或通过率，考后对答案估分是不同能力。不引入内容运营/支付市场、订阅稀缺、云LMS、监控或全服排名。

## v0.1 · 刷题地基（MVP）

**旅程**：导入 Excel 题库 → 章节视图刷题 → 答错进错题本 → 错题重练。
- 题目块契约 + 题库笔记本结构 + **题目表单编辑器**（斜杆/块菜单，评审定为 v0.1 必备）
- 导入流水线 v1：Excel/CSV（字段映射/校验/去重/预览/先导 5 行）+ Aiken
- 练习台 v1：单题快刷 / 专项树 / 整卷；做题-背题双模式（会话头部切换）；会话续做
- **浏览模式 v1**：章节树 + 题目列表 + 单题详情（评审增补）；收藏（`exam-fav` 属性）
- **零决策今日任务**：顶栏直达会话（到期优先+每日一练补足）
- 错题本 v1：自动收录+作答快照、错因三分类、连对 2 次消灭、消灭进度条
- 基础统计：做题量/正确率趋势
- 设置面板骨架 + 模块开关机制 + zh/en i18n
