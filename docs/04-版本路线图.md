# 小驴考试 · 版本路线图

> 原则：每个版本都交付一条完整可用的用户旅程；P0 刚需先行，特色功能（背诵/AI/模考全真）按依赖顺序排入。

## v0.1 · 刷题地基（MVP）

**旅程**：导入 Excel 题库 → 章节视图刷题 → 答错进错题本 → 错题重练。
- 题目块契约 + 题库笔记本结构 + **题目表单编辑器**（斜杆/块菜单，评审定为 v0.1 必备）
- 导入流水线 v1：Excel/CSV（字段映射/校验/去重/预览/先导 5 行）+ Aiken
- 练习台 v1：单题快刷 / 专项树 / 整卷；做题-背题双模式（会话头部切换）；会话续做
- **浏览模式 v1**：章节树 + 题目列表 + 单题详情（评审增补）；收藏（`exam-fav` 属性）
- **零决策今日任务**：顶栏直达会话（到期优先+每日一练补足）
- 错题本 v1：自动收录+作答快照、错因三分类、连对 2 次消灭、消灭进度条
- 基础统计：做题量/正确率趋势
- 设置面板骨架 + 模块开关机制 + zh/en i18n

## v0.2 · 记忆层（差异化起步）

**旅程**：错题一键转卡 → FSRS 到期复习 → 四级自评 → 掌握度更新。
- riff 封装：建卡/到期队列/评级；FSRS 参数暴露（保留率+每日上限，含全局影响警示）
- 背诵模式 v1：盖答案+四级自评+"不会"排队尾+组结算
- 题目形态升降级（答错 2 次→背诵题；背诵 4 连→选择题）
- 每日一练完整版（到期优先+高频考点，固定 10 题；冲刺姿态聚合规则）
- 错题"举一反三"（同考点变式推荐）
- 错题/题目双链三件套 v1（来源跳转+反链聚合）
- **查询圈题**（查询嵌入块→练习集）+ **题库管理视图候选实现**（思源数据库 vs 自研，评审候选 #4）

## v0.3 · 模考场

**旅程**：配置组卷蓝图 → 全真模考（计时/答题卡/标旗）→ 成绩单四维报告。
- 组卷蓝图（模块×题型×数量×分值×来源）+ 错题/收藏变式卷
- 限时/分段计时、超时自动交卷、切屏计数
- 答题卡三态+跳题；全屏专注模式
- 成绩单：得分率三线对比、模块用时、最后 20 分钟、雷达图
- 掌握度树 + 薄弱 Top10 一键组卷 + 53 周热力图（报告中心 v1）

## v0.4 · AI 包（BYO key）

**旅程**：选笔记 → AI 出题 → 待审核队列逐题校对 → 入库练习 → 错题问 AI。
- AI 出题管线全流程（结构化 Schema/超量 1.5×/二遍核验/质量分门槛/pending 审核流）
- 讲解侧栏（逐选项解释/Hint/苏格拉底模式）+ 讲解存块
- Prompt Settings（内置公考/考研/医考/驾考预设）
- 薄弱知识点定向再生成
- GIFT/TSV 导入 + Word 导入（图片/公式→LaTeX）
