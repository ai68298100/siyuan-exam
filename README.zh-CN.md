# 小驴考试（Lv Exam）

思源笔记（SiYuan）上的**本地题库学习管理插件**：题库导入、刷题练习、模拟考试、错题本、FSRS 闪卡记忆、AI 讲解与出题。对标粉笔等刷题 App 的体验，但**题库长在用户自己的知识库里**——数据本地化、块级可检索、与笔记双链互通。

> 定位一句话：**粉笔的刷题体验 × Anki 的记忆科学 × 思源的知识库。**

## 功能模块（详见 [docs/01-功能全景PRD.md](docs/01-功能全景PRD.md)）

1. **题库引擎**：题目块 + 块属性 + 稳定 ID；章节/年份/题型/错题多维视图；全文检索
2. **导入流水线**：Excel/CSV 模板 → Aiken/GIFT/TSV → Word（图片/公式）→ Anki apkg → AI 录题；字段映射+校验+去重+预览，绝不整批失败
3. **练习台**：单题快刷 / 专项分类树 / 整卷；做题-背题双模式；选项乱序；会话续做
4. **错题本**：答错自动收录、错因三分类（粗心/不会/陷阱）、连对 2 次消灭、举一反三变式题
5. **记忆引擎**：对接思源内核 FSRS（`/api/riff/*`）；错题一键转卡；cram 考前冲刺不写回调度
6. **模考场**：组卷蓝图、限时/分段计时、答题卡标旗、成绩单四维报告
7. **背诵模式**：盖答案 + 四级自评（会/模糊/不会/熟知）+ 渐进提示链
8. **报告中心**：热力图、考点掌握度树（FSRS 衰减）、薄弱 Top10、可解释分数预测
9. **AI 模块**（自带 key）：出题管线（结构化 JSON + 来源块引用 + 待审核流）、讲解侧栏（逐选项/Hint/苏格拉底）
10. **备考计划 / 听学 / 激励**：考试倒计时反推计划、TTS 听题、streak 连胜、挑战码 PK

## 开发

```bash
pnpm i                # Node >= 24
pnpm dev              # watch 构建 + 热重载
pnpm make-link        # 软链到 <工作空间>/data/plugins/siyuan-exam/
pnpm check            # 类型 + svelte + i18n + 架构一致性检查
pnpm test             # vitest 单测
pnpm check:i18n       # 中英键一致性
pnpm check:arch       # 架构一致性（27 项）
pnpm verify:package   # package.zip 白名单校验
pnpm build            # 产出 dist/（当前不会生成 package.zip）
pnpm make-install     # 构建后安装到本机思源插件目录
```

内核运行于 `http://127.0.0.1:1568`（本机配置见 `%APPDATA%\siyuan\env`）。
