## 1. 定位

### 1.1 一句话

**思源笔记里的备考工作台**——把散落在笔记里的题库，变成一条有节奏、有证据、可复盘的学习流水线。

### 1.2 用户画像

| 画像 | 场景 | 关键诉求 |
|---|---|---|
 | **备考者**（主） | 考研/法考/CPA/CET/医考/驾照，8 周–12 个月周期 | 今天学什么、负载会不会失控、错题到底消灭没有 |
| **题库生产者**（次） | 老师/UP 主/机构，整理讲义成题 | 批量导入校对、批量维护、修订可追溯 |
| **思源重用户**（放大器） | 已在思源记笔记 | 题目与笔记同库、双链可达、数据不出本地 |

### 1.3 差异化（为什么不用 Anki / 考试宝）

1. **笔记即题库**：题目是思源块属性，不是另一个数据库——双链、引用、搜索天然可用，反形式数据孤岛（对比 Anki 的独立 collection、Obsidian-SR 的 `::` 语法）。
2. **证据化指标**：独立初答 / 受助作答 / 延迟复测分母分开，低样本如实标注——「不看提示答对才算会」（同类产品全部混在一个正确率里）。
3. **本地优先**：数据在你的思源仓库；AI 只出候选不做决定，外发分别确认（对比全云端 SaaS）。
4. **应试完整链路**：导入校对 → 练习 → 模考（蓝图/审计/冻结卷）→ 复盘 → 题库维护，而不是只有背卡。

### 1.4 非目标

- 不做通用背卡软件（FSRS 卡片侧依托思源内核闪卡生态）。
- 不做内容站：不提供题库，只管理你**有权使用**的题。
- 不做全自动学习规划：计划是建议，确认权在用户。

## 2. 信息架构

三 Tab 壳（练习台 / 模考场 / 报告中心）+ 每 Tab 上下文导航（Rail 复用）。原型路由 → 产品页面对照：

| 分组 | 原型路由 | 产品承载 |
|---|---|---|
| 项目首页 | `home` `project` `onboarding` | 练习台入口屏 / 设置页考试配置 / 首启引导（P1） |
| 资料与题库 | `sources` `reader` `import` `bank` | 练习台-资料/导入/浏览视图 |
| 学习与复测 | `practice` `review` `wrongbook` | 练习台-会话/背诵 / **错题本页（P0 新增）** |
| 模拟考试 | `mock-setup` `mock` | 模考场 Tab |
| 证据与知识 | `debrief` `report` `assets` | 报告中心 Tab（结算页/报告/资产） |
| 全局 | ⌘K 命令面板、toast、对话框 | 全局层（**P0 新增**） |

新增页面理由：**错题本**独立成页（对齐 Anki 卡组页 / 墨墨复习入口的心智——「去消灭错题」是一个主动作，不是筛选器）；**命令面板**（键盘优先，思源本身无全局搜索动作面板，插件可补位）。

## 3. 设计原则（评审时逐条对照）

1. **证据优先**：任何数字都要能回答「分子分母是什么」；口径不同的数字不并排换算。
2. **零决策开工**：首页第一按钮永远是「开始（零决策）」；计划是建议，不是表单。
3. **键盘优先**：⌘K 全局命令、1-4 选项、Enter 提交、E/K 翻题；焦点环 3px 永远可见。
4. **密度与呼吸**（Linear）：侧栏/工具条高密度（38px 行高），内容区大留白（卡片 24px 内边距、20px 间隙）；对齐优先于居中。
5. **克制用色**：中性面承担 ≥90% 面积；主色只出现在「开始/确认」类核心动作与焦点态；语义色成对（前景+soft 底）且只表达状态。
6. **状态完备**：每个数据位都有 loading（骨架）/ empty（图标+标题+动作）/ error（横幅+出路）/ normal 四态。

## 4. Design Tokens（`prototype.css` :root；实现见 `lv-tokens.scss`）

### 4.1 中性面（4 层明度差，靠明度分层不靠描边堆叠）

| Token | 亮 | 暗 | 用途 |
|---|---|---|---|
| `--bg` | `#f2f1ec` | `#13151a` | 页面底 |
| `--surface` | `#fffefa` | `#1b1e25` | 卡片/输入 |
| `--surface-2` | `#faf9f3` | `#21242d` | 卡内分区/th 底 |
| `--subtle` | `#eeede6` | `#272b36` | 徽章/内嵌块 |
| `--rail` | `#ebeae2` | `#16181e` | 侧栏 |
| `--border` / `--border-strong` | `#e2e3da` / `#d3d4c9` | `#2b303b` / `#3a4050` | 分隔线 / 控件边 |
| `--text` / `--muted` / `--faint` | 三档文字 | 同 | 标题 / 正文辅 / 微注 |

规则：实现端一律 `--b3-*` 变体映射（跟随思源主题），禁止裸 hex（`check-styles.mjs` 强制）。

### 4.2 主色与语义

- 主色靛紫：亮 `#6153d5`（-deep `#4a3fb8` 做渐变端/按压），暗 `#a99cf5`（on-accent 用深墨 `#1d1836`，不用纯白）。主按钮 = 垂直渐变 + 双层投影 + inset 高光，是全局唯一「重」的元素。
- 语义成对：green `#1f7a52/bg #e7f3ec`、amber `#925f10/#f9efdb`、red `#bb3e4c/#fbebee`（暗色各自换挡）。语义色只用于状态（对/错/到期/存疑），不用于装饰。

### 4.3 字阶（字号/行高/字重/字距）

28/1.35/700/-0.02em（h1）→ 22（hero h2）→ 17/650（h2/分区）→ 14.5（h3）→ 14/1.65（正文）→ 13（表单/次级）→ 12（辅助）→ 10.5/700/+2px 大写（eyebrow/nav-label）。数字一律 `tabular-nums`（`.num`），大数字 -0.02~-0.03em 收紧。中文排版基准：PingFang SC / Microsoft YaHei，行高 ≥1.6。

### 4.4 几何与海拔

- 圆角梯度 `--r-1..4 = 8/12/18/22`；嵌套时外大内小（卡 18 → 内块 12 → 键帽 5-7）。
- 阴影三级 `--shadow / --shadow-raised / --shadow-pop`：全部多层低透明度叠加，禁纯黑硬阴影；暗色换深档。悬停抬升只给可点卡片（`translateY(-1px)` + raised）。
- 间距 4px 栅格：卡片内边距 24（紧凑 20）、组件间隙 16/20、屏头下 28。

### 4.5 动效

统一曲线 `--ease cubic-bezier(0.22,1,0.36,1)`；三档时长 140/220/320ms；只动 `transform` / `opacity`；视图入场 appear、浮层 rise、进度条 width 过渡；`prefers-reduced-motion` 全禁。

## 5. 组件规范

### 5.1 壳层

- **侧栏 Rail**（236px）：品牌位（渐变 mark 36×39 + LV EXAM 字距 2.2px）→ 项目卡（kicker 10px 字距 + 名称 + ↗ 同行）→ 分组标签（10.5px 大写）→ 导航行 38px/9px 圆角；激活态 = surface 底 + 3px 左指示条 + accent 文字 + shadow-1；组级徽标（如错题 12）。≤1023px 转抽屉 + 遮罩。
- **顶栏**（64px，sticky + 轻磨砂）：面包屑（muted 上级/550 当前）· 保存状态点 · ⌘K 入口 · AI 下一步。
- **Subnav**：文字 + 底部 2px 指示条，非按钮块。

### 5.2 动作

- **按钮**：`primary`（渐变+投影，唯一强调）/ `quiet`（细边中性）/ `ghost`（无边）/ `danger`；尺寸 md 44px / sm 34px。禁用 0.55 + not-allowed。焦点环 3px。
- **命令面板**：⌘K 唤出；输入框 + 分组列表（页面/动作）+ ↑↓ 选择 + Enter 执行 + Esc 关闭；关键词别名（kw）支持中英文；空态给可试词。产品化时命令集 = 路由 + 模式启动 + 主题切换 + Recent。
- **徽章 pill**：7px 圆角贴纸（非胶囊）；accent/good/warn/bad 四语义 + 默认中性；可点态（筛选 toggle）hover 出 accent 边。
- **工具行「更多」菜单**（2026-10-08）：高频工具内联（≤3 个 chip），维护面板与导出打印收进卡片语言的下拉菜单（surface + pop 阴影 + 38px 行）；`menuitemcheckbox` 语义、面板开启出点标、Esc/点外关闭、开启即焦点入菜单。适用于工具型工具条 >8 个动作的场景。

### 5.3 数据展示

- **指标卡 metric**：标签（12px muted）+ accent 图标 chip（右上）+ 30px tabular 大数字 + muted 说明（写口径）。四联排，≤960px 两联。
- **目标环 goal-ring**：conic-gradient + mask 环（74px），中心百分比；语义档 good 用绿。承诺口径：当日完成/目标题数。
- **负载预测 forecast**：7 根圆角柱，今天 accent 渐变、峰值 soft 高亮，轴标周一…今天；数据源 FSRS 到期预测（P0 规划项）。
- **连胜 streak**：暖渐变圆角块 + 火焰图标 + 天数 + 冻结点（2 个）+ 下一里程碑差值。文案克制：只陈述事实与差距，不喊口号。
- **进度/图表**：`.progress` 7px 轨道 + 渐变填充；`.chart-row` 98/1fr/52 三栏（标签/条/值）；数据表 `.table-wrap` 圆角包边 + th 浅底。

### 5.4 表单与作答

- **输入**：44px 高、ctl-border、11px 圆角；hover 边框 accent、focus accent+ring；select 同规。
- **选项 option**：radio/letter + 题干行；hover 边框 accent；选中 soft 底 + ring；正确/错误 green/red 成对（`.option.correct/.wrong`）。
- **自评键帽 rate-key**（2026-10-08 融合自 Anki 现代改造共识）：四级自评（背诵 1-4 / 内核 Again-Hard-Good-Easy）的等级代号做成**常显语义色键帽**（red/amber/green/accent soft 底），按钮本体保持中性，hover 再整钮染色——等级一眼可扫，键盘提示不再隐形。实现端 `.lv-rate-key` 与原型 `.rate-key` 同构。
- **反馈横幅 feedback**：左 3px 语义边 + soft 底；只陈述事实与正确答案，顶部不给情绪化大字。
- **答题卡 answer-sheet**：5 列 44px 格；done=soft 紫、flag=amber 描边、cur=实心。

### 5.5 反馈与浮层

- **对话框**：22px 圆角 + pop 阴影 + overlay 背板；动作区顶部分隔线、右对齐、主按钮在最右。
- **Toast**：底部居中、文字色反底、≤4.2s；不打断焦点。
- **空态 empty**：图标块（soft 底 accent 图标）+ 标题 + 一句解释 + 1 主 1 次动作；禁止拿 error 横幅当空态。
- **骨架屏**：shimmer 渐变块，占位尺寸贴近真实内容。

## 6. 逐页规范（目标 / 关键构成 / 状态）

> 每页都必须满足：四态可达、键盘可达、口径脚注存在、空态有出路。

- **home 项目首页（驾驶舱）**：目标 = 回答「现在做什么 + 今天做多少 + 负载是否失控」。构成：屏头 → 今日任务 hero（推荐语 + 时长 chip + 零决策开始 + 可用分钟预算）→ **widgets 三联（目标环 / 7 日负载 / 连胜）** → 今天的三件事（任务列表）→ 右栏（从材料开始 / 待你确认 / 收尾去处）。空库 = `emptyPanel`（选资料 / 导入 / 手工）。数据：目标=当日队列容量；负载=FSRS 到期预测；连胜=本地流水（冻结规则见 TODO 8 组）。
- **onboarding 首次引导（P1）**：三步卡（建项目 → 装题 → 开练）+ 示例数据 CTA + 三个定位 metric 卡；完成后不再出现（47-02 已有 lite 版）。
- **project 项目与配置**：字段栅格 + 影响预览；换范围先看影响。
- **sources / reader**：资料三分（本地原件 / 外部指针 / 在线受限）；阅读器纸面 + 笔记分层。
- **import**：三步向导（来源 → 映射校对 → 试导结果）；失败行单行修复；对齐 Anki 23.10「导入重设计被称赞」的经验：预览先行、错误可就地修。
- **bank 题库与作者**：搜索 + 列表（task-number + 练这道题）；修订时间线（43-01）与判分规格（54-02）固定入口；作者检查在侧栏。
- **practice 独立作答**：主纸面（chips + 题干 + options + 把握度 + answer-actions）+ 右栏本次条件 / 键盘；受助=warn 徽章；严格模考中 AI 关闭（mock 复用同构）。
- **review 复测与复习**：先回忆（textarea）→ 对照依据；受助不计独立。
- **wrongbook 错题本（P0）**：目标 = 让「消灭错题」成为主动作。构成：三指标（在册/本周消灭/平均滞留）→ 消灭进度（百分比 + 预计清空）→ 错因分布（假设口径）→ 队列（到期×错次加权，行内重练）+ 聚类动作；右栏重练策略（加权回流/只练到期/转卡）+ 去向（已转卡/已消灭/存疑）。口径：连对 2 次移出；错因可改判。
- **mock-setup / mock**：蓝图配卷表格 → 严格作答（分段计时 / 答题卡 / 标旗 / 交卷审计）。
- **debrief**：事实→假设→行动 flow；逐段满分按实际卷面（40-02）；下一行动需确认。
- **report**：上下文 chips → 三 metric → **信心×结果四象限**（quad-grid；第 4 格中性档）→ 各考点证据（chart-rows + 正确率趋势虚线）→ 证据不足 → 数据表（文本等价物）。口径脚注必须写明 KPI/热力为流水口径、掌握度为独立题口径 + 算法标注。
- **ai**：任务三联（整理/讲解/下一行动）+ 待审队列（可编辑/重生成/逐条审）。
- **assets**：知识资产与退出（归档/迁移/保留）。
- **settings**：宿主设置渲染，语义对齐 §7 去重/口径/预算等条目。

## 9. 可达性

焦点环**永远可见**（含暗色）：`1px surface 断层 + 4px 主色环`（ring-offset 语言，Geist/shadcn 同款；2026-10-08 由纯 3px 环升级）；44px 触控下限（徽章/键帽除外）；语义角色（radiogroup/checkbox/progressbar/aria-current）；对比度：正文 ≥4.5:1、大数字 ≥3:1（亮暗各自实测）；forced-colors 全组件兜底（见 css 尾段）；面板焦点循环 + Esc 归还。

- **Obsidian Spaced Repetition 插件**：卡组=标签/文件夹聚合、复习页（Easy/Good/Hard + 统计 + 快捷键）、整笔记复习模式；后来者 LearnKit 主打 FSRS + 丰富题型。[obsidian-spaced-repetition](https://github.com/st3v3nmw/obsidian-spaced-repetition)
- **墨墨背单词**：「学习量 = 复习量 + 建议新学量」的整体预算观、遗忘临界点调度、克制的无广告界面是其口碑核心。[墨墨·认识模糊忘记](https://www.maimemo.com)、[产品分析（知乎）](https://zhuanlan.zhihu.com)
- **游戏化机制**：streak + 进度条是被引用最多的留存机制，排行榜/XP 次之（Duolingo 模式综述）。[ICSSIET 论文集](https://www.academia.edu)
- **Linear**（质感基准）：⌘K 命令菜单、键盘优先、密度与对齐、微细节打磨、克制暗色 + 紫色点缀。[How we redesigned the Linear UI](https://linear.app/now/how-we-redesigned-the-linear-ui)、[A calmer interface](https://linear.app/now/behind-the-latest-design-refresh)、[Command Palette 8 States](https://www.setproduct.com)、[Linear 快捷键总表](https://shortcuts.design)

> 对小驴的取舍：采纳「负载预算 / 错题主动作 / ⌘K / 密度微细节」；**不采纳**排行榜社交与 XP 积分（与「证据优先、反虚荣」定位冲突，徽章只做里程碑陈述）。

### 10.1 增量调研（2026-10-08，gh 源码级 + Web 最佳实践）

- **Anki 新 TS/Svelte 前端**（[ankitects/anki](https://github.com/ankitects/anki) `ts/routes`）：graphs 为响应式卡片栅格（3→2→1 列），图表元素可点击下钻进筛选浏览器（`graph-element-clickable`）；社区现代改造的主流共识是「评分按钮 2-4 个大目标、语义色可扫视、保留键盘」。→ 融合：背诵自评按钮数字键帽常显语义色（红/琥珀/绿/主色），hover 再整钮染色（`fusion-recite-reveal.png`）；图表保持静态但口径脚注齐全，可点击下钻待数据契约后评估。
- **Anki 评分按钮显示下次间隔**（AnkiWeb Studying 文档默认行为）：间隔由思源 FSRS 内核产出，插件侧暂无契约透出——**不采纳**（不如实不显示），保留 1-4 快捷键。
- **现代焦点语言**（Geist/shadcn ring-offset 模式）：焦点环带 1px surface 断层 + 4px 主色环。→ 已融合进 `--lv-ring` token，全组件焦点态升级。
- **复习屏最小 chrome + 主题化选区**：作答页保持低 chrome（已有）；`::selection` 跟随主色（已融合）。
- 其余候选（进度环庆祝、图表 hover 十字线、热力图月份标尺）均需 JS/数据契约或与「克制动效」规范冲突，本轮不采纳，留档待评估。
