# 开源题库与主流备考系统竞品调研（2026-10-19）

> 调研对象涵盖国际顶级开源记忆工具（Anki、RemNote、Obsidian Spaced Repetition）、国内主流备考平台（粉笔、考试宝、华图）以及专业机考测评标准（IMS QTI 3.0、国家医考 CBT 系统）。
> 核心目标：结合小驴考试现有思源本地题库架构，提炼出高价值、低依赖且能大幅提升用户做题手感与备考深度的产品待办。

## 二、 提炼形成的新增增量待办清单

基于以上调研，我们为小驴考试规划出以下具备高度可用性与工程落地性的精品化待办：

### 1. 【做题与复习体验深化】
* [ ] **44-09 快速撤销作答（Undo Submission）**：在专注练习中，若刚刚按回车或选项误触提交，支持在 3 秒内按 `Ctrl+Z` 或点击“撤销作答”，恢复到作答前草稿状态，并安全回滚刚才的一条 `AttemptEvent`。
* [ ] **52-08 演算草稿纸画板浮层（Scratchpad Modal）**：做行测、数学或复杂计算题时，提供右上角悬浮便签或纯白板涂鸦/文本演算区，不遮挡题面，支持快捷键一键唤起。
* [ ] **52-09 思源正文双花括号/双等号高亮出题（Cloze Generator）**：选中文档中带有 `==重点词==` 或 `{{挖空词}}` 的段落，一键批量识别并转化为填空题入库。

### 2. 【题库管理与生产效率】
* [ ] **43-07 题库全文快速去重合并助手（Duplicate Merger）**：利用现有的 2-gram Jaccard 相似度算法，在题库健康面板中提供并排“两题对比与一键合并”操作，允许保留一条并迁移另一条的全部作答历史。
* [ ] **55-05 主观解答题结构化采分点（Subjective Rubric）**：为简答题与论述题配置 2–5 个采分点（权重比例如 40%/30%/30%），交卷后支持用户逐项自评“满足/部分满足/未达标”，并计算综合得分。

### 3. 【测评与学习报告】
* [ ] **63-04 知识点掌握度能力雷达图（Knowledge Radar Chart）**：在复盘报告中，按考点树顶层前 6–8 个核心板块，绘制个人能力雷达多边形（展示正确率与作答频次覆盖）。
* [ ] **63-05 备考周赛与虚拟排名模拟（Mock Percentile Curve）**：在全真模考成绩单中，基于正态分布模型计算用户成绩在虚拟考生池中的百分位排名（Top N%）。
