# 学生备考与教师教研双角色深度调研与整体架构方案（2026-10-22）

> 调研背景：小驴考试作为思源笔记生态中的本地优先题库系统，核心用户自然分化为两大高价值群体：
> 1. **学生与在职备考者**：以“通关考试、高效刷题、错题攻坚、考前冲刺、知识沉淀”为首要目标；
> 2. **辅导老师、教研员与机构助教**：以“试题录入审校、考纲对齐、全真组卷、双栏打印排版、作业分发与学情诊断”为核心诉求。
> 本调研系统剖析两大角色的差异化需求，对标行业标杆，提出“双视角工作台 + 教师讲义排版 + 作业集交付”的完整工程方案。

---

## 一、 两大核心用户画像与诉求差异化对比

| 维度 | 角色 1：准备考试的学生 / 上班备考人群 | 角色 2：辅导学生的老师 / 题库作者 |
|---|---|---|
| **核心使用目标** | 快速消灭知识盲区、提高刷题正确率、顺利通关考试 | 打造高质量题库资产、编制标准化测验试卷、授课点拨与学情把控 |
| **高频触发场景** | 每日打卡、地铁/通勤碎片刷题、错题复盘自诊断、考前模考仿真 | 扫描录题、大纲变动对照、题目质量校准、组卷排版打印、分发作业 |
| **界面心智需求** | **极简、专注、无干扰**：不想看到复杂的数据库属性、代码修补、冷门导入设置 | **专业、全能、可控制**：需要细粒度设置分值、采分点 Rubric、生命周期、导出格式 |
| **对试卷的需求** | 纯净作答卷（安全红线：绝不能提前看到答案与解析） | 1. 学生作答卷；2. 详解答案册；3. **教师专用讲义教案卷（含破题点拨与拓展）** |
| **错题视角** | “我为什么错？下次怎么不错？”（自诊断、思维陷阱分析） | “班级易错分布在哪里？哪道题区分度差/是死题目？”（CTT 指标、教学重点） |

## 二、 同类产品与行业标杆深度调研

### 2.1 学习者端（Student-Centric）标杆经验
1. **粉笔 App / 金考典**：
   - **极速手感**：单选即选即跳，错题停顿，错题消灭有明确阶梯；
   - **考期牵引**：首页即是大倒计时看板与每日任务环，给在职考生明确的作息减负；
   - **考场仿真**：主观题提供 20×20 规范作答纸，字数超限实时标红。
2. **Anki / FSRS-5**：
   - 算法驱动间隔复习，但在模考、题库成卷与笔记回跳上体验割裂；
   - **思源+小驴考试优势**：题目即是思源块，做错题可一键跳回笔记原文，知识长在笔记库中。

### 2.2 教师教研端（Educator-Centric）标杆经验
1. **学科网 / 组卷网 / 21世纪教育网**：
   - **标准排版输出**：提供 A4/A3 双栏排版试卷、密封线、考号填涂区、答题纸；
   - **教师教案讲义卷**：除了提供给学生的空白卷，核心卖点是**【教师专用讲义卷】**（每道题下方直接附带【考点解析】、【思维方法点拨】、【评分细则采分点】与【变式拓展题】），老师可直接带进课堂讲课！
2. **Canvas LMS / Google Classroom / 问卷星考试**：
   - **作业/测试集标准化分发**：出卷人能够导出一份具备不可变约束的作业包（如限定考试时长 60 分钟、禁止查看答案、不可倒退交卷），受测人导入后严格按规程作答。
3. **经典测验理论（CTT）与题目质量评估**：
   - 区分度 $D < 0.2$ 提示题质低劣或题干有争议；
   - 选项选择率直方图：检出从来无人选择的 0% “死干扰项”，指导老师修订题目。

## 三、 小驴考试双角色协同整体架构方案

```
                     ┌─────────────────────────────────────────┐
                     │          小驴考试统一数据内核           │
                     │ (思源块属性 + 流水日志 + 不可变快照)    │
                     └────────────────────┬────────────────────┘
                                          │
                  ┌───────────────────────┴───────────────────────┐
                  ▼                                               ▼
     【👨‍🎓 备考学员专注工作台】                       【👨‍🏫 教师教研专业工作台】
  ┌─────────────────────────────────┐           ┌─────────────────────────────────┐
  │ • 今日驾驶舱 & 考期倒计时看板   │           │ • 题库制作 Studio (录题/OCR/资料)│
  │ • 极速刷题流 (即选即跳/错题顿歇)│           │ • 题目作者生命周期 (草稿/审校)   │
  │ • 速记标签系统 (⭐️好题/⚠️陷阱) │           │ • 题目质量治理 (区分度/死干扰项) │
  │ • 错题四要素自诊断与消灭门槛    │           │ • 全真蓝图智能拼卷 & 答题卡设计 │
  │ • 主观题实时字数 & 20×20方格纸  │           │ • 🖨️ A4双栏试卷 / 教师备课讲义卷 │
  │ • 原书笔记双向回跳与深度复盘    │           │ • 📦 便携作业测验包生成与分发   │
  └─────────────────────────────────┘           └─────────────────────────────────┘
```

### 3.1 核心设计原则
1. **单一题库，双向视角**：
   - 题库底层数据完全打通，但顶层根据用户身份进行视觉降噪与能力聚焦；
   - **学员视角（Learner View）**：默认隐藏批次回滚、属性维护、生命周期流转等复杂出题设置，专注“今日要学什么、当前怎么做、错题怎么改”；
   - **教研视角（Author/Teacher View）**：激活出题工作台（Studio）、题目审定、CTT 质量分析、A4 出卷与讲义排版、作业包生成。
2. **教师专属武器：【教师备课讲义卷】（Teacher Lecture Sheet）**：
   - 目前系统已有“学生作答卷”（绝不泄题）与“答案册”；
   - **增量落地**：在 `printPro.ts` 中实现 `buildTeacherLectureSheetPro`，在每道题目下方排版呈现：
     - 正确答案（粗体显眼）；
     - 考点归纳与难度星级；
     - 主观题采分点（Rubric Criteria）逐项赋分依据；
     - 详细破题逻辑与教学点拨（Analysis）；
     - 完美支持 A4 双栏紧凑打印，老师一键打印即可作为上课教案与讲义。
3. **教学分发闭环：【学生作业测试包】（Assignment Pack）**：
   - 老师在题库或模考中选择题目，一键打包为便携作业集（`.examset.json`）；
   - 内置教师设定的建议作答时长、及格线、作业说明与防泄密约束；
   - 学生直接通过导入窗口选择导入，立即进入对应作答模式。

## 四、 本轮实施交付清单

1. **底层引擎增强（`src/core/printPro.ts`）**：
   - 实现 `buildTeacherLectureSheetPro`：支持生成出版级【教师授课与备课讲义卷】（包含题面、答案、考点、采分点规范、教学解析与数学公式）；

   - 扩展作业/测验集规格 `AssignmentPackSpec`，支持教师预设作业标题、时长限制、截止说明与不可变试卷指纹；

   - 挂载 `buildTeacherLectureSheet` 与作业集生成方法；

   - 在模考与题库导出中增加【👨‍🏫 教师讲义教案卷】导出按钮；
