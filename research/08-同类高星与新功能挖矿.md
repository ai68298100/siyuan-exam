## 一、逐产品

### 【第一轮：开源高星 / FSRS 生态新星】

### 1. Revu（revu.cards，开源 GPL-3，macOS 原生 + Web 版）

**定位一句话**：本地优先、围绕 FSRS + 检索练习（引 Dunlosky 2013）的开源学习 App，独有的是"日历感知的复习排期"。

**独有功能机制详述**：
- **Autopilot 排期**：FSRS 计算到期卡片 → 同步用户 Google/Apple ICS 日历找空闲时段 → 自动生成"7 天学习计划"放置学习块；错过的内容滚动进后续会话。
- **考前冲刺模式（exam cramming）**：考试临近时自动把学习时间"约三倍化"。
- **Coverage mapping（覆盖度映射）**：跟踪用户材料中"哪些内容还没有被做成卡片/没有被复习过"，考前暴露盲区——这是对"只复习已制卡内容"这一 SRS 通病的修补。
- 卡型：问答/填空/多选；Anki .apkg 导入；完全离线。

**借鉴价值**：★★★★★（日历感知排期 + 覆盖度映射 + 考前加倍，均为小驴"备考"场景可直接落地的机制）

### 2. True Recall（pieralukasz/true-recall，Obsidian 插件，64★，2026-10 活跃开发）

**定位一句话**：Obsidian 里的"下一代 SRS"，把 AI 制卡做成了一套有工作流的产品（而非一键生成按钮）。

**独有功能机制详述**：
- **AI Inbox（收件箱式 AI 工作流）**：每一次 AI 请求（选中文本生成卡片、润色既有卡片）都变成一个"线程"，用户可逐条 **应用 / 拒绝 / 重试**——AI 结果永不直接入库，人始终在回路里。
- **Projects 系统**：卡片与笔记多对多组织；子项目**继承父项目的 FSRS 预设**。
- **25+ 内联 codeblock 小部件**：仪表盘、统计、日历热图、预测图表等可嵌入任意笔记。
- **Typed Answers 双轨批改**：输入答案后可选 AI"教师式判分"或无 AI 的 diff 比对。
- **并发复习合并**：多设备同时复习通过"回放 review log 过 FSRS"合并冲突。
- 本地 SQLite（vault 内 `.true-recall/`），APKG/CSV 导入导出，21 参数 FSRS-6（400+ 次复习后个人化优化）。

**借鉴价值**：★★★★★（AI Inbox 是"AI 制卡不做垃圾场"的最佳实践；思源插件可直接抄这套交互范式）

### 3. MySummaries（mysummaries.app，商业，ts-fsrs）

**定位一句话**：把用户自己的资料变成"空间学习板"，并在闪卡之外自动生产**书面卷 + 口语考官**两种考试形态。

**独有功能机制详述**：
- **口语考官（oral examiner）**：WebRTC 语音对话提问 + 追问，对 transcript 按 rubric（评分量规）打分。
- **错题自动回卡**：书面卷/口试中答错的问题自动转成新卡片，并与既有卡组**去重**。
- **drill 队列**：`enable_short_term: false`——忘记的卡不当天以短间隔再现，而是进"同会话钻练队列"，避免垃圾短周期。
- `enable_fuzz: true` + `maximum_interval: 365`：同批生成的卡不再"齐步走"，且无排期超过一年。
- 跨科目/跨主题 due 队列聚合；音频讲座带逐词跟读。

**借鉴价值**：★★★★（错题自动回卡去重、drill 队列、fuzz 防齐步走都是低成本高收益机制）

### 4. Quanta Study（quanta-study.de，商业，德语区，ts-fsrs）

**定位一句话**："引用优先"的 AI 出题平台——每张卡在生成前必须挂上可验证的学术来源。

**独有功能机制详述**：
- **强制来源声明**：AI 从主题/PDF/照片/URL 生成卡片时必须先给出 Google Scholar/Wikipedia/教材等出处（≥0.90 置信阈值）才允许生成——针对"AI 编造"的信任设计。
- **干扰项按规范生成**：多选题 distractor 遵循 Haladyna & Downing 的选项设计指南（心理学界的经典 MCQ 编写规则）。
- **Bloom 分类学控制**：交互式"布鲁姆金字塔"让用户指定题目考记忆/理解/应用/分析哪个层级。
- **费曼法 AI 导师**、LaTeX 渲染、经典/无尽/模考三种 FSRS-6 复习模式。

**借鉴价值**：★★★★（来源挂链 + 置信阈值 + 干扰项规范，是小驴"AI 出题可信化"的三件套）

### 5. HSRS / grsly（satchelspencer/hsrs，开源）

**定位一句话**："非原子"层级 SRS——一次复习同时包含许多嵌套概念，且每次复习动态生成全新题目。

**独有功能机制详述**：
- **参数化语法卡**：一张卡是一个"参数树"（语法结构），每次复习按用户当前知识水平**实例化出一个新例句**，各组成部分（词汇等）按用户掌握度挑选——复习永不重复、且难度自适应。
- **贝叶斯子卡联动调度**：对一张卡的复习结果，用贝叶斯统计估计各子概念对该结果的贡献，进而**重排整棵参数树上所有子卡的调度**；FSRS 的稳定性变化在"可提取性空间"按概率插值传播。
- 解决的问题：原子卡学语法 = 死记描述或孤立例句；非原子卡让"结构知识"也进入 SRS。

**借鉴价值**：★★★（思想极具启发性：题库中"同一考点的变式题"可以用参数化模板生成，复习一次考点=重排其下所有变式；实现复杂度高，适合远期）

### 6. LinGoat（lingoat.app，商业，py-fsrs）

**定位一句话**：把"每个词/每条语法"各自调度，再把多个到期概念**堆叠进同一个翻译句子**里练习。

**独有功能机制详述**：
- 句子里的每个单词和语法点都有**独立的 FSRS 日程**，复习由"逐项回忆数据"而非"整句对错"驱动。
- **到期概念堆叠**：一句翻译题刻意同时塞入多个到期/将到期的概念，最大化"每分钟有效复习次数"。

**借鉴价值**：★★★（"一题多考点到期感知"可用于小驴的组合题/多选题生成：优先出"同时覆盖多个到期考点"的题）

### 7. Flipnem / spacedrep / MemPro（MCP 三兄弟）

**定位一句话**：2025-2026 的新趋势——把卡组/题库通过 **MCP server** 交给用户自己的 AI agent 操作。

**独有功能机制详述**：
- **Flipnem**：Anki 兼容在线闪卡平台，内置 MCP server，用户的 AI agent 可连接其收藏进行"出题测验、卡组管理、助记符强化"；另有助记符字段、卡组加密、公开进度主页。
- **spacedrep**（wpwilson10/spacedrep）：CLI + MCP server，.apkg 导入导出，专为脚本和 AI agent 工作流设计，无 GUI，上 PyPI。
- **MemPro**：编程学习 SRS，卡面即代码题——浏览器沙箱跑测试判对错后再让用户自评记忆等级；同样提供 MCP server 供 Claude Code/Cursor 自建卡。

**借鉴价值**：★★★（小驴可预留"MCP/命令行只读暴露题库与学习数据"的口子，让用户的 AI 助手能查错题、出题；P2-P3）

### 8. LeetFlash（leetflash.com）

**定位一句话**：自动捕获 LeetCode（含力扣中国）提交记录，把"你真实做过的题"变成 SRS 复习流。

### 【第二轮：移动 / 桌面端新品】

### 10. Markji 墨墨记忆卡（markji.com，墨墨公司出品）

**定位一句话**：墨墨背单词团队推出的通用闪卡 App（考研/考公/考证/外语），搭载自家 MMX 记忆算法。

**独有功能机制详述**：
- **MMX 算法**：FSRS 同源（FSRS 起源于墨墨 DHP 模型），但迭代依据不同——FSRS 靠离线 benchmark（RMSE/LogLoss），MMX 靠**线上真实用户 A/B 实验**（任务完成率、留存、学习时长）。
- **著名公案**：墨墨用 8,982 名新用户做了 FSRS-6 的 30 天线上 A/B（4,570 vs 4,412 人），发现离线指标更优但**线上学习效率无优势、活跃留存反而负面**（两组保持率约 75%，低于 85% 目标），结论"未成功"，并称离线指标驱动的算法迭代是 "wrong way"。
- 启示：算法调参的终极裁判是留存与完成率，不是离线误差；小驴若做 FSRS 参数个性化，应观察"七日留存/每日完成率"这类目标指标。

**借鉴价值**：★★★★（国产大厂通用闪卡的新动向 + 算法评估方法论；对 FSRS 选型的"反方证据"必须知情）

### 11. 练题狗（liantigou.com，3000 万+题库）

**定位一句话**：主打"AI 智能推题"的职业资格刷题 App，把"薄弱点定位→推题优先级→顽固错题"做成一条流水线。

**独有功能机制详述**：
- **正确率自动标注薄弱知识点**：界面上直接写"该类型正确率仅 42%，建议加强训练"。
- **动态推题优先级**：正确率越低的考点，相关题的推送优先级越高；推题精准度随做题量"越刷越准"。
- **顽固错题反复推送**：反复错的题持续回流推送队列直至做对。
- **错因三分类归因**：知识点缺失 / 审题失误 / 粗心大意，各生成针对性巩固计划。
- **21 天抗遗忘训练**：1→3→7→21 天多轮间隔复习节点；AI 解析标注易错陷阱 + 推荐变式题（举一反三）。

**借鉴价值**：★★★★★（错因三分类 + 顽固错题概念 + 变式题推荐，是 07 号报告错题本机制的最佳增量补强）

### 【第三轮：学习科学产品化】

### 15. Math Academy（mathacademy.com，商业，公认"学习科学产品化天花板"）

**定位一句话**：把八种认知科学策略工程化到"每题都由知识图谱驱动"的数学学习系统，创始人 Justin Skycak 写有《The Math Academy Way》设计文档。

**独有功能机制详述**（实测官网 pedagogy + how-it-works 两页）：
- **自适应诊断（30-45 分钟，可分段）**：同时测量 mastery 与 automaticity，把学生放在"知识边界"，已会内容零重复；识别出的低年级基础缺口**与当前课程并行补齐**（而非停下重修）。
- **层级化间隔重复**：追踪**每一道题**的作答并更新个人学习曲线；"spaced repetition profile"记录学生对全数学体系每个主题完成的有效复习次数，知识图谱节点颜色越深蓝=记忆越稳定。
- **交错复习（interleaving）**：每个复习作业混合大量已学主题，训练"把题目匹配到正确解法"的鉴别能力。
- **非干扰（non-interference）**：相似概念不同时/连续教，防前摄/后摄干扰；会话内刻意搭配不相似材料。
- **测验驱动复习**：每 150 XP 一次测验，错哪个主题立即变为复习主题，复习达标后可重测赚额外 XP。
- **精通即推进 + 微知识点**：微积分拆成约 1000 步（300 知识点 × 3 难度阶段），比普通教材细 10 倍；连续答对 2 题即过关；每知识点先 worked example（带 subgoal labeling 步骤分组 + 图示 dual-coding）再做题。
- XP≈1 分钟专注学习；周联赛，XP 永不清零。

**借鉴价值**：★★★★★（诊断→并行补漏、测验驱动复习、考点鉴别式混排，三项均可降维落地到小驴）

### 16. iDoRecall（idorecall.com，Barbara Oakley 背书）

**定位一句话**：闪卡必须**链接回源材料精确位置**的检索练习工具。

**独有功能机制详述**：
- 每张"recall"（闪卡）链接到学到该概念时的**源材料精确位置**：PDF 页码、视频时间码、网页片段、笔记位置。
- 复习时想不起来 → **一键跳回原文现场**刷新记忆（不是看答案，是回到学习情境）。
- Web clipper 边读边制卡；视频挂时间码；另有 Obsidian 插件版链接笔记精确块。

**借鉴价值**：★★★★★（思源块引用天然就是"源位置"——错题/闪卡挂块引用、复习失败跳回笔记原文，是小驴差异化于所有独立 App 的杀手锏）

### 17. Clozemaster（clozemaster.com）

**定位一句话**："海量语境挖空"——用词频排序的真实句子填空做大规模暴露，SRS 只是辅助。

**独有功能机制详述**：
- 句子按**词频表**组织，进度按"你对最高频词的掌握度"追踪（先高频后低频的覆盖率设计）。
- 掌握度百分比制：连续答对推进 1→10→30→180 天固定间隔（刻意简化保游戏感，被 Anki 用户批评但留存好）。
- 挖空=完形填空（cloze）而非翻译题：考"在语境中识别"而非"凭空回忆"。

**借鉴价值**：★★★（"按考点词频/考频排序的完形式刷题"可做小驴的轻量模式；固定简化间隔的用户体验值得与 FSRS 精细度权衡对比）
