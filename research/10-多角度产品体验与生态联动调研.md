# 多角度产品体验与生态联动调研（2026-10-02）

> 本报告只产生规划输入，不代表功能已经开发。新增候选待办写入 TODO.md 第 43–50 组；每项仍需经过真实思源环境、版本能力矩阵和固定 fixture 验收后才能转为“已实现”。

## 一、调研边界与当前判断

本轮把问题从“某个函数是否能跑”扩展到八个角度：题库生产、学习流程、UI/可访问性、移动端、性能与资源、跨模块入口、系列插件生态、宣传与发布支持。前几轮已覆盖存储、导入、riff/FSRS、模考、AI 证据和基本性能；本轮不重复提出同一 bug，而是把已有方向补成用户可走通、可解释、可恢复、可宣传的闭环。

源码审计显示，当前运行时仍存在几类结构性差距：

- 练习视图在 `PracticeTab.svelte` 中以多个 view 分支直接切换，入口、返回上下文和活动会话没有统一状态机；“模式卡”也仍有硬编码的 disabled 分支。设计文档中的 S1–S14 不能直接当作已经实现的页面。
- 多选题仍沿用 `role="radio"` 及单值 `aria-checked` 判断；报告图表是无文本等价物的 SVG；多处入口仍使用原生 `confirm()`。这些属于可访问性和交互契约缺口，应单独验收。
- `src/scss/lv-tokens.scss` 保留颜色 fallback，界面仍有 emoji 作为唯一图形入口；这与 docs/12、docs/13 的主题和 icon sprite 约定不一致。
- `lv-exam:stats` 当前由 `index.ts` 在加载时广播一次；迟到的监听者、答题后的更新、跨窗口补发和按需查询都没有明确契约。不能把一次启动广播宣传成完整生态 API。
- 兄弟插件已有可复用的公开桥，但成熟度不同：打卡有 `window.siyuanCheckin` API v5，人脉有 `window.LvContacts` protocol v1，雷切有 `registerHomeModule` widget protocol v2；小驴闪卡的自定义事件主要留在插件 eventBus，拾遗的 `window.siyuanGlean` 仍是拟议接口。考试联动必须按“已实现/拟议”区分。

## 三、待办分组说明

### 43：题库生产与模块深化

把“能导入/能练习”推进到题库作者能管理质量、修订、材料组和批量操作。重点是可追踪修订、可撤销写入和低样本提示，不引入多人协作或云端运营系统。

### 44：学习策略与完整使用流程

把到期复习、普通练习、预览、模考复盘和每日计划区分开；策略可以选择，统计口径保持一致。研究结论只作为解释和实验设计输入。

### 45：UI、交互、可访问性与视觉一致性

补齐路由上下文、异步状态、焦点、表单、图表、颜色、图标、缩放、移动安全区、TTS 和 AI 发送预览。目标是每个状态都有可行动下一步，键盘/读屏/触控走同一条任务路径。

### 46：性能、资源、离线与可观测性

把“万题级”从纯函数软上限变成真实首屏、滚动、导入、报告重算和内存门槛；定义取消、低功耗、断网和诊断包边界。性能目标应记录设备、前端、数据规模和 p75/p95。

### 47：模块边界、入口协作与首用引导

统一模式能力描述、设置作用域、入口移交、深链返回、首次五分钟任务和错误诊断，避免每个视图各自维护一套状态与文案。

### 48：小驴系列插件联动

先做能力发现和用户同意，再做单向、幂等、可撤销的最小联动。打卡、人脉、雷切已有公开契约；闪卡跨插件事件和拾遗 API 仍需先做协议 spike，不能把私有 eventBus 或文档拟议接口当成可用依赖。

### 49：宣传、介绍与发布沟通

宣传材料按“已验证/实验性/规划”分层；演示素材来自固定 fixture；README、Release、预览图、隐私说明和实际 UI 必须互相对得上，不以学习科学、FSRS 或 AI 自报质量做效果承诺。

### 50：验收、支持与反馈闭环

将上述候选转为可复核的场景矩阵、诊断包、问题模板和版本回归材料，避免只靠单元测试、截图或“方法存在”判定完成。

## 五、实施顺序建议（仍然不是开发授权）

1. 先把 47-01/47-02、45-01/45-02、50-01 固定为验收框架，形成一条可复现的入口→练习→错题→报告旅程。
2. 再做 45 组的可访问性和移动端阻断项，以及 46 组基准；未通过时不扩展更多联动入口。
3. 在 37–42 的保存、题块读回和 riff 语义稳定后，优先实现 43/44 中会改变数据口径的事项。
4. 48 组按打卡→雷切→人脉的真实公开契约推进；闪卡/拾遗只做协议 spike 和用户选择式流程，不把拟议 API 写进已支持列表。
5. 最后根据 50 组证据更新 49 组 README、预览图、演示 GIF 和 Release 说明。
