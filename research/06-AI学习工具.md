## 一、逐产品深挖

### 1. StudyFetch（AI 家教 Sparky / Spark.E）

**定位一句话**：把"AI 家教"作为常驻中枢的学习平台——上传课件/讲义/PDF/录课/YouTube 后自动生成闪卡、测验、笔记，AI 家教 Sparky 以侧边栏形式贯穿所有学习环节。

**核心功能机制详细清单**：
- 输入源：PPT、课程讲义、课堂笔记、PDF、学习指南、讲课录音、笔记照片、YouTube 链接；上传后"瞬间学会你的课程材料"。
- **来源引用（Citations）**：每张闪卡、每道测验题、每个学习工具都带"回指原始材料"的引用——这是该产品反复强调的信任机制，FAQ 明确说题目 grounded 在教师提供的内容上，而非开放网络。
- 测验题型：选择题、判断题、填空题、简答题、自由作答共 5 类（宣称"比典型学习应用多 5 倍题型"）；实时判分；答错时"解释为什么正确答案是对的"。
- **错题重现机制**："Missed questions come back until you get them right"——答错的题反复出现直到做对，已掌握的题停止出现，把注意力集中在薄弱处。这是生成→练习→再暴露的闭环核心。
- **置信度追踪（Confidence tracking）**：每题可自评"我有多确定"，AI 据此区分"会做"与"蒙对/不会但做对"（元认知校准），不只是统计对错。
- Sparky 侧边栏：在测验和闪卡界面内以持久侧栏存在，可以"做题中途不打断地要求讲解"、"对某张闪卡就地追问"；一次对话里可同时完成讲概念、总结章节、生成测验、生成闪卡。
- 家教模式/插件体系：Socratic Tutor（用提问引导而非直接给答案）、Essay Coach（挑战论证结构、指出表达漏洞）、Visual Explainer（类比+空间描述+分步视觉推理）、Tutor Me（Explore/Mastery 两种模式）、Exam Mode、Hint Helper（提示递进）、Mnemonic Maker（口诀）、Professor Sparky、Deep Learner；还支持**自定义指令插件**（如"把我当大一新生讲解"、"做成 MCAT 风格"）并可保存复用。
- Guided Chatting：对话会"按正确顺序"把你先推进闪卡、再测验、再模考，根据你的节奏和学习风格自适应排序。
- 学习计划：按主题排序列出"已覆盖/还差什么"；Cram 模式为考前冲刺优先关键概念。
- 其他：录直播课实时记笔记、语音通话求助（Call Sparky）、iOS/Android 全端。

**值得偷师的具体细节**：
1. **来源引用作为全链路硬约束**——每道 AI 生成的题都能跳回原文，思源笔记天然有块引用（block ref），AI 出题时把来源块 ID 写进题目字段即可低成本复刻这一信任机制。
2. **"错题循环出现直到做对"**——把错题本从"静态收藏"变成"动态重排进练习流"，实现成本极低。
3. **置信度自评**——一道题只加一次点击成本，却能把"蒙对"纳入薄弱点统计，对考试类产品价值极高（考场不允许蒙对）。
4. **插件化 prompt 预设**（Hint Helper / Exam Mode / 自定义指令）——本质是一组可切换的 system prompt 片段，用户还能自存自定义 prompt，与思源插件的用户自带 API key 场景契合。
5. 侧边栏不打断练习流——讲解是练习的附属通道而非独立页面。

**明确不借鉴的部分及理由**：
- 直播课录音转写、语音通话、Podcast 类功能：与"题库学习管理"定位无关，且依赖重音频基础设施。
- SaaS 会员配额体系（生成量/对话量计费墙）：小驴考试用户自带 key、本地存储，不搞配额。

### 2. Knowt（Quizlet 免费替代）

**定位一句话**：以"完全免费复刻 Quizlet Plus 付费功能"为增长武器的刷卡/刷题平台，主打从 PDF/视频/PPT/笔记一键生成闪卡与练习题。

**核心功能机制详细清单**：
- **Quizlet 导入路径（增长黑客）**：装 Chrome 扩展 → 打开任意 Quizlet 学习集 → 点扩展"Open in Knowt"，几秒完成迁移；也支持粘贴学习集 URL 直接导入。用"把存量内容搬过来"替代"让用户重新录入"，冷启动成本≈0。
- **5 种学习模式全免费**：Learn Mode、Practice Test（模拟测验）、Match（连线小游戏）、Flashcards、Spaced Repetition——精确对标 Quizlet Plus 的付费点逐个免费化。
- **Learn Mode 机制**：AI"预测并为每张闪卡选择最合适的题型"（选择/手写输入/判断/填空，连线是独立小游戏模式）；目标是"尽快把所有卡片移入已掌握"；本质是**按卡片自适应出题**而非按题库抽题。
- 生成流程：上传讲课视频/PDF/PPT/文件 → 自动产出"重点摘要笔记"+ 闪卡 + 练习题三件套；也可在"AI 编辑器"里打字写笔记再生成。
- Kai 吉祥物助手：针对"你的文件"提问的问答助手（file-grounded chat），无通用闲聊。
- 免费策略细节：无限次 Learn Mode、练习测验、闪卡双面贴图、闪卡格式化、间隔重复全免费；另有 Student/Teacher/School 付费档（细节未公开）。

**值得偷师的具体细节**：
1. **"按卡片选题型"的自适应粒度**：同一张卡今天考你选择、答错下次改成手写（生成成本递增），这是"AI 出题"与"闪卡 SRS"打通的最优雅示范——小驴考试可把"错题降级为更简单题型重考、连对升级为手写/简答"做成难度爬梯。
2. 导入存量内容（Quizlet/Anki）作为增长入口——小驴考试对应"导入已有题库/Excel 题库"，把导入做顺滑比把生成做华丽更能拉新。
3. 摘要笔记 + 闪卡 + 练习题"三件套"同源生成——一次解析，三种产物，成本分摊。
4. 免费标尺宣传法：把竞品付费功能逐条列成免费清单（对国内可对标"某笔/某题库的会员功能"）。

**明确不借鉴的部分及理由**：
- Match 连线小游戏：娱乐性强但对严肃考试（公考/考研/资格证）帮助有限，优先级低。
- Chrome 扩展导入 Quizlet：Quizlet 内容迁移涉及版权与法律风险，且目标用户场景不同。

### 3. Turbolearn AI（现名 Turbo AI）

**定位一句话**：先做"AI 课堂笔记员"再做学习工具——录音/PDF/视频先进来变成结构化笔记，闪卡和选择题再从笔记二次生成。

**核心功能机制详细清单**：
- 输入：讲座录音、视频、PDF、手写笔记照片；可实时听课记笔记。
- 笔记生成：自动产出含表格、图表、emoji、公式的结构化笔记，可下载当学习指南。
- **"笔记是中间产物"架构**：闪卡和 MCQ 测验从生成的笔记二次派生，而非直接从原始 PDF 生成——先压缩再出题，控制了上下文长度与出题质量。
- 与笔记对话：chatbot 只基于上传内容回答；**不保存会话历史**（每次新会话）；无家教模式、无追问建议（评测明确指出这是短板）。
- 配额体系：免费版每月 5 道测验题、1 次 PDF 上传、10 条对话；Pro（$9/月年付、$17.99 月付）50 题/月、10 次 PDF、无限闪卡、200 条对话、听课 15 小时/月。
- 已知质量问题（第三方评测）：测验题"重复、简单、有准确性问题"，建议人工复核后再用；闪卡生成约 30 张/笔记封顶，长材料要手动拆分。
- 附加：笔记转播客（音频摘要）。

**值得偷师的具体细节**：
1. **两段式生成（原文→笔记→题目）**：对超长材料先让模型做"考点提纯"再出题，比直接对整本 PDF 出题省钱且质量更稳；小驴考试对大部头教材/讲义应默认走这条管道。
2. **闪卡/题目按"笔记"为单位分批生成（30 张上限暴露的工程现实）**：长材料必须切片，切片单位应与知识点对齐，否则生成质量下降。
3. 反面教材三连：不存会话历史、无追问、题目准确性差需人工复核——说明"AI 讲题"若只是"对材料问答"留不住用户，必须做成有状态、可追问、带题面上下文的讲解。

**明确不借鉴的部分及理由**：
- 每月 5 道题的配额墙：极端反用户，评测差评集中于此；小驴考试 BYO key 无此问题。
- 笔记转播客：超纲。
- "以笔记为中心"的定位：小驴考试以题库为中心，笔记只是输入源之一。

### 4. Quizgecko（文档→测验专家）

**定位一句话**：面向教师/企业/学生的"文档变测验"垂直工具，题型与难度控制选项最全，导出生态（Anki/CSV）最完整。

**核心功能机制详细清单**：
- 输入源：PDF、网页 URL、YouTube 视频、粘贴文本、docx、PPT；也可反向导入 Anki 闪卡。
- **题型（6+1 种，同类产品最全）**：单选、多选（select all that apply）、判断、简答、填空、匹配，以及 Mixed（混合）模式。
- **难度分档（同类最细）**：Auto / Easy / Medium / Hard / Very Hard / Mixed 共 6 档；生成时可同时设定 Max Questions（题目数量上限）与输出语言。
- 生成后编辑：题目可逐题复查编辑（改措辞、修答案、**单题重新生成**）——把"人工校对"做成产品内一等公民。
- **导出体系**：Course → More → Export Course / Export Questions；闪卡可导出 Anki 原生 `.apkg`（官方推荐路线），CSV 导出随订阅档位解锁；另有 Chrome 扩展对任意网页即时出题。
- 商业化：免费档功能受限（页数/字符数/导出格式），教育与企业档为主。

**值得偷师的具体细节**：
1. **难度档位的完整词汇表**：Easy→Very Hard→Mixed 六档比"三档"更贴考试场景（公考行测天然分"易/中/难/极难"），Mixed 档对应"乱序混合练习"。
2. **多选题与匹配题的一等公民地位**：公考多选题、常识匹配题是刚需题型，多数竞品只做单选，Quizgecko 的题型清单几乎可直接抄成小驴考试的题型枚举。
3. **单题重新生成**：整批重生成太贵太慢，"对这一题不满意→换一题"的粒度才是用户真正要的。
4. `.apkg` 导出：把 AI 生成的题目送进 Anki 生态，等于免费接入了最硬核的 SRS 用户群。

**明确不借鉴的部分及理由**：
- 按导出格式收费（CSV 都要付费）：开源插件做内容封锁会被社区反噬。
- Chrome 扩展抓任意网页出题：浏览器扩展超出插件形态，暂不做。

### 5. Revisely（+ Monic.ai 关停事件）

**定位一句话**：以"quiz/闪卡生成器矩阵"为核心轻量平台（宣称已生成 1 亿+ 道题），2024 年前后吸收了竞品 Monic.ai 的用户。

**核心功能机制详细清单**：
- 输入界面明确分四类：Document / Text / Image / Video；支持手写笔记照片识别；无材料时提供"从零创建"（不依赖原文直接出题）。
- 配套工具矩阵：AI Quiz Generator、AI Flashcard Generator（图片/PDF/PPT/手写/粘贴文本）、Notes Summarizer、AI 答案评估（AI-Assessed Answers：免费 50 次/付费无限——AI 对用户主观作答打分）。
- AI 辅助编辑题目；免费版仅"非 AI 闪卡"无限（手动制卡），AI 生成需付费；文档上传限 5 页（免费）→ 200 页（付费）。
- **Monic.ai 关停（2026-03-07 停服）**：官网挂告别信，"两年、10 万+学习者"，停服前开放数据导出表单，用户被社区引导迁移至 Revisely。教训：纯 AI 包装类学习 SaaS 生命周期短、留存难。

**值得偷师的具体细节**：
1. **AI 主观题判分（AI-Assessed Answers）**：把"简答题 AI 阅卷"做成独立计费点，说明需求真实存在——小驴考试的主观题（申论/问答）模块可复用此机制：按采分点比对给分+评语。
2. "从零创建"模式：允许无材料直接按主题+考纲出题（备考后期"按大纲查漏"场景）。
3. 停服时主动提供**数据导出**是行业底线动作——本地优先的小驴考试天然把题库文件交在用户手里，这是对云产品最锋利的差异化卖点。

**明确不借鉴的部分及理由**：
- 工具矩阵式分散布局（quiz/flashcard/notes 三个独立入口）：小驴考试应围绕"一本题库"做深，不做三兄弟工具箱。

### 6. NoteGPT（YouTube/PDF 摘要 + 测验）

**定位一句话**：以视频/PDF 摘要起家、附带 AI 测验生成器的轻量学习助手，特色是把生成用的 Prompt 开放给用户自定义。

**核心功能机制详细清单**：
- 输入：文件（PDF/PPT/DOCX/电子书/图片，≤50MB）、文章链接、YouTube、粘贴文本四类入口。
- 生成设置面板（页面明示）：Question（数量，默认 10）、Difficulty Level（默认 Medium）、Output Language（默认 Auto）、**Prompt Settings（高级 prompt 自定义入口）**。
- 产出以单选题（MCQ）为主；宣称覆盖布鲁姆认知分类多个层级；用户证言提到情景题、听力理解题等变体。
- 答题与反馈：在线作答；**即时反馈 / 延迟反馈两种模式可选**（instant or delayed feedback）；每题带解析；"从每次测验获得学习洞察"指出强弱项；支持打印、分享、追加出题。
- 三步工作流：①上传+调设置 → ②生成并在线作答 → ③看反馈/洞察，打印/分享/加题。
- 另有独立 AI Flashcard Maker（自动含"问题+答案+要点提示"三要素的卡），但**测验与闪卡之间无打通机制**（页面未描述任何联动）。

**值得偷师的具体细节**：
1. **Prompt Settings 开放给终端用户**：允许自带 API key 的思源用户直接编辑出题 prompt（保存为模板），是差异化亮点且实现成本≈0——本质就是把这个调研里的 prompt 模板做成可编辑配置。
2. **即时/延迟反馈切换**：刷题阶段即时反馈，模考阶段延迟反馈（考完统一复盘），两种模式对应学习科学里的两种场景，一个小开关覆盖。
3. "追加出题"按钮：在已有测验上继续加题（增量生成），避免一次生成太多。
4. Bloom 层级作为题目属性：与"难度"正交，可支撑"今天专刷应用层题"的练习维度。

**明确不借鉴的部分及理由**：
- YouTube 摘要主线：视频学习不是考试刷题场景核心，小驴考试不做视频转题。
- 打印/分享为获客噱头：纸质打印与插件场景弱相关（但"导出为标准试卷排版"值得保留为导出格式之一）。

### 7. 通用大模型"题库生成"Prompt 工程模式（QuizAPI / practicequiz 模板 / 中文实战）

**定位一句话**：把 LLM 变成稳定出题机器的工程套路——结构化 JSON 约束 + 超量生成 + 独立模型校验 + 机器清洗 + 人工终审，社区已有成熟可复制的模板。

**核心机制详细清单**：

**A. QuizAPI 的四阶段出题管线（工程化最完整）**：
- 管线：生成 → 结构校验 → 答案核验 → 质量评分 → 人工复核队列 → 发布。
- **超量生成 1.5 倍**（`ceil(targetCount × 1.5)`），过滤后裁剪到目标量，失败不重试整批而是丢弃淘汰。
- Prompt 硬约束：每题只考一个具体概念；恰好 4 个选项恰好 1 个正确；**每个干扰项必须对应"一个常见误解"**；解析 ≤80 词且要针对"最常见的错误选项"写；难度校准公式——easy=记忆、medium=情景应用、hard=边界情况/细微区别/多步推理；明令禁止观点题、脑筋急转弯、歧义题；显式要求 JSON 输出防格式漂移。
- 结构校验用 Zod：题干 20–2000 字符、difficulty 枚举、4 个选项各 1–500 字符且经 refine 保证恰好一个 `isCorrect=true`、解析 10–500 字符。
- **答案核验双通道**：代码题直接执行代码验证输出（"LLM 预测输出会犯细微错误，跑一遍是唯一可靠手段"）；概念题用**另一个模型 + 不同温度**独立核验，返回 `{correctAnswerIsRight: boolean, confidence: 0.0–1.0, issue: string|null}`，confidence < 0.85 拒收。关键发现：**换模型核验比自我核验抓错多得多（self-verification 只是自我附和）**。
- 质量评分 0–100（4×25 分）：清晰度（罚超短题干、"which of the following"句式、否定词 not/never/none）；干扰项质量（罚选项长度方差过大，"all/none of the above" 罚 15）；难度准确度；解析质量（罚超短、罚不含"because"的解析）。≥75 分进入人工复核，<75 弃用重生成。
- 人工侧遗留问题：**LLM 无论 prompt 怎么写都向中等难度漂移**，难题仍需人工校准。
- 效率：宣称比人工命题（10–15 题/专家小时）快 10 倍。

**B. practicequiz.app 的 GitHub prompt 模板（单次对话出题范式）**：
- 结构：角色设定（"教育测评专家"）+ 无材料时的兜底话术（要求先提供材料）+ 持续学习模式（对话中追加材料自动追加出题）+ 出题要求 + JSON schema + 质量守则。
- JSON：`{title, questions:[{question, options[4], correct_answer（必须与 options 中某项逐字一致——天然可机器校验）, explanation_prompt}]}`；8–12 题；考理解不考背诵；难度混合（记忆/应用/分析）。
- 质量守则：禁"以上都是/以上都不是"；干扰项"合理但明确错"；题目聚焦材料最重要概念；题型多样化（定义/应用/分析）。

**C. CSDN《AI 模拟出题实战》（中文场景，含全链路质量数据）**：
- Prompt 五模块框架：角色设定（资深命题专家，熟悉考纲）→ 任务描述（题型/数量/知识点范围）→ 格式约束（JSON 数组）→ 内容规则（覆盖面/去重/难度分层）→ 输出示例（few-shot）。
- 中文七字段 JSON：`{id, question, options:{A,B,C,D}, answer:"B", analysis, difficulty:"基础|中等|提高", knowledge_point}`。
- 难度控制技巧：**用干扰项类型定义难度**（提高题的干扰项来自"常见性能误区或边界条件错误"）；让 AI 先写正确答案的执行过程再按典型错误造干扰项；**试做校验**——抽题试做，正确率应落在 60%–75% 区间，否则难度标注失真。
- 批量生产参数：temperature=0.75、top_p=0.9；按知识点分批循环调用、追加写 JSON；产出 208 题、有效保留 108 题（**约 52% 存活率——AI 直出的题目一半要被洗掉**）。
- 自动组卷：按 `(knowledge_point, difficulty)` 二维分桶 + 试卷蓝图比例抽取（如选择题 30 = 基础12/中等12/提高6）+ 固定随机种子可复现 + 知识点穿插排序防扎堆 + 桶不足告警。
- 机器清洗五件套：字段完整性检查、缺答案剔除、题干哈希查重、关键词匹配知识点、**Jaccard 相似度 >0.7 判重**；人工终审收尾；编程题必须实际跑参考代码（未验证代码错误率 5%–15%）；**多生成 30%–50% 备选**。
- 问题-对策表（全是踩坑经验）：知识点分布漂移→把考纲原文粘进 prompt 要求按清单出题；批间重复→把已有题目摘要作为上下文传入+语义指纹查重；难度失真→干扰项设计+试做校验；参考答案错→执行验证；解析空泛→限定"必须含具体计算过程，禁用'该题考察了…'"；JSON 非法→强调"只输出 JSON 不要解释文字"+代码里容错提取大括号再 parse；输出截断→分小批次。

**D. 阿里云《企业培训系统 AI 出题》（RAG + 自适应方向）**：
- RAG 管线：python-pptx 抽取 shape.text → **按标题层级语义切片**（非机械按字符切，单块约 1000 字）→ embedding → Qdrant 向量库 + ES 双路检索（向量抓语义、BM25 抓"制度条款编号"类精确术语）→ **RRF 倒数排序融合**取 top_k。
- Prompt 四要素：角色定位 / 输出格式约束 / 质量标准 / **溯源要求**——每题必须标注 `source`（文档名+段落），用户质疑答案时"翻原文对质"。
- 认知层次映射：布鲁姆分类（记忆/理解/应用/分析/评价/创造）作为题目字段；判断题错误项须说明原因；干扰项须来自常见易混淆点。
- **三层质量校验**：格式层（正则提取 JSON、必填字段校验）→ 去重层（题干前 30–50 字建 set）→ **多模型投票层**（GPT-4o + Claude + 文心一言交叉判定，不合格自动优化或重生成）。
- **IRT 难度自适应**：用历史答题数据估计每题难度 D、区分度 Disc、猜测系数 G 三参数；生成期用 prompt 分层（简单=显性知识直接考记忆、中等=2–3 步推理、困难=跨章节综合/案例）；组卷按 30/50/20 比例从题池抽题；进阶用强化学习策略网络"千人千卷"。
- 薄弱点闭环：基于答题记录更新难度参数与干扰项库（持续学习），实现"按薄弱知识点定向出题"；效果：出题周期 12 小时 → 30 秒。

**值得偷师的具体细节（本节汇总）**：
1. 超量生成 + 淘汰（1.5×，甚至 30–50% 冗余）是比"生成后修复"便宜得多的质量策略。
2. 换模型核验 >> 自我校验；BYO key 场景可退化为"同模型、不同 temperature、换角色 prompt 的独立第二遍"。
3. 干扰项工程是题目质量的命门：干扰项=常见误解清单；解析要针对最常见错误选项写。
4. 试做校验（正确率 60–75% 区间）是廉价难度校准器，也是难度漂移（LLM 向中等难度漂）的唯一民间解法。
5. 溯源字段（来源文档+段落/block）解决 AI 出题最大的信任危机，思源块引用是现成基础设施。
6. 题干哈希 + Jaccard 0.7 双层查重 + "把已有题摘要喂回上下文"防批间重复。

**明确不借鉴的部分及理由**：
- IRT/强化学习自适应组卷：需要大规模历史答题数据冷启动，个人插件 v1 无数据，先用"正确率分桶"简化版。
- 多模型投票（3 个商用 API 交叉）：BYO 单 key 用户负担不起三份调用，v1 做单模型双遍校验即可。

### 对小驴考试的启示

**必须做（v1 核心，有明确验证的做法）**：
1. **AI 出题 → 结构化 JSON 题目格式**（见下节 schema），字段至少含：题干/选项/答案/解析/难度/知识点标签/来源块 ID；来源引用直接复用思源块引用，实现"每题可回原文对质"。
2. **生成设置面板**：输入源（当前文档/所选块/指定笔记本/粘贴文本）、题型（单选/多选/判断/填空起步）、数量、难度（易/中/难/混合）、输出语言——对齐 Quizgecko 选项词汇表。
3. **错题循环**：答错的题自动回流练习队列直到做对（StudyFetch 机制，本地实现零成本）。
4. **AI 讲解侧栏**：做题界面常驻"问 AI"面板，带题面+选项上下文；答错默认给"为什么正确答案对+你这个选项错在哪"（逐选项解释）；提供"给点提示"（Hint 递进）与"苏格拉底模式"开关（只提问不报答案）。
5. **单题重新生成 + 题目编辑**：用户对某题不满意可就地重生成/手工改，生成结果永远是"草稿待审"而非"成品"。
6. **机器清洗兜底**：JSON 容错解析、必填字段校验、题干哈希查重、选项数与答案一致性断言（correct_answer 必须命中 options）——这四项在客户端就能拦掉大部分废题。

**改造后做（有需求但需按本地/BYO key 场景改造）**：
1. **两段式生成**（长材料→考点提纯→出题）：SuperTrim 版本，切片按思源标题层级走，比通用 RAG 便宜。
2. **超量生成 1.5× + 二遍校验**：v1 用"同模型第二遍换角色+温度"做核验（置信度门限 0.85 可配置），留接口给多模型投票；解析必须 ≥N 字、含因果词，空泛解析打回。
3. **置信度自评**：答题界面加"确定/模糊/蒙的"三态，统计时把"蒙对"计为薄弱知识点。
4. **按薄弱知识点定向重出题**：错题本统计知识点分布 → 一键"针对错 3 次的知识点生成 10 道新题"，把已有题目摘要喂进 prompt 防重复；难度先按正确率分桶，数据积累后再谈 IRT。
5. **导出 .apkg / CSV / 试卷排版**：接入 Anki 用户群并满足打印模考需求。
6. **Prompt Settings**：把出题 system prompt 做成可编辑模板（内置"公考行测""考研政治""医学执业"预设），配合 BYO key 是天然卖点。
7. **即时/延迟反馈切换**：刷题=即时，模考=考后统一解析。
8. **布鲁姆认知层级标签**：作为知识点之外的第二个正交维度（先只标记记忆/应用/分析三层，降低 prompt 复杂度）。
9. **主观题 AI 判分**：申论/问答按采分点比对给分（Revisely 的 AI-Assessed Answers 机制），主观题模块上线后做。

**明确不做（及理由）**：
1. 直播课录音转写/实时记笔记/语音通话/播客生成——音频基础设施重、与刷题定位无关。
2. YouTube/视频转题——视频场景非考试题库核心，成本高收益低。
3. SaaS 配额墙与导出收费——本地插件 + BYO key 的产品伦理不允许，且这是对云竞品的差异化武器。
4. 强化学习自适应组卷/千人千卷——冷启动无数据，先用正确率分桶；预留数据结构。
5. Essay Coach/作文批改——超出题库考试范畴。
6. Chrome 扩展/全网抓取出题——超出插件形态与版权边界。
7. 蒙题"以上都是/都不是"类选项——社区共识是质量毒药，prompt 里明令禁止。

### AI 出题的结构化 JSON 题目格式建议（Schema 示例）

综合 QuizAPI（answers 数组+isCorrect）、practicequiz（correct_answer 逐字可校验）、CSDN（七字段+中文难度）、阿里云（source/bloom_level）四家之长，适配思源块引用与本地题库：

```jsonc
{
  "id": "ai-20261001-a1b2c3",              // 生成题唯一 ID（入库后映射题库 ID）
  "type": "single",                         // single | multiple | judge | fill | short | matching
  "stem": "下列关于思源笔记块引用的说法，错误的是？",   // 题干；禁止"以下说法正确的是"式空泛句式
  "options": [                              // 判断题/fill 可为空数组
    { "key": "A", "text": "块引用支持跨文档跳转", "distractor_reason": null },
    { "key": "B", "text": "块引用会随源块删除而自动变成纯文本", "distractor_reason": "常见误解：以为引用是软链接" },
    { "key": "C", "text": "块引用可被搜索定位", "distractor_reason": null },
    { "key": "D", "text": "块引用支持动态锚文本", "distractor_reason": null }
  ],
  "answer": ["B"],                          // 与 options.key 严格对应，多选题为数组
  "analysis": {
    "summary": "块引用是硬引用，源块删除时引用块会断链提示而非自动降级，需手动处理。",  // ≤80 词，必须含因果解释
    "per_option": {                         // 逐选项解释（AI 讲题直接复用）
      "A": "正确，块引用支持跨文档。",
      "B": "错误即本题答案：源块删除后引用进入'缺失引用'状态，不会静默变成文本。",
      "C": "正确，引用可被全局搜索。",
      "D": "正确，锚文本可编辑。"
    }
  },
  "difficulty": "medium",                   // easy | medium | hard | very_hard；生成参数里的 mixed 只影响抽题不影响单题标注
  "bloom": "understand",                    // remember | understand | apply | analyze | evaluate | create（v1 建议只用前三层）
  "knowledge_points": ["块引用", "数据安全"], // 数组；中文关键词，与题库知识点体系对齐
  "source": {                               // 溯源（思源块引用即免费 citation，StudyFetch 同款信任机制）
    "doc_id": "20250901120000-xyz",
    "block_id": "20250901120100-abc",       // 可直接转为块引用链接
    "quote": "删除源块时，引用处会显示缺失引用标记……"
  },
  "meta": {
    "origin": "ai",                         // ai | manual | imported
    "model": "glm-4.7",                     // 生成模型（BYO key 记录，便于复盘换模型）
    "generated_at": "2026-10-01T12:00:00+08:00",
    "prompt_template": "default-exam-zh",   // 关联 Prompt Settings 模板
    "review_status": "pending",             // pending | verified | edited | rejected（人工校对流状态机）
    "verify": { "passed": true, "confidence": 0.92, "checked_by": "self-round2" }, // 二遍校验结果
    "quality_score": 82,                    // 客户端规则评分（清晰度/干扰项/解析长度等，对齐 QuizAPI 四维）
    "stats": { "attempts": 0, "correct": 0, "confidence_self": null }  // 练习统计回写，支撑薄弱点重出题
  }
}
```

配套生成管线建议（一段话版）：按知识点切片注入 prompt（五模块框架：角色/任务/格式/内容规则/few-shot 示例）→ 超量生成 1.5× → 客户端 Zod 式校验（字段完整性、答案命中选项、禁"以上都对"）→ 哈希+Jaccard 查重并把已有题摘要回灌 prompt → 二遍换角色核验（confidence ≥0.85）→ quality_score ≥75 入库标 pending、其余丢弃 → 用户练习中逐题编辑/重生成 → 错题知识点回流触发定向再生成。难度用"干扰项类型定义难度 + 试做正确率 60–75% 校准"对抗 LLM 中等难度漂移。
